# 層状空隙セルでの真応力制御・接触過渡検証

2026-10-18。前回の荷重演算子と製造解の検査から進み、空隙の閉鎖と自己接触を
陽解法FEMで実際に時間積分しました。全ケースを完了／不合格／未達に分けて保存します。

## 検証する系と条件

これは **1×1×1 mm、固体体積0.8 mm3、初期平面空隙率20%の層状セル** です。
参照z座標0～0.4 mmと0.6～1 mmに固体層があり、中央が空隙です。
周期境界と6成分の平均変形勾配を使い、せん断・横変形を固定していません。
16節点・12四面体の粗い検証メッシュで、球充填体ではありません。
圧力の変換とCSVの公称荷重列の定義は[真応力制御の記録](objective-pressure.md)に示します。

材料は従来の試験用 Hencky J2：E=10 MPa、ν=0.33、Kirchhoff降伏応力0.05 MPa、
硬化係数0.2 MPa。数値密度1e-9 tonne/mm3、減衰6000/s。
接触は `area_guarded`、μ=0.3、参照面積、バリア厚さ0.02 mm、ペナルティ20 MPa/mm。
圧力は空間固定の Cauchy 応力 diag(0,0,−p)、目標p=0.02 MPa。
低圧の接触過渡を先に確認するための開発上の検証条件で、ユーザー指定の0.1 MPaの代替結果ではありません。
質量フレームは従来比較用の `pinned`、保持2 ms。

増加時間4 ms／8 msとCFL 0.2／0.1の4ケースを比較します。
増加時間を延ばすのは準静的近似への速度依存、CFL半減は時間離散化の影響を見るためです。
材料・摩擦・ペナルティ・幾何形状・合否公差を変更していません。
この比較をメッシュ収束、密度・減衰の感度検証、または一般的な速度収束の証明とは扱いません。

## 判定を分ける理由

1. **ソルバー監査**：既存の全採用ステップ監査を使用します。最終力の釣合い、
   エネルギー相対誤差2%未満、運動エネルギー比1%未満、Coulomb上限、正のJ、
   体積一致、指定荷重への到達、経路完了などです。
   既存の運動エネルギー判定区間は「増加時間の半分より後」です。
   エネルギー・Coulomb比の極値は全採用ステップから集計し、閉曲面体積と静力釣合いは終点で検査します。
2. **終点の追加検査**：最終状態の四面体幾何体積、参照体積×弾性体積比、閉曲面体積を
   別々に求めます。仕事等価Cauchy応力と指定一軸応力の相対差2%未満、
   正の層間距離、平面性、接触発生も確認します。
   応力比較はソルバーが内部一般化力から復元した出力を使います。
   接触履歴のチェックポイントがないため、終点の摩擦接触力を別実装で再構成した検査ではありません。
3. **既知の対角平衡枝との比較**：軸圧縮差1e-4、空隙率差1e-5、平均Fのせん断ノルム1e-8を
   事前の基準として保存します。この枝は対角変形・均質層という仮定を持ちます。
   摩擦履歴を持つ一般の過渡解で、唯一の平衡枝であると主張しません。
4. **接触開始からの追加KE診断**：接触数>0、指定圧力が観測最大値の1%を超える
   出力点を調べ、K/|Δ内部エネルギー|を集計します。小さい分母の床は既存エネルギースケール×1e-8です。
   後半の監査が合格しても、初期の接触応答が準静的とは限らないため追加しました。
   判定目安1%は既存の準静的公差です。これは出力点の最大値で、全採用ステップの最大値の**下限**です。
   超過は不合格の証拠になりますが、非超過だけで過程全体の合格を証明しません。
   初期の材料エネルギーだけを分母にした影響も区別するため、材料内部エネルギー変化と
   接触の法線・接線エネルギーを足した分母でも比を併記します。

追加KE診断は途中で接触直後の応答を確認して導入した診断です。
既存ケースの事前の合否条件を書き換えず、独立の集計として明記します。
時間積分から得た終点と、解析式で構成した状態の検査を混同しません。
未完了・不合格ケースも消さず、未達状態を解と呼びません。

対角平衡枝の既知解は、塑性流動が等体積であることから
log(J)+(1−2ν)pJ/E=0、τ=pJ、ep=max(0,(τ−y)/H)、
λz=exp(−τ/E−ep)、λt=exp(ντ/E+ep/2)。
接触力は参照面積あたりB'(g)=p λt²、セル高さh=0.8λz+g、空隙率g/hです。
実際の計算解から係数を調整していません。

## 接触前の無剛性モード

過渡計算とは独立に、上側の固体層を剛体並進させ、周期セルの高さを同じ量だけ縮める
変位を構成しました。閉鎖量0 / 0.05 / 0.10 / 0.17 mmで検査しています。
最小の残存間隙は0.03 mmで、全てバリア厚さ0.02 mmより大きい状態です。
この変位は周期運動学で表現でき、全四面体の変形勾配はI、内部エネルギーと
接触エネルギー、抵抗力はゼロでした。一方、0.02 MPaの外力は閉鎖方向に0.02 Nの力を持ちます。

したがって、この層状セルには接触前の無剛性の閉鎖モードがあり、
その範囲で正の軸圧力と静的に釣り合わせることはできません。
負荷速度や刻み幅の比較だけで、未接触状態からの全過程を連続した準静的平衡枝として
検証できるとは扱いません。これは接触後の終点の釣合いを否定するものではありません。
また、連結した焼結粒子のネットワークにも同じモードがあるとは結論しません。

[機構検査CSV](../exports/layered-contact-transient-001/mechanism/mechanism.csv)と
`mechanism/summary.json` に全判定を保存します。
次の準静的な検証では、初期から荷重を伝達できる連結した多孔質セルを使い、
初期剛性と接触開始の応答を先に確認する必要があります。

## 連結モデルの初期検査

既存の4 mm連結検証セル（100節点・264四面体、空隙率0.25%）では、
微視的な自由度を静的に消去した6×6初期弾性接線を組み立てました。
6個の固有値は475.91～1846.96 N mmで全て正です。
有限変形FEMの中心差分による6方向の力微分とも最大相対差2.89e-9で一致しました。
これは初期から荷重を伝えられる検証セルの確認で、自己接触を伴う圧力過渡の計算ではありません。

さらに周期グラフの閉路の格子巻数を求めました。境界に触れるだけの孤立体を
3方向につながった構造と誤判定しないよう、閉路の独立な巻数のランクを確認しています。

| モデル | 周期連結成分数 | 巻数ランク | 判定 |
| --- | --- | --- | --- |
| 1 mm層状セル | 1 | 2 | x,yのみ。zの荷重伝達ネットワークなし |
| 4 mm連結検証セル | 1 | 3 | 3方向に連結 |
| 準備済み25 mm充填モデル、初期空隙率39.8592% | 1 | 3 | 3方向に連結 |

25 mmモデルは14320節点・56382四面体の既存メッシュです。
ユーザー指定の100 mmモデルとは区別します。位相的な3方向の連結は必要な検査ですが、
剛性の正定値性や数値的な釣合い、圧密の収束の証明にはなりません。
節点グラフは点・辺だけの共有でも接続として数えるため、有限な弾性荷重伝達を保証しません。
この充填モデルの初期剛性の計算は今回まだ行っていません。

接触開始の検出と周期巻数の判定を含む関連テストは29件合格しました
（最初の27件と、追加の位相検査2件。重複再実行は加算しません）。

## 実行結果

4ケースとも指定の圧力と保持時間まで完了しました。後半・終点の合格は2ケース、
接触開始を含む全過程の準静的な検証は未達です。全ケースでPEEQは0であり、
今回の低圧試験は塑性圧密の検証ではありません。

| 増加時間 | CFL | 最終空隙率 | 後半最大K/ΔI | ソルバー・終点検査 |
| --- | --- | --- | --- | --- |
| 4 ms | 0.2 | 2.120467% | 3.297311% | KE基準不合格 |
| 4 ms | 0.1 | 2.120467% | 3.310295% | KE基準不合格 |
| 8 ms | 0.2 | 2.120474% | 0.004268% | 合格 |
| 8 ms | 0.1 | 2.120474% | 0.004271% | 合格 |

終点の応力相対誤差は最大2.48e-7、エネルギー収支の相対誤差は最大3.00e-4でした。
4ケースとも条件付き対角平衡枝のせん断・軸変形検査は不合格です。
CFL半減による最終空隙率差は4 msで1.45e-10、8 msで8.84e-10（いずれも空隙率の無次元値）。
終点が近いことから全過程の時間収束を主張しません。

接触開始に着目した規格化KEの標本最大値は、出力時刻と小さい分母に強く依存しました。
とくに8 ms・CFL 0.1では、接触直後を捉えた点のK/ΔIが約3360となります。
接触エネルギーを分母に足してもその点の比は約346ですが、これを刻み半減による
動的誤差の増大や速度収束の定量指標とは解釈しません。

実際の接触期間の標本最大KEは8.79e-6～5.48e-5 N mm、終点の材料内部＋接触エネルギーは
約3.44e-5 N mmです。初期の応答と終点の静的釣合いは別の検査になります。
同じ200ステップ毎の出力でもCFLによって物理的な出力時刻が異なります。
CFL比較の補間された過渡空隙率差は最大0.00344／0.00241ですが、出力補間の影響を含みます。
次の監査では、接触開始の全採用ステップ極値または固定物理時刻の出力を保存し、
出力間隔によるピークの取り逃がしを分離する必要があります。

## 再現

既存仮想環境を使用し、作業ディレクトリはリポジトリ直下とします。
`PYTHONPATH=.`、`OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1` を設定します。
出力先は必ず未使用の名前にします。

```bash
python tools/verify_layered_pressure.py --ramp-seconds .004 --cfl .2 --output results/layered-T4-cfl02-NEW
python tools/verify_layered_pressure.py --ramp-seconds .004 --cfl .1 --output results/layered-T4-cfl01-NEW
python tools/verify_layered_pressure.py --ramp-seconds .008 --cfl .2 --output results/layered-T8-cfl02-NEW
python tools/verify_layered_pressure.py --ramp-seconds .008 --cfl .1 --output results/layered-T8-cfl01-NEW
```

初期状態の独立検査は次のコマンドです。

```bash
python tools/verify_layered_mechanism.py --output results/layered-mechanism-NEW
python tools/verify_connected_initial_stiffness.py --output results/connected-stiffness-NEW
python tools/verify_periodic_connectivity.py --output results/periodic-connectivity-NEW
```

集計ツールは `tools/summarize_layered_pressure.py`。完了した4ケースを `--inputs`、
上記3つの結果を順に `--mechanism`、`--connected`、`--connectivity`、未使用の保存先を
`--output` に指定します。描画には既存環境の `MPLCONFIGDIR` と `XDG_CACHE_HOME` を使います。

検証コマンドはソルバー・独立終点・対角枝の全検査が合格した場合のみ終了コード0です。
比較・保存ツールの終了コード0は、圧密モデルの物理検証合格を意味しません。

## 適用限界

一般的な辺だけの接触の反力、複数接触パッチ、表面適応再メッシュは未対応です。
1種類の粗い表面メッシュによるこの検証だけで粒子表面接触の収束を主張しません。
100 mmの球充填体、粒径10 mm、ネック径2 mmの空隙率40%→10%の圧密は未完了です。

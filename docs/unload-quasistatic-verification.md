# 無荷重へ戻る過程の準静的性：解析解と時間刻み・除荷速度の検証

[比較PNG](../exports/unload-quasistatic-verification-001/unload-sensitivity.png)・[全CSVと計算データZIP](../exports/unload-quasistatic-verification-001.zip)・[判定JSON](../exports/unload-quasistatic-verification-001/verification-summary.json)。

今回の対象は中実1 mm立方体の独立な弾性対照試験と、4 mm角・初期空隙率0.25%の連結セルである。球充填層の40%→10%圧密、塑性・接触後の除荷、メッシュ収束の完了を意味しない。

ソルバーの運動方程式・物性・接触・合否判定は変更していない。追加した検証ツールは、既存の全採用ステップCSVを読み、解析解との誤差と固定エネルギー尺度による補助診断を計算する。既存の不合格を合格へ置換しない。

## ゼロ荷重近傍で瞬間比が大きくなる理由

単一の弾性モードで剛性k、有効質量m、変位qなら、U=kq²/2、K=m q̇²/2、K/U=(m/k)(q̇/q)²。使用中の五次滑らか荷重は除荷完了時刻Tの近傍でp∝(T−t)³となる。準静的な変位をq∝pとすると、U∝(T−t)⁶、K∝(T−t)⁴で、瞬間比K/Uは(T−t)⁻²に比例する。絶対KEがゼロへ減っていても比率は大きくなり得る。

これは単一モードの説明であり、多孔質体の全モードや摩擦の検証を代替しない。既存実装では分母下限もあるため、数値的には有限のピークを持つ。補助指標はゼロ圧力の時刻も含めてK/Urefを計算し、別途解析解・時間刻み・速度依存を確認する。

## 独立な有限変形弾性解

E=10 MPa、ν=0.33、圧縮Cauchy真応力p≥0、横方向自由、塑性化なし。軸対数ひずみをe、a=1−2νとすると、

```
e_x = e_y = −ν e
J = exp(a e)
τ_z = E e = −p J
e = −W(a p/E)/a
軸圧縮 = 1−exp(e)
Uref(p) = V0 E e²/2
```

WはLambert W関数の主枝。材料のFEM内力・応力更新ルーチンを参照せず求めた静的解であり、動的解の解析式ではない。基準圧力0.02 MPa、V0=1 mm³では最大軸圧縮0.001996645432、Uref=1.997283694×10⁻⁵ N mm。材料応答との応力・エネルギー一致と、微小荷重でp/Eへ近づくこともテストした。

以下は全採用ステップの最大値。誤差は最大軸圧縮を分母にする。通常ケースの載荷8 ms・保持2 ms・回復保持2 ms、除荷時間のみを比較した。

| 1 mm立方体 | CFL | 除荷時間 | 全経路の軸誤差／基準最大ひずみ | 除荷中最大KE／Uref | 既存の後半KE／瞬間内部エネルギー |
|---|---:|---:|---:|---:|---:|
| 基準 | 0.2 | 8 ms | 0.008580% | 0.00033398% | 1.7726%（不合格） |
| 刻み半減 | 0.1 | 8 ms | 0.008580% | 0.00033398% | 1.7802%（不合格） |
| 除荷を遅く | 0.2 | 16 ms | 0.008580% | 0.00008349% | 0.4423% |

遅いケースの全経路誤差は共通の載荷区間が支配する。**除荷区間だけの誤差は0.008577%→0.004278%**へ減った。除荷区間最大KEは約1/4。通常3ケースの追加診断（固定尺度KE<1%、全経路ひずみ誤差<1%、復元F誤差<10⁻⁷、塑性なし）はすべて満たす。これらの数値閾値は開発上の検査で、材料の測定値ではない。

## 不適切な急速荷重を見逃さない対照

最初の2 μs載荷・2 μs除荷、CFL 0.2の試行は18ステップしかなく、指定ピーク圧力に届かず、エネルギー誤差3.50%で不合格だった。この試行は保存し、慣性の証拠には採用しない。

その原因を分けるため、同じ2 μs載荷・2 μs除荷にピーク保持1 μsを挿入し、CFL 0.02と0.01で再検証した。回復保持は10 μs。材質・密度・減衰は変更していない。指定圧力到達とエネルギー収支の合格を確認したうえで、急速荷重を棄却できるか調べた。

| 急速対照 | ステップ | エネルギー誤差 | 最大KE／Uref | 最大軸誤差／基準最大ひずみ |
|---|---:|---:|---:|---:|
| CFL 0.02 | 189 | 0.02438% | 21.5456% | 98.2672% |
| CFL 0.01 | 377 | 0.00949% | 21.5561% | 98.2662% |

両者とも釣合い・復元・準静的追従が不合格で、補助指標も不適切な荷重として棄却した。元の粗い試行も全データに保持する。固定尺度KEの導入が、すべてを合格にするだけの操作ではないことを確認した。

## 連結セルの比較条件

前回の0.02 MPa、8 ms載荷・2 ms保持・8 ms除荷・2 ms回復、CFL 0.2を基準として再利用する。新規にCFL 0.1、または除荷16 msだけを変更した2ケースを連続計算する。中間再始動は行わず、履歴を保持する。

密度1×10⁻⁹ tonne/mm³、減衰6,000/s、摩擦0.3、E=10 MPa、ν=0.33、降伏0.05 MPa・硬化0.2 MPaは従来の試験設定。E・ν・摩擦はユーザー指定値で、降伏・硬化・密度・減衰・時間・閾値は未校正の開発用設定である。追加診断の固定尺度は同一メッシュの初期弾性縮約剛性SからUref=fᵀS⁻¹f/2とする。fのzz成分は−pmax V0。これは固定尺度の定義で、連結形状の有限圧力経路の厳密解ではない。

比較は両ケースの全採用時刻（速度比較では除荷位相）の和集合で線形補間し、刻み比較は同じ物理時刻、速度比較は同じ除荷位相で行う。固定点数の抽出によるピークの見落しを避ける。極値・エネルギーは補間せず全採用ステップで評価する。事前の追加検査は、刻み半減の軸差／初期弾性最大圧縮<0.1%、除荷速度比較の位相軸差<1%、遅い除荷の最大KEが半分未満、全経路の固定尺度KE<1%とした。これらも既存ソルバーの判定とは別に保持する。

## 連結セルの結果

初期弾性の固定尺度はUref=0.001305119438 N mm、基準最大軸圧縮=0.002039249121。

| 条件 | ステップ | 除荷中最大KE／固定Uref | 既存の後半KE比 | 既存の総合判定 |
|---|---:|---:|---:|---|
| 前回基準 CFL 0.2、8 ms除荷 | 56,400 | 0.00399096% | 24.4533% | 不合格・診断用 |
| CFL 0.1、8 ms除荷 | 112,799 | 0.00399097% | 24.4745% | 不合格・診断用 |
| CFL 0.2、16 ms除荷 | 78,960 | 0.00099700% | 5.7124% | 不合格・診断用 |

刻み半減の最大軸差／基準最大圧縮は3.65×10⁻⁸、最大空隙率差1.18×10⁻¹²。同じ除荷位相での8 msと16 msの軸差は0.05143%、空隙率差1.63×10⁻⁸。除荷中最大KEの比は0.249815で、除荷を遅くすると約1/4になった。全経路の最大KEは共通の載荷区間が支配するため、除荷を遅くしただけでは変わらない。

新規2ケースは全予定区間を完了し、終点釣合い・体積・エネルギー等の既存検査に合格したが、低KE比の既存基準のみ不合格だった。終点の軸圧縮残りは刻み半減1.59×10⁻¹¹、遅い除荷2.58×10⁻¹²。全3ケースで接触は発生せず、摩擦履歴の検証ではない。

事前に定めた補助比較項目はすべて満たした。刻みを半分にしても既存の瞬間比の不合格は残り、単なる時間離散化誤差では説明できない。解析解への追従・速度依存・絶対KEの低下と併せて、無荷重へ戻るときの分母の影響を確認した。**補助指標単独で全過程の準静的性を認定せず、既存の総合判定は変更していない。**

急速対照の全採用時刻での刻み比較も実施し、軸差／解析解最大圧縮は4.285×10⁻⁵だった。急速荷重の約98%の追従誤差に対して小さく、時間刻みを十分細かくしても不適切な荷重として棄却される。

PNGを確認し、ZIPのCRC検査と全格納ファイルのSHA-256照合を実施した。既存基準の不合格、粗い急速対照のエネルギー不合格も含め、全データ・コード・監査CSVを保存する。

## 再現と適用限界

リポジトリルートで既存の環境Pythonを用い、`PYTHONPATH=.`、`OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1` とする。毎回新しい出力先を指定する。

```sh
python tools/verify_unload_quasistatic.py --output results/unload-controls-NEW
python tools/verify_unload_quasistatic.py --resolved-negative-controls --output results/unload-negative-NEW
python tools/verify_connected_pressure.py --pressure .02 --ramp-seconds .008 --unload-seconds .008 --recovery-seconds .002 --cfl .1 --output results/unload-fine-NEW
python tools/verify_connected_pressure.py --pressure .02 --ramp-seconds .008 --unload-seconds .016 --recovery-seconds .002 --cfl .2 --output results/unload-slow-NEW
python -m pytest tests/test_unload_reference.py tests/test_explicit_audit.py tests/test_explicit_backend.py tests/test_cauchy_unloading.py -q
```

関連テスト24件は合格。追試用CLI追加後も、解析式・監査の3テストを再実行して合格した。

固定された全体エネルギー尺度だけでは局所接触の慣性、全経路の力の釣合い、塑性除荷、接触履歴、表面再メッシュやメッシュ収束を保証できない。ソルバーの既存判定は今回変更せず、診断として公開する。次の段階では、塑性・接触後の除荷について力の釣合いと残留変形の速度・刻み依存を確認する必要がある。

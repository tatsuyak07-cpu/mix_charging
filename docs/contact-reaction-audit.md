# 摩擦履歴の保存と接触反力の独立勾配・組立監査

[比較PNG](../exports/contact-reaction-audit-001/contact-audit.png)・[反力監査CSV](../exports/contact-reaction-audit-001/reaction-audit.csv)・[全結果ZIP](../exports/contact-reaction-audit-001.zip)・[判定JSON](../exports/contact-reaction-audit-001/independent-audit/summary.json)。

対象は前回と同じ4 mm角・初期空隙率0.25%の連結セル。E=10 MPa、ν=0.33、摩擦0.3、試験用Kirchhoff降伏0.05 MPa・硬化0.2 MPa、密度1×10⁻⁹ tonne/mm³、減衰6,000/s、CFL 0.2を保持する。0.1 MPaまで32 ms、保持2 ms、除荷8 ms、無荷重保持2 msを連続計算する。物性・荷重・境界・メッシュ・接触則・合否基準を変えず、監査情報を追加する。

球充填層の40%→10%圧密ではない。降伏・硬化・密度・減衰・時間・監査閾値は開発用の未校正設定で、材料の測定値ではない。温度依存性なし、剛体円柱なし。

## 保存する2種類の状態

`--save-contact-audit` を指定した `area_guarded` 計算では、従来のNPZに加えて `run/contact-audit.json` を保存する。既定では無効で、他の接触バックエンドで有効化すると明示的に拒否する。

保存する情報は、確定した摩擦履歴と、最後に採用された反力評価の状態を分ける。接触ばねの塑性滑り、方向、付着点・重み、支持節点・周期像、局所座標、評価済みの節点反力と周期像による巨視成分を保存する。

既存実装は、反力を評価した後に摩擦ばねの向き・付着点を輸送し、エネルギーを保って履歴を確定する。そのため、確定後の履歴だけから更新前の反力を再構築することは適切ではない。評価時の固定された塑性滑り・方向・付着点も別に記録する。履歴をゼロへリセットしない。

接触評価は試行記録を作り、ソルバーが幾何を採用した時点でのみ確定記録を差し替える。未採用・拒否された試行は、採用済みの監査状態を上書きしない。これは診断用記録で、時間積分器・探索キャッシュ・全再始動状態を保存するチェックポイントではない。

## 独立に検査するもの

接触実装が使う複素数微分による摩擦内力関数を呼ばず、保存した固定履歴における接触ポテンシャルを実数の中央差分で微分する。法線の距離ポテンシャルと、材料とともに移動する接線フレームのエネルギーを別実装で計算し、各接触の9節点支持に対する27成分を評価する。差分幅は4×10⁻⁷ mmと2×10⁻⁷ mmの2段階。

記録された近接特徴集合を使うため、候補探索や接触の見落しを独立に証明する監査ではない。特徴が変わるところの一般的収束、辺のみの接触、複数パッチや表面再メッシュの検証でもない。

周期像による巨視反力は、各支持反力fと初期の像ベクトルRから `f_x R_x` 等の6成分を別に組み立てる。現在の変形した周期行列を、そのまま初期像ベクトルの代わりに使わない。

骨格材料の内力は、四面体の各節点に対向する面の外向き面積ベクトルAから `σ A/3` を積分する。これは既存ソルバーの体積勾配積分とは別の組立である。構成応力は既存の検証済み材料応答を使用する。接触内力と足し、全周期自由度に投影し、ソルバーが使用した反力・外力と比較する。巨視成分をセル長で割り、Nへ揃えて比較する。

追加検査は接触力の相対差2×10⁻⁵未満、全力の組立差は最大荷重尺度 `pmax L²` の10⁻⁷未満、無荷重の残差ノルムは同尺度の2%未満。既存のより厳しい終点釣合い判定も同時に維持する。ポテンシャルのエネルギー、ばね座標、構成則上のCoulomb比、確定履歴の件数も照合する。閾値は監査用の数値設定であり、材料条件を調整して合格させる操作ではない。

## 保存機能が力学を変えないことの検査

付着と滑りの平面接触で、監査の有効・無効による反力と周期像巨視成分が配列単位で一致することを検査した。確定履歴のJSON読戻しからの接触状態評価が元のオブジェクトと一致すること、未採用の次試行が採用済み記録を変えないことも検査した。滑り中の監査は、塑性滑りを固定した反力のエネルギー勾配を評価する。

別の中実立方体の陽解法FEMでは、保存有無で全採用ステップCSVが完全一致し、無効時には追加ファイルを作らないことを確認した。

最初の滑り試験は0.03 mmを一度に動かして既存の移動証明ガードに拒否された。ガードを緩めず、0.0001 mm以下の増分で同じ総滑り量を与えて再検証した。元の失敗ログと、記録された編集から復元した初期試験設定を保存する。

追加試験と既存の全試験は **169件合格、141.97 s**。実セルの全採用ステップCSVと全NPZ状態も前回の保存無効ケースと比較し、観測機能の追加で解が変わっていないかを検査する。

## 実セルの監査結果

142,355ステップ、全44 msを完了した。残留圧縮0.22071236817793713、残留空隙率0.0022172997859826182（0.2217299786%）は前回と一致し、既存の全検査に合格した。終点の接触2記録と確定履歴2件を保存した。

| 中央差分幅 | 接触反力の最大成分差 | 接触反力の相対差 | 材料＋接触の最大組立差 | 無荷重残差ノルム |
|---|---:|---:|---:|---:|
| 4×10⁻⁷ mm | 1.2051×10⁻¹⁰ N | 4.6845×10⁻⁹ | 1.2051×10⁻¹⁰ N | 1.6898×10⁻⁹ N |
| 2×10⁻⁷ mm | 2.4116×10⁻¹¹ N | 9.3747×10⁻¹⁰ | 2.4116×10⁻¹¹ N | 1.6777×10⁻⁹ N |

接触反力の相対差は、節点反力および像による巨視反力/Lの最大成分差を、対応する保存反力のL2尺度で割った値（分母下限10⁻¹² N）。2段階とも事前の閾値を満たした。既存ソルバーの終点釣合い比は0.002100833で、従来基準の2%未満も維持している。追加監査の残差規格化には初期最大荷重尺度1.6 Nを用いており、既存の無荷重時の小さい力尺度とは区別する。

記録を足し合わせた反力と保存反力の差はゼロ。独立なポテンシャルと履歴CSVの接触エネルギー差もゼロ。構成則上の終点Coulomb比は最大0.2333928815でμ=0.3以下。接触反力の合力・非折返し座標でのモーメントも検査閾値内だった。保存された局所反力から独立微分へ、さらに材料の面力積分を含む全力組立へと段階を分けて照合した。

全採用ステップCSVは初期状態を含む142,356行×11列の全数値を照合し、符号付きゼロも区別したIEEE配列のバイト列が完全一致した。最終NPZの位置、参照位置、要素接続、弾性b、PEEQ、参照体積、一般化位置・速度の8配列も形状・dtype・バイト列がすべて一致した。圧力や密度・減衰を変えず、観測の追加による影響がないことをこの経路で確認した。

初回の数値一致監査に加え、厳密なIEEEバイト列比較を追加して別の新規ディレクトリで再監査した。FEM自体は一度だけ再計算した。初回と最終の監査コード・判定を両方保存する。PNGを確認し、ZIP CRCおよび全格納ファイルのSHA-256を照合した。

## 再現

リポジトリルートで環境のPythonを使い、`PYTHONPATH=.`、`OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1` を設定する。結果先は毎回新規にする。

```sh
python tools/verify_connected_pressure.py --pressure .1 --ramp-seconds .032 --unload-seconds .008 --recovery-seconds .002 --cfl .2 --max-steps 300000 --save-contact-audit --output results/contact-capture-NEW
python tools/audit_contact_capture.py --input results/contact-capture-NEW --output results/contact-audit-NEW
python -m pytest -q
```

監査ツールは今回の `pinned` 質量フレームと前回の同条件の圧縮・除荷基準との比較に対応する。異なる質量フレームや別の圧力経路を今回の保存無効基準と同一条件と扱わない。

## 残る範囲

この監査は採用された接触特徴集合での反力・終点釣合いの検証であり、全時刻の独立反力監査、独立な接触探索、完全な再始動、接触一周期のCFL感度・メッシュ収束・一般接触・表面適応再メッシュ、材料校正は別途必要。球充填層の40%→10%圧密は未完了。

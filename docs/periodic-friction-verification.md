# 周期境界の内外判定・摩擦履歴の検証

## 今回の到達点

周期セルの切断面を接触面と誤認せず、実際の自由表面までの距離から法線接触を求める試験用処理を追加した。また、同じ接触領域と既知である場合の接線ばね履歴の移送とCoulomb摩擦を検証した。

**圧縮ソルバーへの組込みは未実施。** 独立した試験点を使った幾何学・摩擦演算子の検証であり、自己接触の隣接除外、接触領域の自動追跡、辺―辺交差、接触中の再メッシュ、準静的圧密の合格を示すものではない。実モデルの材料・粒径・初期空隙率・摩擦係数は変更していない。

## 周期境界の内外判定

開いたセル切断面の立体角和で内外を判定する方法は使用しない。現時点の四面体の各周期像に対する重心座標から固体内部を判定し、対応する反対側の三角形が存在するセル切断面を自由表面から除去する。そのうえで、面・辺・頂点を含む最近点を探索する。

像の範囲は現在のセル行列とメッシュの分数座標境界箱、探索距離から毎回計算する。729像を超えれば切り捨てずに停止する。固体内でも最近点が探索距離を超える場合は計算を停止する。探索距離は0.2 mm、独立試験点の法線剛性は100 N/mm。これらは検証用の数値であり、実モデルの物性や接触ペナルティを置き換える値ではない。

3 mm角のセル内で、周期境界をまたぐ1 mm幅の角柱を作った。試験点を境界の−0.08～0.08 mmの区間で移動させ、実際の横自由表面からの食込み0.04 mmを与えた。切断面の前後で法線力4 N、エネルギー0.08 N mmが一定となることを確認した。

- 境界方向x・y・z、メッシュ幅1 mm・0.5 mm、各41点、合計246点で合格した。
- 最大誤差は力6.94×10⁻¹⁵ N、エネルギー1.39×10⁻¹⁶ N mmだった。
- 単体試験では、整数周期分移した試験点、セルの切り方を変えた同一形状、せん断を含む変形セルでも確認した。
- 作用反作用、周期像の位置を含めたモーメント、試験点とセル行列の摂動に対する力・エネルギー差分の一致を確認した。
- 試験点を別の周期表現に移した場合は、試験点自身の巨視的仕事と相手の像の仕事を合わせて比較した。像の仕事だけは表現変更によって変わるため、単独の不変量とは扱わない。

この試験は周期的な体積メッシュを用いる独立点の検証である。既存メッシュの節点をそのまま試験点にすると自身の固体内に含まれるため、圧縮ソルバーへの導入には局所隣接の除外を別途組み合わせる必要がある。一般の自己交差メッシュや非整合な周期表面の修復は実装していない。

## 摩擦履歴とエネルギー

摩擦係数は指定通り0.3とした。試験用接線剛性50 N/mm、法線力2 Nの平面接触で、0.3 mm滑らせた。途中で最近点の三角形番号が変わるが、同じ接触領域のばねを引き継いだ。

| 項目 | 201点 | 401点 |
|---|---:|---:|
| 最終摩擦力 N | 0.6 | 0.6 |
| 最終ばねエネルギー N mm | 0.0036 | 0.0036 |
| 摩擦散逸 N mm | 0.1728 | 0.1728 |
| アルゴリズムの散逸 N mm | 0.00045 | 0.000225 |
| 後退Eulerで評価した仕事 N mm | 0.17685 | 0.176625 |

摩擦力はCoulomb上限を超えず、三角形の切替えでばねが消えることもなかった。連続系の解析的仕事0.1764 N mmに対し、離散的仕事の差は経路刻みを半分にすると半減した。

仕事の監査では、`仕事 = ばねエネルギーの増分 + 摩擦散逸 + アルゴリズムの散逸` を使用した。最後の項は後退Eulerの離散化に由来し、物理的な摩擦散逸に混ぜていない。平面試験の全経路の収支誤差は約8.1×10⁻¹⁷ N mm以下だった。

法線を90°回転させながら滑らせる既知の接触領域でも、Coulomb上限、散逸の非負性と仕事の収支を確認した。収支誤差は約7.0×10⁻¹⁶ N mmだった。法線方向の変化だけからは法線軸回りの材料回転を復元できないため、材料回転が必要な場合は正しい回転行列を外部から与えるインターフェースとした。その入力で剛体回転に対する客観性を単体試験した。反対向きの法線への回転が曖昧な場合は、自動処理せず明示的な回転を要求する。

**接触領域が同一かどうかは試験で与えている。** 離れた接触領域への履歴の誤転送を防ぐ自動識別、離接触時の履歴の扱い、有限滑りで材料回転を求める処理は今後の課題である。今回の経路は変位と法線を直接与える演算子試験であり、時間刻み・載荷速度に関する陽解法の準静的検証ではない。

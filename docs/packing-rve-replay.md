# 周期変位移行修正後の全履歴再検証

前回の周期変位移行修正を含むコミット `02b247a` で、初期形状から計算し直した。**移行誤差による停止は再発しなかったが、表面分割の上限16回で停止した。0.1 MPaの平衡解や40%→10%圧密の結果ではない。**

## 条件と判定

前回と同じ小周期BCCセル（球径10 mm、ネック径2 mm、セル長12.1 mm、初期空隙率39.84375%）を使用した。E=10 MPa、ν=0.33、試験J2降伏応力0.05 MPa、硬化係数0.2 MPa、摩擦係数0.3。100 mm角の統計的な等方充填層の代替として検証済みではない。

0.1 MPaまで4 msで載荷、2 ms保持する診断用条件であり、準静的な載荷速度の検証用ではない。前回設定と今回設定のSHA-256はともに `712900cedc2006040f7d9a1e9e1523d11cec8bc738c9767b3316f63ff6d2bbad`。品質下限0.03、移行監査許容値0.001、CFL 0.2、分割上限16回などは変更していない。実行ソースの差は `explicit_periodic.py` と `explicit_solver.py` の周期変位移行修正である。

## 停止の解釈と次の工程

最初の38出力行は前回と完全一致した。その後の接触・分割の履歴には差が生じ、前回10回だった採用分割は今回16回となった。丸め誤差に対する接触枝の感度は、今後の単独試験で切り分ける必要がある。分割の多くがほぼ同じ時刻に集中しており、実用上の進展は得られていない。前回より先の物理状態を得たとは判断しない。

次の17回目に相当する分割案を、保存状態で**形状だけ**検査した。最小品質は0.08344から0.05237へ低下し、周期位置の復元誤差は1.78×10⁻¹⁵ mmだった。この案は時間積分に採用しておらず、接触履歴・エネルギー移行の監査も未実施である。品質不足が今回の直接の停止原因だったとはいえない。

次は、ほぼ同時刻の連続分割と接触枝の感度を単独試験で再現し、辺分割の選択・終了条件と、履歴を保持する局所品質回復を検証する。その後に圧力履歴を再実行し、載荷速度・刻み・メッシュの比較を行う。分割上限を増やすだけで準静的圧密の成功とは判定しない。

## 再現と保存

既存環境を使用し、追加の依存導入や環境設定変更は行っていない。実行時ソース、ネイティブカーネルのハッシュ、初期・停止時メッシュ、全採用ステップCSV、接触監査、16回の分割案、失敗判定をZIPに保存した。前回データは保持している。

```bash
export PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
PY=/workspace/environment/mix_charging/.venv/bin/python
$PY -m tools.run_packing_rve \
  --config exports/packing-rve-replay-001/validation/config.json \
  --native-library LIBRARY_PATH --output results/new-replay
$PY -m pytest tests/test_packing_rve.py tests/test_closest_tie.py tests/test_surface_development.py -q
```

`LIBRARY_PATH` は既存の `tools.build_native_kernel` で計算外にビルドしたライブラリを指定する。出力先は毎回新しいディレクトリにする。

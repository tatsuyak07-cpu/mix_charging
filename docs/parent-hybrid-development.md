# 親面監査と保存則付き積分重み再配分

2026-11-01。到達目標は載荷・平衡状態の空隙率40%→10%。今回は、子面ごとの面積一致を強制する方式から、**元の材料親面全体で積分精度を監査する方式**へ拡張した。精度不足の場合には既存積分点の正の重みを保存則付きで再配分する。圧密完走の報告ではない。

## 実装

- `parent_quadrature.py` は元の3頂点を材料親面IDとして保持する。子面が親面を重複・欠落なく覆うことと、積分重みの総和が親面積に一致することを検査する。子面個々の重み総和と子面積は一致しなくてよい。
- 独立した適応参照積分で、法線エネルギーと**分割後の全節点の反力**を監査する。接触する相手側の新節点と周期像も含む。合力・エネルギーだけが一致する誤った積分則は拒否する。
- `conservative_quadrature.py` は既存点の位置を固定して重みだけを変更する。全ての旧周期自由度に対する接触仮想仕事、法線エネルギー、確定・力評価用の摩擦エネルギー、実際の接線ポテンシャル、親面の面積と2次までの材料座標モーメントを制約とする。保持した過去姿勢・制御姿勢の法線応答も制約する。
- 摩擦ばね・塑性滑り・方向・材料アンカーの物理位置を引き継ぐ。新しい摩擦履歴をゼロで作らない。重み変更に応じて各点の保存エネルギーを変更し、全体のエネルギーを再検査する。
- 速度移行には既存の運動量・角運動量・運動エネルギー保存射影を使う。失敗時には提案全体を棄却し、旧状態を変更しない。
- `explicit_solver.py` に明示的な設定を追加した。従来の既定モードは維持する。親面メタデータはチェックポイントへ保存される。接触前の認証済み状態からのみ演算子更新を許す。分割後の面IDを分割前状態へ適用する巻き戻しは拒否する。

```json
{
  "surface_audit_mode": "parent",
  "surface_error_budget": "normalized",
  "surface_redistribution": "conservative",
  "surface_redistribution_factor": 2.0,
  "surface_velocity_transfer": "momentum_energy",
  "active_embedded_surface_remesh": true
}
```

## 数値上の選択と検証

単位は mm、N、MPa、tonne、s。材料・摩擦・周期条件は変更していない。小規模BCCセルは一辺12.1 mm、粒径10 mm、ネック径2 mm、初期空隙率39.84375%、E=10 MPa、ν=0.33、Hencky J2塑性、降伏0.05 MPa、硬化0.2 MPa、μ=0.3。これらは既存の試験モデルであり、焼結鉱の同定済み物性ではない。

重みは元の0.5～2倍の範囲に制限し、面積重み付きL1変化を最小化する。保存行列のSVD零空間で解き、特異値の相対しきい値は1e-12、保存制約の独立再検査は1e-9、実際の力・エネルギー移行は1e-8を上限とする。積分精度制約には許容誤差の半分を使い、後段の丸め誤差の余裕を確保する。一般の大規模問題には行列サイズ上限がある。

初期の冗長な等式をそのまま解くLPは、小さな係数の処理により偽の実行不能判定を生じた。零空間化で改善したが、実接線ポテンシャルの制約を追加したCFL=0.2ではHiGHSの自動法が `Status 0: Not Set` を返した。同じ行列を内点法 `highs-ipm` で解き、独立監査を通過することを確認したため内点法を明示する。失敗した実行・診断行列・ログも保存する。重み上限や物理条件を緩めて通過させていない。

最終の動く平面接触では、CFL=0.2、0.1、0.05で面積重み付き変更量はそれぞれ0.52148264%、0.52148264%、0.52149238%。再配分前後の仕事誤差は9.68e-16以下、法線・接線エネルギー誤差は5.07e-16以下だった。これは移行操作の保存性であり、圧密応答の時間刻み収束を示すものではない。

固定配置の合格は相対誤差と絶対予算の混合判定である。非常に弱い初期接触では相対反力誤差が約61%、エネルギー誤差が約69%の親面もある。絶対力誤差の超過合計は約1.18e-8 Nで、最小予算6.25e-8 Nの半分以内に収まる。**相対0.1%で全反力が収束したという意味ではない**。

実時間発展では分割直前68履歴を引き継ぎ、監査された接触力移行誤差は約5.35e-11。質量・運動量・角運動量・運動エネルギー・材料/接触エネルギー・Coulomb境界が合格した。90262刻みの空隙率は36.94169748%だが、載荷途中の過渡値であり平衡解ではない。次の評価で親面3166の相対反力誤差約2.10%、絶対力超過1.34e-7 Nとなり停止した。積分誤差を隠して継続していない。分割による最悪要素品質の改善も認められない。

## 未完了と次の開発

現在の再配分は**再メッシュ移行時に限定**する。時間発展中に親面精度が不足した場合の保存再配分は停止診断まで。新しい点の追加・移動、未登録面の節点積分の分割、複数回の親面再メッシュ、保持済み分割パーティションの再切断は未対応で明示的に拒否する。従来の10辺のうち、未登録隣接面を含む8辺は引き続き対象外。

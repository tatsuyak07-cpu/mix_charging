# 接近する両側の辺の選択と、棄却試行の再実行

接近する2本の辺の最短位置を分割候補とし、品質と状態移行の監査を通過した候補だけを採用する処理を、圧縮ソルバーの試行棄却・再試行に接続した。小さな移動接触試験では、実際の接触ガード、分割、時間積分の継続を確認した。**これは0.1 MPaの準静的な圧密解を検証したものではない。**

[比較画像](../exports/closest-selection-001/selection-comparison.png)、[停止時メッシュ](../exports/closest-selection-001/stopped-mesh.png)、[候補イベントCSV](../exports/closest-selection-001/candidate-events.csv)、[判定JSON](../exports/closest-selection-001/summary.json)、[全データZIP](../exports/closest-selection-001.zip)。前段は[非中点分割の状態移行検証](weighted-surface-transfer.md)。

## 選択と採用の条件

`surface_remesh_strategy="closest_quality"` を明示した場合だけ新しい選択を使う。既定値は従来の `midpoint` である。

接触ガードが検出した棄却試行の辺対から最短位置のパラメータを求め、両側について直前の**採用状態**の分割案を作る。採用状態の最小四面体品質が高い順に候補を並べる。端点そのものになる候補や不正な幾何は拒否し、最小品質が既存下限を下回る候補は採用しない。パラメータを端点から離すために丸めたり、下限を緩めたりしていない。

候補ごとに周期位置、参照体積、材料状態、質量・運動量、速度の周期射影、材料・接触エネルギー、摩擦履歴、巨視的接触力、Coulomb上限を確認する。最初の候補が監査で不合格なら反対側を試す。すべて不合格なら既存の採用状態を保持して停止する。

分割後の力・加速度・接触状態の計算まで成功してから、計算状態を置き換える。棄却した試行の塑性状態や位置は取り込まず、同じ採用時刻から刻みを再評価して試行をやり直す。イベント数の上限も既存値を守る。提案NPZには補間重みを保存する。

既存の空隙幾何証明用の拡張写像は中点分割に限定される。これを持つ場合の非中点候補は、未対応として拒否する。証明を外して通過させる処理は追加していない。

## 小さな移動接触試験

2個の四面体の辺同士を交差する向きに配置し、初期間隔0.0200005 mmから片側へ初速度−1 mm/sを与えた。接触厚さ0.02 mmに入ると、節点による接触積分で捉えられない辺対のガードが実際に作動する。このガードを分割と再試行で解消し、3 µsまで時間を進めた。

初速度が駆動する試験である。指令圧力は数値上の微小値10⁻¹² MPaで、圧力で圧密する試験ではない。離れた位置の周期フレームで周期セルの巨視的自由度を支持する。初回はフレームを持たない2物体だけのモデルで巨視的・微視的自由度が冗長になり、セル反転で停止した。初回には診断JSONのNumPy真偽値変換にも不備があり修正した。初回の計算出力と例外ログも保持している。

実際の辺ガード、修復、修復後の時刻進行、試験履歴の完了、移行監査、接触の発生、人工的な辺ばねを使わないこと、Coulomb上限の8項目が合格した。準静的釣合いはこの試験の合格条件ではない。

## 回帰・拒否・フォールバックの検証

関連14テストが合格した。新規の5件は以下を検証する。

- 保存した大変形状態で、品質の高い相手側の辺が優先され、入力配列が変化しない。
- 実際の辺ガードで分割・再試行が起こり、試験の全時間を完了する。補間重みも保存される。
- 最初の監査を意図的に拒否すると反対側が監査され、採用後に時間積分が継続する。
- 両候補の監査を意図的に拒否すると、分割上限0の対照と停止時の全状態配列が完全一致する。
- 未知の選択戦略を設定すると入力検査で拒否する。

監査拒否の注入はテストだけで使用し、実際の計算では行っていない。

全体267テストも合格し、失敗・skipはない。事前ビルド済みライブラリを指定し、ネイティブ要素カーネルのテストも実行した。

## 小周期BCCセルの全初期状態からの再計算

前回と同じ小周期BCCセルを初期状態から計算し直した。設定差は `surface_remesh_strategy="closest_quality"` の追加だけである。球径10 mm、ネック径2 mm、E=10 MPa、μ=0.3、試験塑性材料、荷重履歴、CFL、品質下限0.03、移行許容値0.001、分割上限16回は前回のままとした。100 mm角の統計的な等方充填層を検証したものではない。

0.1 MPaまで4 msで載荷し2 ms保持する予定の**短時間載荷の診断**で、準静的な平衡解を求める条件として検証済みではない。

## 次の停止原因

分割後の区間で、移動中の表面の非交差を確かめる `Linear-step separation certificate` が刻み縮小を要求した。接触の再試行6,240回はすべてこの理由であり、4回の分割再試行と合わせて6,244回となった。最終的には次の刻みが既存下限10⁻¹⁴ sを下回り、`Stable timestep below budget` で自然停止した。下限を変更したり、計算を手動中断したりしていない。

最後の棄却試行を、保存した一般化位置・速度・力・摩擦履歴から再構成した。最初の診断では採用済みの幾何状態と最小離隔を復元しておらず、この幾何チェックを再現できなかった。これらも復元した診断では、同じ採用時刻・同じ拒否理由を再現した。再現できなかった診断も保存している。

採用状態の最小離隔は約2.9863×10⁻¹⁰ mmで、ほぼゼロである。保存近傍候補の最短辺対は節点[175,384]と[385,401]、周期シフト[0,0,0]で、この距離を再現した。品質不足や分割上限が今回の直接の停止原因ではない。

この候補では局所材料近傍による力の除外は偽、表面方向微分によるスクリーニングは `dominated=true`、端点401は別途接触履歴を持つ。方向微分の星近傍を列挙できたことは、表面全体の非交差を証明するものではない。ほぼゼロの離隔での微分判定の数値感度と、辺対を節点接触で捉えられているかは、次の検証で切り分ける必要がある。

次はこの辺対の表面近傍・接触積分・幾何チェックの整合性を検証する。単に刻み下限を下げたり、非交差確認を外したりする対処は行っていない。一般の辺接触の力積分・品質回復・接触積分の収束、0.1 MPaの準静的解、空隙率40%→10%圧密は未完了である。

## 再現

既存のPython環境と事前ビルド済みネイティブ要素カーネルを使用する。インストールや環境設定変更は行っていない。出力先は毎回新しくする。

```bash
export PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
PY=/workspace/environment/mix_charging/.venv/bin/python
$PY -m tools.verify_closest_retry --output results/new-crossed-retry
$PY -m tools.run_packing_rve \
  --config exports/closest-selection-001/validation/config.json \
  --native-library LIBRARY_PATH --output results/new-closest-pressure
$PY -m tools.diagnose_last_contact_retry \
  --source exports/closest-selection-001/validation/pressure-run/calculation \
  --output results/new-contact-stop-diagnosis
$PY -m pytest tests/test_closest_selection.py tests/test_weighted_surface_transfer.py -q
```

`LIBRARY_PATH` は既存の `tools.build_native_kernel` を計算外で実行して得たライブラリを指定する。ZIPには設定差、初回失敗、試験結果、圧縮途中履歴、分割案、移行監査、実行時ソースを含む。

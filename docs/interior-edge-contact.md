# 辺―辺の反力・摩擦とソルバー結合

## 今回の変更

前回は辺の交差を検出すると停止していた。今回、**非平行な辺の内部同士の接触**に限り、法線反力と摩擦を実装した。`contact_backend: tracked_edges` で明示的に選択でき、従来の `tracked_guarded` と `legacy` は保持した。

単独の辺の力・仕事・モーメントを検証し、スリット試験で2組の辺の反力が実際に有効になることを確認した。ただし、次の節点―面への切替えで停止する。**一般的な圧密への適用は依然として未合格で、初期空隙率40%→10%や荷重0.1 MPaの実充填体の解は得られていない。**

## 法線反力と摩擦

移動中の交差時点で、接触する2辺の内部パラメータと、交差前の側を保存する。現在の辺の外積から法線を求め、初期の側と整合する符号付きギャップgを用いる。g<0で法線エネルギーは `kn*g²/2`。辺の最近点が内部に存在する範囲だけを扱い、端点への移行、平行化、初期の側が曖昧な場合は停止する。

摩擦係数は指定どおり0.3。接触開始時の材料点を基準に、辺の方向に従って回転する局所座標で接線ばねと塑性滑りを保持する。局所接線トラクション `kt*|spring|` が `μ*fn` を超えればCoulombリターンを行う。この上限は局所トラクションに適用しており、回転による節点力の全成分の大きさを直接制限する条件ではない。

接線力を異なる空間位置の端点へ単純に配ると、食込みと摩擦に応じた余分なモーメントが生じる。そのため、塑性滑りを固定した接触ポテンシャルの全微分を複素ステップ法で求め、接触座標系が回転する項も節点力に含めた。法線力だけでなく摩擦が有効な場合にも、作用反作用とモーメント、剛体回転に対する客観性を確認した。

接線仕事は前段のソルバーと同じく台形則で評価し、摩擦散逸と符号付きの数値補正を分けて記録する。数値補正を物理的な摩擦散逸とは呼ばない。最初に接触を検出したステップの一部だけが有効となる時間積分について、一般的な精度が保証されたわけではない。

## 単独の辺の検証

2 mm長の直交する2辺について、食込みを0→0.01 mm、接線相対変位を0→0.02 mmとした。kn=10 N/mm、kt=5 N/mm、μ=0.3は検証用の数値で、実材料の変更ではない。

| 項目 | 100分割 | 200分割 |
|---|---:|---:|
| 全仕事 N mm | 0.0008 | 0.0008 |
| 解析的な全仕事 N mm | 0.0008 | 0.0008 |
| 最終弾性エネルギー N mm | 0.00059 | 0.00059 |
| 摩擦散逸 N mm | 0.0002121 | 0.00021105 |
| 数値補正 N mm | −0.0000021 | −0.00000105 |

台形則の仕事とエネルギー・摩擦・補正の収支誤差は約1.8×10⁻¹⁹ N mm以下。作用反作用の誤差は約1.4×10⁻¹⁷ N以下、モーメントの誤差は約2.6×10⁻¹⁷ N mm以下だった。

追加した4件の単体試験では、摩擦がある場合を含む全12自由度の力と、独立した中央差分のポテンシャル勾配の一致、剛体回転・並進、周期像の移動に相当する2端点の並進と仕事、Coulomb上限、散逸の非負性、離接触、未対応の端点・平行化の拒否を確認した。全ソフトウェアテストは93件合格した。

## ソルバーへ組み込む際の数値的選択

辺のペナルティは、4端点の初期表面分担面積の和の1/8に既存の接触ペナルティを掛けて求める。接線剛性は法線剛性の1/2とした。これは開発上の積分重みで、メッシュ収束や粒子表面の正確な面積積分として検証した値ではない。`edge_penalty_scale` で辺の数値剛性だけを変更でき、感度試験では1と2を比較した。材料剛性・摩擦係数・元の形状は変えていない。

時間刻みのばね制限には、前の受理状態で有効な辺の剛性を追加する。ただし、回転する座標系による幾何学剛性の厳密な固有値上限ではない。新しく発生する多数の接触や強い変形での安定性は、時間刻み・ペナルティ・メッシュ依存性の検証が必要である。

## スリット試験の結果

元のスリット入力について、標準刻み・半分刻み・辺ペナルティ2倍を実行した。初期の時刻0での内部再接続は従来と同じ条件のまま有効とした。

| 条件 | 最大の辺接触数 | 最後の受理時刻 μs | 最大食込み mm |
|---|---:|---:|---:|
| 標準 | 2 | 9.46357159 | 0.000101659 |
| 半分刻み | 2 | 9.46357079 | 0.000101911 |
| 辺ペナルティ2倍 | 2 | 9.46357159 | 0.000101659 |

以前は約9.448787 μsの受理状態から次に進めなかった。新しい処理では辺の反力が発生し、その後のステップで同じ接触が節点―面としても検出された。このとき両方の反力を足すと、別の積分重みに基づく接触を重複して数えるため、**エネルギー整合性のある切替えが未実装として停止した。** 最後の受理状態だけを解の候補として保存し、未受理状態を解として出力していない。

受理できた辺接触の区間は非常に短い。標準刻みで反力が有効になったのは1ステップだけであり、半分刻みやペナルティ2倍との比較は、反力発生と停止条件の確認にとどまる。これらの値が近いことをもって収束や感度検証の合格とはしない。

また、前回完了した空孔内の先端衝突試験を新バックエンドでも実行した。節点接触が有効な経路を完了し、エネルギー誤差2%以内を満たした。この回帰試験でも準静的条件の合格は主張しない。

## 残る開発

次は辺接触から節点―面接触へ移る際に、接触領域を1つとして対応づけ、法線ポテンシャル、接線ばね、塑性滑り、力と仕事を移す処理が必要である。単に片方の力を捨てたり、失われた法線エネルギーを散逸として帳尻合わせする方式は採用していない。

辺の端点・頂点への移行、ほぼ平行な辺、最初の材料点に基づく接線座標の大滑り時の更新も未解決である。これらを含む切替え、長い接触経路、動的再メッシュ、全経路のエネルギー監査と準静的条件、メッシュ・載荷速度依存性を順に確認してから実充填体へ適用する。

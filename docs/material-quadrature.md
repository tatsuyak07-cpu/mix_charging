# 摩擦履歴と接触積分を保持する再メッシュ処理

**再メッシュで幾何節点が増えても、接触積分点の参照面積と摩擦履歴を自動的に増減させない `material` モードを実装した。** 過去に拒否された提案で、約49.9%あった法線接触エネルギーの変化は0となり、従来の10項目の移行監査を通過した。固着・滑りの別試験でも、力・エネルギー・履歴の保存を確認した。

[エネルギー比較図](../exports/material-quadrature-001/energy-conservation.png)、[積分点と幾何節点の図](../exports/material-quadrature-001/material-points.png)、[比較CSV](../exports/material-quadrature-001/energy-comparison.csv)、[判定JSON](../exports/material-quadrature-001/summary.json)、[全データZIP](../exports/material-quadrature-001.zip)。

ただし、これは**再メッシュ時の積分の保持**であり、接触積分点の適応追加・積分精度の収束を完成したものではない。圧縮試験は積分点不足を明示して停止し、0.1 MPaの平衡解は得ていない。

## 変更した仕組み

従来の `nodal` モードでは、再分割した表面の節点ごとに参照面積を再配分し、新節点も接触積分に使っていた。節点を増やすと接触ポテンシャルの評価位置と重みも変わり、新節点の過去のすべりを補間できない場合があった。

新しい `material` モードでは、既存の積分点を保持された材料節点として識別し、参照面積の重みをそのまま保持する。新しい幾何節点の積分重みは0とする。追加節点も、相手面の形状関数を通じて接触反力を受ける。積分点としての役割と有限要素の幾何・変位自由度を区別した。

既存積分点の塑性接線オフセット・弾性すべり・接線基準・接触パッチの履歴を保持し、平均化やゼロ初期化を行わない。摩擦アンカーは同じ参照材料位置を含む子三角形へ表現し直す。参照位置と現在位置の両方が変わらないことを確認し、表現できない場合は拒否する。

今回の対応範囲は、元の節点を保持する周期的な辺分割である。節点削除、一般の再生成、ALE、パッチの生成・消失・分岐を任意に扱う処理ではない。材料点の対応がない場合や履歴が一意に対応しない場合は引き続き停止する。

## 摩擦の確定履歴と、力評価に使った状態

既存の摩擦則は、ステップ内で接線基準や材料アンカーを更新する。そのため、ステップ末の確定履歴を同じ形状で再評価した力と、直前のステップで実際に適用した力は、一般に同じではない。確定履歴だけを移して再計算すると、この差を再メッシュによる力の変化として持ち込んでしまう。

今回、確定履歴と、実際の力評価に用いた状態を別々に保存・移行するようにした。`replay_force_state` は、確定履歴を進めずに直前の力評価を再現する。監査と再メッシュ直後の力にはこちらを用い、次の力学ステップには保持した確定履歴を用いる。摩擦則やCoulomb上限を変更したものではない。

保存する接触JSONには `committed_history` と `applied_force_history` を含めた。積分重みは `contact-quadrature.npz` に保存する。これらは診断用の状態保存であり、全ソルバーの再開機能を完成したという意味ではない。

## 固着・滑りと力の保存

周期的な平面接触で、接線変位0.0001 mmと0.01 mm、分割位置0.2・0.5・0.8の6条件を検証した。前者は固着、後者は滑りを含む、変位を指定した接触単体試験である。圧縮平衡試験ではない。

全条件で以下を確認した。

- 元の積分点の重みと履歴キーを保持し、新節点に未知の履歴を作らない。
- 法線ポテンシャルと接線弾性エネルギーを保持し、均一平面の解析的なエネルギーとも一致する。
- 子要素の形状関数で配分した反力を元の有限要素空間へ戻すと、元の接触力・仮想仕事と一致する。
- 塑性接線オフセットを保持し、Coulomb上限μ=0.3を満たす。

さらに、非一様な弾性すべりを平均化せず保持すること、次の滑りステップで摩擦仕事・反力・エネルギーが一致すること、剛体回転・並進、連続3回の再分割、保存・再読込を確認した。履歴と力評価状態の分離をしなかった初期実装では、エネルギーが一致しても巨視的接触力の監査に失敗したため、力評価状態も移行する実装へ修正した。

最終の全体300テストは合格し、ネイティブ要素計算のテストも実行した。失敗・skipはない。新方式と接触記録の関連17テスト、6条件の単独検証も合格した。初期実装の6件の不合格と、テスト用自由度数の取得誤りによる初回全体テストの1件の失敗も、ログを保持している。

## 圧縮ソルバーへの接続と残る制約

`contact_quadrature_mode="material"` を指定すると、圧縮ソルバーの移行監査・力の再評価・接触CFLの面積評価・状態保存にも新方式が使われる。従来の `nodal` モードは互換用に保持した。新設定は [packing-rve-material-quadrature.json](../configs/packing-rve-material-quadrature.json) に保存した。

0.1 MPaを目標に初期状態から圧縮したが、約0.0509275 MPaで辺対の接近を固定積分点では解像できず停止した。幾何節点を増やすだけでは固定した積分点は増えないため、`Material contact integration unresolved; integration refinement required` として明示的に停止する。履歴をゼロで生成したり、重みを変えて進めたりしていない。

既存の材料積分点が初めて接触する通常の履歴初期化は維持している。一方、計算途中で積分点そのものを増やすには、接触領域の積分精度と過去のすべりを別途管理する適応積分が必要である。今回の変更で、体積メッシュの変更と接触積分点の生成を分離し、問題を保存性と解像度に切り分けた。

したがって、0.1 MPaの準静的な完走、一般の接触パッチ変更、積分点の適応追加、メッシュ収束、空隙率40%→10%の圧密は未完了である。停止時の空隙率を平衡圧密の結果として使っていない。

## 再現

既存環境を用い、依存関係やコンパイラの変更は行っていない。単位はmm、N、MPa、tonne、s。出力先は毎回新しくする。

```bash
export PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
PY=/workspace/environment/mix_charging/.venv/bin/python
$PY -m tools.verify_material_quadrature --output results/new-material-contact-test
$PY -m tools.audit_rve_remesh_proposal \
  --source exports/compaction-stages-001/validation/resolved-rapid-run/calculation \
  --material-quadrature --output results/new-material-transfer-audit
$PY -m tools.run_packing_rve --config configs/packing-rve-material-quadrature.json \
  --native-library LIBRARY_PATH --output results/new-material-pressure
```

`LIBRARY_PATH` は既存の `tools.build_native_kernel` を計算外で実行して得たライブラリを指定する。ZIPには入力状態、拒否提案、新旧の履歴と重み、力評価状態、比較CSV、圧縮停止結果、ソース、失敗を含むテストログを保存した。

次段階の[履歴再生・狭い接触領域の積分検証](integration-replay.md)では、規定された平面運動の12条件と既知形状の帯の18条件を確認した。圧縮ソルバーへの適応積分の接続は未実装である。

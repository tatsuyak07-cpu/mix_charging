# 温度依存性のない、永久変形が残る試験モデル

高温焼結鉱の変形を冷間モデルで模擬するための、有限変形・弾塑性の初期実装。
ユーザー指定は「粘土のような変形、永久変形あり、温度効果なし」。
材料データは未指定なので、以下の降伏・硬化は開発者が置いた試験値であり、焼結鉱や粘土の実測物性ではない。

## 材料と形状

| 項目 | 値・モデル | 根拠 |
|---|---|---|
| 初期ヤング率 | 10 MPa | ユーザー指定 |
| ポアソン比 | 0.33 | ユーザー指定 |
| 初期降伏応力 | 0.05 MPa | 仮の試験値 |
| 塑性硬化係数 H | 0.2 MPa | 仮の試験値 |
| 硬化曲線 | σy = 0.05 + 0.2 × 相当塑性ひずみ | 開発者の初期近似 |
| 塑性モデル | von Mises、等方硬化、有限変形 | 圧縮・除荷の基本機能を検証するため |
| 温度・時間依存性 | なし | 冷間の率非依存モデル |
| 球・ネック | 直径10 mm・直径2 mm、同じ材料の連続体 | 既存仕様 |

本実装は圧力非依存・ほぼ等容の塑性流動を持つJ2モデル。
土質のModified Cam-Clayや圧力依存のキャップモデルを実装したものではない。
見かけの圧密は明示的な空隙の変形から求め、骨格材料そのものの塑性体積圧縮とは区別する。
粘性・クリープ・亀裂・圧壊・ネック破断は未実装。

## 有限変形と荷重・除荷

CalculiXの `*STEP,NLGEOM` と、等方弾性＋ `*PLASTIC,HARDENING=ISOTROPIC` を使用。
ローカル参照資料はCalculiX 2.11の `*PLASTIC` 説明
（`/workspace/environment/calculix/usr/share/doc/calculix-ccx-doc/ccx/node274.html`）。
同資料では等方弾性に対して大ひずみの増分塑性理論が適用される旨を明記している。
実際の動作はインストール済みCalculiX 2.20で検証した。

周期変位差は `u(X+L)-u(X)=(F-I)L`。巨視変形Fを対称として全体の回転を固定し、
要素・局所構造の回転は有限変形として扱う。対称Fの6変数を使用し、軸変位以外は自由。
一節点で並進の基準を固定する。既存の線形解析経路は保持し、専用コマンドへ分離。

1. 軸方向の圧縮変位を段階的に与える。初期試験はセル長の1%。
2. 軸変位拘束を解除し、一般化軸荷重ゼロへ除荷する。変位ゼロへ戻す試験ではない。
3. 全ステップで変位・Cauchy応力・相当塑性ひずみPEEQを出力する。
4. 変形要素の8点体積積分とdet(F)によるセル体積から空隙率を求める。
   平均Cauchy応力も変形後の体積で重み付けする。

時間軸は静解析のステップパラメータで、物理的な時間ではない。
マクロ節点のRFはMPCによる力を完全に含まないため、荷重評価に使用していない。

## 現在の適用範囲

**これは圧縮・除荷で塑性変形が残ることを確認する初期モデルであり、0.1 MPaまでの圧密モデルの完成版ではない。**
`target_mpa=0.1` は目標値の記録で、現在の変位制御試験では到達を強制しない。
新たに接近する骨格表面間の自己接触と、周期境界を越える接触は未実装。
出力は必ず未校正・接触未検証を含む状態名とし、物理的な採用済み解と表示しない。
接触を含まない大圧縮の空隙率を実験予測として使用してはならない。

100 mm角の設定は `configs/plastic-trial.json`。動作検証用の30 mm角設定は
`configs/plastic-smoke.json`。30 mm試験の初期空隙率は58.6185%で、
100 mm角の60%目標と区別する。ネック2セル幅のメッシュ収束は未検証。

## 実行と出力

```bash
python -m packing_fem.plastic --config configs/plastic-smoke.json --output results/plastic-test-new --timeout 600
# 100 mm角の入力設定を使う場合（接触を含まない未校正試験）
python -m packing_fem.plastic --config configs/plastic-trial.json --output results/plastic-100mm-new --allow-large --timeout 1800
python -m pytest -q
```

同じ出力先は再使用できない。ソルバー未完了や出力不足、負のJacobian等は診断用。
入力 `plastic.inp`、元のログ・DAT・STA、`plastic-history.csv/.png`、
`plastic-summary.json`、最終受理フレーム `plastic-last-frame.vtu` を保存する。
未完了の場合、最終フレームは除荷後の解を意味しない。

## 基礎検証

24件のテストが合格（従来20件＋非線形4件）。
均質な周期立方体で、弾性域のEによる応力、塑性域の単軸硬化曲線、
除荷後の平均応力ゼロ、塑性域でのみ残留変形が生じることを検証した。
圧縮3%の材料ブロック試験では最大応力約0.05496 MPa、相当塑性ひずみ約0.02481、
除荷後の軸残留ひずみ約0.02465、平均応力は約1e-16 MPaとなった。

初回の手動材料試験 `results/plastic-material-001` は後処理のnumpy boolのJSON変換で失敗し、
出力を保持。修正後の002で再計算した。最初のテストでは、理論的に空隙ゼロの均質体に
DATの約7桁出力の独立丸めから最大約5e-9の見かけ空隙率誤差が出た。
空隙率を切り詰めず、出力精度の検査許容差を絶対1e-7として明示した。
ひずみ・降伏値・形状を変更して検査を通したものではない。

## 次の検証

- 降伏応力・硬化の感度試験と圧縮／除荷曲線への同定。
- ネック細分化、荷重刻み幅の依存性、塑性仕事と外力仕事の確認。
- 自己接触・周期画像間接触の実装と検証、圧密時の要素歪み対策。
- その後、100 mm角で平均Cauchy圧縮応力0.1 MPaまでの追跡と除荷。
- 骨格材料の体積塑性や圧壊が必要なら、圧力依存のキャップ／損傷モデルへの拡張。

## 30 mm角の骨格での圧縮・除荷結果

`results/plastic-packing-001`、21球、固体要素11,173、約120秒。
セル長の1%を圧縮し、軸変位拘束を解除して一般化荷重ゼロへ除荷した。

| 項目 | 結果 |
|---|---:|
| 最大平均Cauchy圧縮応力 | 0.00266623 MPa |
| 除荷後の軸残留圧縮ひずみ | 0.00557313（約0.557%） |
| 最大相当塑性ひずみ | 0.1428441 |
| 初期空隙率 | 58.6185% |
| 除荷後の空隙率 | 58.3908% |
| 除荷後の平均応力成分の絶対最大値 | 約3.1e-6 MPa |

完了・正のJacobian・正のセル体積・周期変位差・残留変形・除荷応力の検査は合格。
状態は `trial_material_cycle_passed_contact_and_calibration_unverified`。
自己接触未実装のため、空隙率も未校正試験の参考値に限定する。
この試験は0.1 MPaに到達しておらず、本仕様の100 mm角の計算結果ではない。

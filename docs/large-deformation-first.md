# 大変形の圧密経路を先に計算する開発（2026-11-05）

目的は小規模な焼結球充填体で空隙率40%→10%の圧密・保持・除荷をまず計算すること。
局所検証の追加だけでは完了としない。以下は実装中の試作経路であり、物理結果の精度認定ではない。

## 計算方式の変更

- 3次元T4有限変形FEM、既存のHencky/Kirchhoff J2材料を使用する。
  E=10 MPa、ν=0.33、初期降伏0.05 MPa、硬化係数0.2 MPa。
  E・ν・摩擦係数は利用者指定値。降伏応力・硬化係数は未指定のため従来の試験値を継続し、計測値とは扱わない。
- 明示的な波動時間刻みの追跡から、増分ポテンシャルの準静的最小化へ変更。
  累積塑性仕事は既存材料ポテンシャルに含まれており、二重加算しない。
  局所整合接線を組み立て、負の固有値だけを除いて降下方向を計算する。
- 対向面の変位差を正確に共有する周期拘束を維持。
  軸方向圧縮を与え、横方向とせん断の巨視的成分は自由に解く。
  接触中に軸方向を不連続に移動させず、拡張Lagrange法で所定変位へ収束させる。
- IPC Toolkit 1.6.1の面・点／辺・辺バリアと連続衝突判定を使用する。
  周期切断面を除去し、画像間で一致する頂点を結合する。
  各相互作用は基準配置の代表中心が主セル内にある画像だけを積分する。
- 摩擦係数0.3を維持し、IPCの遅延Coulomb散逸ポテンシャルを使用する。
  **従来の接線ばね履歴の再現ではない。** 新方式には弾性接線ばねがなく、
  塑性履歴と変形後座標を次の増分に引き継ぐ。摩擦正則化長さは0.0001 mm。
- バリアの物理形式を使用し、数値剛性の圧力尺度をE=10 MPaとした。
  初回試行の未正規化バリア係数100は長さ尺度に対して弱く、接触収束が悪化したため中断。
  圧力尺度と作用距離0.02 mmの感度は、全経路が得られた後に評価する。
- 最初の経路試行では自由成分の最大換算残差0.005 N、巨視的変位成分誤差1e-6を基準とする。
  巨視的勾配をセル長さで除してNへ換算する。L2残差と反力比も記録し、
  この基準だけで全体の力の誤差や物理的収束を保証したとは扱わない。

## メッシュと再メッシュ

CADは従来と同じBCC球・円柱ネックの和集合、球直径10 mm、ネック直径2 mm、セル長12.1 mm。
試行の2678節点・10653四面体メッシュでは、CAD空隙率40.066%に対し測定空隙率41.162%。
形状・材料量を恣意的に補正せず、この近似誤差を明記して経路の実行性を先に調べる。
正確な初期40%条件とメッシュ収束は別途必要であり、この試行をその合格結果としない。

劣化要素には変形後の辺の分割を用いる。周期的に対応する辺を同時に分割し、
四面体の入射要素も分割するため、幾何学的な表面と周期性は変わらない。
構成則履歴は子要素にそのまま複製し、基準体積を幾何学的分割率で配分する。

TetGenによる空洞内の再接続も用意する。旧・新四面体の厳密な重なり体積を計算し、
重なり領域ごとの構成則履歴を別々の積分部分として保持する。
単純な平均化による20.24%の材料エネルギー損失が見つかった試行は不採用とした。
履歴を分けて保持する方式では、その試行領域で体積・材料量・エネルギーの差を
約1e-10以下に抑えたが、最小要素品質を悪化させた再接続は採用していない。
再メッシュ後は同じ巨視的圧縮量で再び釣り合いを解く。

## 再実行

依存関係は計算の外で `pip install -r requirements-implicit.txt` により導入する。

```bash
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python tools/run_implicit_compaction.py \
  --config configs/implicit-ipc-compaction.json \
  --mesh results/large-deformation-first-001/cad-coarse/mesh.npz \
  --out results/a-new-exclusive-directory
```

`--restart`は保存された釣り合い状態のNPZを指定する。失敗した反復解は別ファイルに保存し、
次の材料状態には採用しない。出力先は既存ディレクトリを受け付けない。
40%→10%の完走状況、実際の到達空隙率、保持・除荷、画像とCSVは結果アーカイブで報告する。

## 完了判定と現在の制約

空隙率10%への到達、保持、ゼロ荷重への回復は、それぞれ独立に結果を判定する。
途中の大変形で実施した保持・除荷の分岐は、10%到達後の除荷と区別する。
初期からの圧密履歴と、この分岐を混ぜて一つの10%達成経路に見せない。

形状と材料履歴を保った要素分割に対し、TetGenの空洞再接続では新しい運動学的な基準配置を作る。
この試作ではその際に接触バリアの基準面積も再構成するため、**材料エネルギー保存だけで
接触エネルギー・接触力の完全保存を主張しない**。圧密経路を先に得る試作上の制約であり、
接触面積尺度の移行とその感度は物理的な結果の認定前に評価する必要がある。
またT4変位要素の塑性非圧縮性に伴うロッキングの影響も、メッシュ比較前には排除できない。

全体変形が大きくなり得るため、軸方向圧縮の数値的な上限を80%から95%へ延長した。
これは材料・摩擦・横方向応力自由の条件の変更ではない。セルの正体積と各四面体の正のJacobian、
連続衝突判定、力の残差を毎増分で確認する。95%圧縮も10%到達の代替合格条件にはしない。

## 実際に完走した大変形・保持・除荷の分岐

従来の接触直前の停止を越え、軸方向57.5%圧縮まで進めた状態から、準静的保持とゼロ荷重回復を完走した。
空隙率は初期メッシュ41.162% → 保持27.103% → ゼロ荷重28.943%。
ゼロ荷重で軸方向55.593%の残留圧縮があり、最大相当塑性ひずみ2.526が残る。
除荷最終の自由成分最大残差は0.001004 N、L2残差は0.003095 N。
公称軸応力は−6.86e-6 MPaで、圧縮保持時0.20738 MPaに比べて十分小さいが、完全な数値ゼロと表記しない。
この分岐では除荷中に塑性ひずみの増加は見られず、圧縮・回復の差が永久変形として残っている。

この分岐は**10%まで圧密した結果ではない**。
より高い圧縮量への主計算と区別し、`demonstration-hold-unload.csv`と比較画像に保存する。
空隙率は変形後四面体の実体積と周期セルの体積から算出し、変位画像の変形倍率は1倍とした。

高圧縮域では拡張Lagrange反復の初期乗数を直前の反力から求め、拘束用の数値剛性を
`max(1e5 N·mm, 10 × 巨視的軸方向のFEM接線対角成分)` としている。
連立方程式は微視的変位を疎分解し、巨視的変形6成分をSchur補行列で解く。
いずれも材料定数や境界条件の変更ではなく、最終的な力の残差と拘束誤差の基準を変えない高速化である。

## 95%圧縮までの主計算結果

| 状態 | 巨視的軸方向圧縮率（Fzz基準） | 測定空隙率 | 公称軸応力 |
|---|---:|---:|---:|
| 初期の粗い試行メッシュ | 0% | 41.162% | 0 MPa |
| 経路中の最小空隙率 | 87.499% | 25.137% | 1.84147 MPa |
| 設定した圧縮範囲の終点 | 94.99998% | 25.81585% | 6.88571 MPa |

95%圧縮の主計算は、`compression_limit_reached_target_not_reached` として正常終了した。
**空隙率10%は未達成**。57.5%からの保持・除荷分岐は、この終点からの除荷ではない。
最終の自由成分最大残差0.0007453 N、L2残差0.0026289 N、L2/軸反力2.61e-6。
最小要素品質0.02761、最大相当塑性ひずみ5.252。すべての四面体体積は正で、要素品質の独立した感度は未確認である。
終点では横断面積が初期の15.587倍に広がり、周期セル体積は初期の77.898%になった。
軸方向の大変形と空隙率10%への圧密は同じ完了条件ではないことが、今回の経路で明確になった。

主圧縮39状態と保持・除荷12状態の計51状態を、周期画像27個と125個で再監査した。
全状態で接触数、バリアエネルギー・勾配が一致し、表面交差は検出されなかった。
要素体積と履歴に基づく体積の最大相対差は7.74e-10。
この確認は、メッシュ・荷重増分・バリア距離・摩擦正則化の収束認定とは区別する。
関連28テストには、塑性ポテンシャルの力勾配、弾性接線、構成則履歴を分けた積分、
重なり体積の分割、周期辺分割、周期接触のエネルギー勾配・画像数・連続衝突判定を含む。

開発中は保存された釣り合い状態から再開を挟んだ。原材料定数と横方向応力自由条件は維持したが、
最終版を初期状態から一括実行したことや、物理的な空間・増分収束の合格は主張しない。
各再開の入力、ソーススナップショット、失敗・中断理由をZIPに保存する。
初回の保持・除荷は最終状態の保存後に完了JSONの型変換で失敗したため、型を修正した
`hold-unload-002` で全体の正常終了を確認した。先行試行も保存している。

より細かい準備メッシュは3959節点・15383要素、測定空隙率40.527%である。
メッシュ生成までの準備であり、このメッシュでの圧縮・メッシュ比較は未実施。
横方向拘束の比較は荷重条件の変更になるため、利用者の回答なしに追加していない。

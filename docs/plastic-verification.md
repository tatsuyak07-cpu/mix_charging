# 大変形弾塑性モデルの追加検証

対象は温度依存性なし・未校正の30 mm角焼結骨格。E=10 MPa、ν=0.33、球径10 mm、
ネック径2 mm、同じ21球の中心と同じ接合規則を固定し、1%圧縮して除荷する。
100 mm角・0.1 MPa到達の本計算ではない。自己接触や周期画像間接触は未実装で、
表面の新規接触・交差がないことを確認した試験でもない。

## 実施した比較

| ケース | 変更点 |
|---|---|
| baseline | 降伏0.05 MPa、硬化0.2 MPa、最大刻み0.1、要素幅1 mm |
| half_increment | 初期・最大刻みを1/2 |
| quarter_increment | 初期・最大刻みを1/4 |
| yield_half | 降伏応力のみ0.025 MPa |
| hardening_double | 硬化係数のみ0.4 MPa |
| mesh_075mm | 同じ球中心・ネック規則で要素幅のみ0.75 mm |

刻み幅は静解析のステップパラメータで、物理的時間ではない。
材料変更は感度を見るための仮の値であり、実験への同定ではない。
メッシュ変更時は球数を再調整せず、同じ解析形状を再ボクセル化する。
そのため、離散形状の初期空隙率は完全には一致しない。
2段階のメッシュ比較だけで収束済みとは判定しない。

比較の探索的基準はピーク応力と残留ひずみの相対差2%、最終空隙率の絶対差1e-4。
この基準は開発者定義で、材料・接触・メッシュの精度保証ではない。

## 後処理の修正

C3D8の積分点番号をCalculiXのx方向が最速で変わる順番に統一した。
従来の体積和は積分点の順序によらないが、変形後の点ごとのJacobianと応力を
掛け合わせる場合には順序を合わせる必要がある。
参照はCalculiXマニュアルC3D8 Figure 50（node25.html）と `src/gauss.f` の `gauss3d2`。
非一様な体積変化を持つ要素の解析式と、有限変形時の応力・仕事の対応をテストした。
以前の入力・出力は保持し、新しい結果を別ディレクトリへ保存した。

## 仕事・エネルギーの評価

各積分点の変形勾配FとCauchy応力σから、第一Piola応力 P=det(F)σF^(-T) を計算。

- 巨視仕事：初期セル体積 × ∫平均P : dF_macro。
- 微視仕事：初期固体体積について ∫P_local : dF_local を積分。
- いずれも保存した増分間の台形積分。両者の比較は周期構造の仕事の整合性を確認する。
- ソルバーには最初の増分からELSEを要求し、蓄積内部エネルギーと仕事を比較する。
- ELSEは回復可能な弾性エネルギーだけではない。ELSEを「弾性ひずみエネルギー」と
  呼び替えて塑性散逸を算出することはしていない。
- ∫(σy0 εp + H εp²/2)dV0 は硬化則に基づく参考積分で、硬化の蓄積成分と
  熱力学的散逸を独立に分離した結果ではない。

探索的な仕事検査の基準は巨視・微視の差1%、微視仕事・ソルバー内部エネルギーの差2%。
弾性サイクルの終了時には内部エネルギーがほぼゼロなので、サイクル誤差は最終値で
割らず、サイクル中の内部エネルギー絶対最大値で正規化する。
最初の実行では最終値で割る検査が弾性試験で不適切になったため、この正規化を修正した。
ソルバーの値や2%の基準は変更していない。実行中に生成済みの旧正規化レポートも保持し、
集計にはピーク正規化レポートを併記する。

拘束解除による除荷では最初の受理増分で急に平衡状態へ移るため、保存出力による
除荷経路の積分が粗くなる可能性がある。仕事差は圧縮終了時と全サイクルで別々に報告する。

## 現在の限界と次段階

本検証の結果が良くても、自己接触・周期画像間接触、ネックの破断、圧壊、
実験への材料同定、代表体積のサイズ依存性、100 mm角で0.1 MPaまでの圧密は未検証。
特にC3D8の塑性域の体積ロッキングや曲げ剛性、ネック表面の階段形状への依存性には
別の要素形式と追加の細分化比較が必要。

## 検証結果

全6ケースが圧縮・除荷まで完了。各ケースの既存の実行時検査と仕事検査は合格したが、**メッシュ依存性の比較は不合格で、定量結果を採用できる段階ではない**。

| ケース | ピーク圧縮応力 MPa | 除荷後の残留圧縮ひずみ % | 除荷後空隙率 % |
|---|---:|---:|---:|
| baseline | 0.00266108 | 0.557313 | 58.390786 |
| half_increment | 0.00266202 | 0.557117 | 58.390879 |
| quarter_increment | 0.00266252 | 0.557013 | 58.390928 |
| yield_half | 0.00175609 | 0.702840 | 58.331790 |
| hardening_double | 0.00284501 | 0.535639 | 58.401186 |
| mesh_075mm | 0.00213379 | 0.601954 | 58.291175 |

刻み比較は半分→1/4でピーク応力差0.0187%、残留ひずみ差0.0186%、最終空隙率差4.89e-7。
これらは上記の探索的基準に合格した。比較の相対差は細かい側の値を分母とする。
材料感度は、降伏応力を半分にするとピーク応力が約34%減り、残留ひずみが約26%増えた。
硬化係数を2倍にするとピーク応力が約6.9%増え、残留ひずみが約3.9%減った。

メッシュは1→0.75 mmでピーク応力が0.00266108→0.00213379 MPa（元の値から約19.8%低下）。
細かい側を分母とする相対差は24.7%、残留ひずみ差は7.42%、最終空隙率の絶対差は9.96e-4で、比較基準に不合格。
初期空隙率も58.6185→58.5375%へ変わり、形状のボクセル近似による差と力学的離散化の差を含む。
**メッシュ収束は未達**。ネックの局所細分化や要素形式の比較を優先し、この結果を0.1 MPaへ外挿しない。

仕事・エネルギーについて、全ケースの巨視・微視の最大相対差は約1.03e-7以下。
圧縮中の仕事・内部エネルギー差は標準0.0174%、半分刻み0.00471%、1/4刻み0.00122%。
ピーク内部エネルギーで正規化した全サイクルの差は全ケース0.238%以下で、2%基準内。
ただし、標準→1/4の全サイクル差は0.213→0.229%で改善しておらず、除荷経路の出力不足を解消したとは言わない。

後処理修正による旧30 mm試験との差は、ピーク平均応力約-0.193%。
残留ひずみと最終空隙率の差はゼロ。除荷後の平均応力の残差も約3e-6 MPaから約1e-12 MPaとなり、
積分点の対応を修正した影響と分かる。旧出力はそのまま保持した。

基礎テストは26件合格。新規の非一様要素・有限回転とせん断の変形勾配テスト、
既存の材料ブロック試験に追加した仕事検査を含む。

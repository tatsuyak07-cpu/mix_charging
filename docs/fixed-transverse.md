# 横方向の周期セル寸法を固定（2026-11-07）

利用者の「横方向の周期境界は大きさを変更しない」に従い、現在の計算条件を変更する。
新しい指定ファイルは `configs/implicit-ipc-fixed-cell.json`。
過去の横方向応力自由の入力・計算結果は保存し、拡大済みの状態を初期状態として使わない。

- 巨視的変形勾配は `Fbar=diag(1,1,lambda_z)`。
  横方向の周期ベクトルは常に `(L,0,0)` と `(0,L,0)`、巨視的せん断もゼロ。
- 対向する節点の周期変位差を維持し、微視的な変位の揺らぎは自由に解く。
  全節点の横方向変位をゼロにする拘束とは異なる。
- 横方向反力は許容し、釣り合い残差に含めない。
  圧縮・保持では微視的自由度を釣り合わせ、除荷では軸方向の巨視的自由度も解く。
- 除荷中も横寸法を固定する。最終状態は「ゼロ軸荷重」で、横方向反力が残り得る。
- 材料定数、球直径10 mm、ネック直径2 mm、摩擦0.3、接触方式は変更しない。
  初期メッシュも前回と同じものを使い、境界条件の変更を分けて評価する。
  この試行セルは L=12.1 mm、測定初期空隙率41.162%。指定40%とメッシュ収束の確認は引き続き別項目。

追加の弾性体試験では、有限Hencky弾性の一軸ひずみ解（拘束弾性係数と横方向反力）に一致した。
Schur補の巨視的未知数は従来の6成分から軸方向の1成分となる。
固定セルへ、横方向が拡大した古い巨視的変形を引き継ぐ再開は拒否する。

```bash
PYTHONPATH=. python tools/build_periodic_sintered.py \
  --config configs/implicit-ipc-fixed-cell.json --output results/new-fixed-cell-mesh
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python tools/run_implicit_compaction.py \
  --config configs/implicit-ipc-fixed-cell.json \
  --mesh results/new-fixed-cell-mesh/mesh.npz --out results/new-fixed-cell-run
```

依存関係は `requirements-implicit.txt`。出力先は未使用のディレクトリを指定する。

## 再計算結果

同一の初期メッシュから、再開を挟まず圧縮・保持・除荷の27状態を計算し、正常終了した。
初期空隙率41.162% → 保持時10.04795%（軸方向約35.401%圧縮）
→ ゼロ軸荷重回復時11.57157%（横拘束下の残留軸圧縮33.55289%）。
目標空隙率10%に対する既存の許容差は±0.1パーセントポイントである。
X・Y周期寸法は圧縮・保持・除荷の全27状態で12.1 mm、横断面積比1。
固定した巨視的成分に加え、保存節点の対向境界間ベクトルも検証する。

除荷の最終軸反力は−0.002734 N（外部の軸荷重はゼロ）。
X・Y方向の拘束反力はそれぞれ−2.257 N、−2.095 Nなので、完全な全方向無荷重状態とは扱わない。
最終自由成分の最大残差0.002734 N、L2残差0.006265 N。
関連29テスト合格。初期空隙率40%の形状精度、メッシュ・増分・接触正則化の収束は未認定。
降伏・硬化係数は従来の開発用試験値で、利用者指定のE・ν・摩擦を含め、境界以外の入力は変更していない。

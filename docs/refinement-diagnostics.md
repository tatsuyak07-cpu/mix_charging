# 表面分割が集中する区間の検証

**最後に検出した辺対では、中点を追加しても接触範囲を捉えられないことを、保存した失敗試行の形状で確認した。相手側の辺の最短位置を分割する案は品質を保てるが、状態・摩擦履歴の移行は未検証である。** 荷重・材料・接触則・品質下限・分割回数上限は変更していない。圧縮の時間積分は今回は行っていない。

## 何を検証したか

前回の[全履歴再検証](packing-rve-replay.md)で保存した、16回の採用分割と17回目の停止候補を解析した。各候補の4点は、積分器が拒否した**試行形状**の値であり、採用された平衡解ではない。

各辺対について、片方の辺上の位置パラメータをsとし、その点から相手の有限線分までの距離d(s)を計算した。線分への射影は端点で切り詰める。凸集合への距離の凸性を利用して、d(s)が接触厚さ0.02 mmを下回る区間を根探索で求めた。既存の線分対最短距離と、独立した1変数の有界最小化を照合した。

17件すべてで、最短点は0.02 mm以内にある一方、辺の中点から**相手の辺**までの距離は0.02 mm以上だった。最後の候補では、辺長約0.0244824 mmに対して接触区間の長さは約0.000453993 mm。区間はs≈0.222386〜0.240930で、中点s=0.5から離れている。

これは全17件で中点が相手の全表面から遠いことを意味しない。相手の三角形の内部が辺より近い場合があるため、最後の候補では実際の表面三角形も検査した。

## 失敗試行全体の再構成と分割位置

保存された一般化位置・速度・力・刻みから失敗試行を再構成した。記録された4点との最大差は約4.36×10⁻¹² mmで、同じ辺IDの停止を再現した。診断ツールは保存設定の `closest_tie_rule` を使うよう修正した。ソルバー本体の接触処理は変更していない。

最後の辺対について、相手の辺を共有する2枚の三角形への距離を計算した。反対側への挿入を調べる場合は、元の辺を共有する三角形を用いた。

| 幾何試験の挿入位置 | 相手の隣接三角形への距離 mm | 最小品質 | 接触厚さ内 |
|---|---:|---:|---|
| 元の辺の中点 s=0.5 | 0.02023433 | 0.05237193 | いいえ |
| 元の辺の最短点 s≈0.231658 | 0.01999939 | 0.03129383 | はい |
| 相手の辺の最短点 t≈0.588571 | 0.01999939 | 0.08344348 | はい |

どの案でも参照・試行形状の体積を保存し、周期的に対応する辺も同じ物理位置で分割した。品質下限0.03は維持した。元の辺の最短点を分割する案は下限に近く、**最短点への挿入だけでは品質回復を保証できない**。最後の候補では、相手側を選ぶ案の方が品質を保った。

これらは形状だけの提案である。材料状態、質量、摩擦履歴を持つ計算状態は作成していない。新しい節点の摩擦履歴、力・エネルギー移行、他の辺対を含む接触ガードの解消、分割後の時間積分は未検証である。幾何的に接触厚さ内に入ることを、分割案の採用条件として単独で使っていない。

## 感度とテスト

17件それぞれで、端点順序の反転、辺対の交換、剛体回転・並進、座標への±10⁻¹² mmの摂動を調べた。102通りすべてで単一辺対の接触厚さ内外判定は変わらず、最短距離差は2×10⁻¹² mm未満だった。これは全候補の走査順、同距離パッチの選択、摩擦履歴や積分軌道の安定性を検証したものではない。

幾何診断8項目と位置比較8項目が合格。関連31テストがすべて合格し、失敗・skipはない。新規テストでは交差線分の解析的な接触区間、端点・非接触の極限、非中点分割の体積とアフィン写像、節点順が逆の周期対応辺を検証した。全体テストの再実行はしていない。

## 次に組み込む前の検証

候補は「接近している両側の辺を比較し、最短位置の挿入とメッシュ品質を両立する側を選ぶ」方式である。まず非中点分割の参照体積に応じた材料状態・質量・速度の移行を検証し、続いて新しい接触節点への摩擦履歴と接触エネルギーの移行を監査する。監査を通過した案だけを試行棄却・再試行の処理に接続する。その後、圧力履歴と載荷速度・刻み依存性を確認する。

現状は約0.05674 MPaで停止した前回と同じ開発段階であり、0.1 MPaの準静的解や40%→10%圧密は未達成である。分割上限を増やす変更は行っていない。

## 再現

既存のPython環境を用いた。追加インストールや環境設定変更は不要だった。各出力先は新しいディレクトリを指定する。

```bash
export PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
PY=/workspace/environment/mix_charging/.venv/bin/python
CALC=exports/packing-rve-replay-001/validation/corrected-run/calculation
$PY -m tools.diagnose_refinement_chain --input "$CALC" --output results/new-chain
$PY -m tools.diagnose_rve_stop --source "$CALC" --output results/new-trial
$PY -m tools.probe_refinement_location --trial results/new-trial \
  --calculation "$CALC" --output results/new-location
$PY -m pytest tests/test_refinement_diagnostics.py tests/test_surface_stationarity.py \
  tests/test_packing_rve.py tests/test_closest_tie.py -q
```

ZIPには元の失敗候補・設定、試行再構成、各幾何提案、診断時ソース、テストログを含む。位置比較001は元の辺の2案、002で相手側を追加、003で出力の距離項目名を「反対側」に統一した。過去の出力は保持した。

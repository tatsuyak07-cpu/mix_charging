# 接触追跡から圧縮ソルバー結合までの段階検証

## 到達点と未合格項目

新接触処理を `contact_backend: tracked_guarded` として、研究用の準静的陽解法FEM圧縮ソルバーへ選択的に組み込んだ。接触力を拘束系へ戻し、接触エネルギー、摩擦散逸、履歴解除による数値的なエネルギー損失、接線ばねの仕事積分の補正を監査する。既存の設定は `legacy` のままで、以前の結果は変更していない。

**ソフトウェア結合と限定的な動的接触試験は確認できたが、一般的な圧密への適用検証は未合格である。** 辺―辺の接触反力は未実装で、交差または曖昧な移動を検出した場合に停止する。元のスリット試験はこの停止条件に該当した。したがって、40%→10%の空隙率変化や0.1 MPaの実モデルの解は今回も得られていない。

| 工程 | 実施内容 | 結果 |
|---|---|---|
| 接触領域の追跡 | 同一三角形・基準形状上の共有辺を自動対応 | 限定条件で合格 |
| 摩擦履歴の移送 | 材料回転、法線変化、離接触を含めたばね移送 | 試験合格 |
| 接触中の内部再接続 | 非ゼロ法線力・接線履歴で2→3接続変更 | 静的な転送試験合格 |
| 辺―辺の検出 | ステップ内の線形移動の共面条件と距離 | 検出・停止を確認 |
| 辺―辺の反力 | 未実装 | **未合格** |
| ソルバー結合 | 接触力→拘束系→加速度→変位の往復 | 小規模動的試験合格 |
| 元のスリット試験 | 標準刻みと半分刻み | **辺―辺検出で停止** |
| 一般的な準静的圧密 | 全経路・メッシュ・速度・接触依存性 | **未検証** |

## 1. 接触追跡と履歴移送

周期像の整数シフトを加えた基準座標で共有辺を照合する。単に同じ粒子、同じ連結体、近い位置という理由で履歴を移さない。異なる周期像で共有辺が一致する場合は対応し、誤った像や近接した別表面へは対応させない。

対応できる面移動は同一面または共有辺を持つ隣接面である。頂点だけを共有する移動、1ステップで隣接面を飛び越す移動など、対応が曖昧な場合は計算を停止する。これは一般的な大滑りの追跡完了を意味しない。

前の面の現在形状から求めた変形の極分解で材料回転を得て、接触法線の変化を加えてばねを移送する。前の重心座標で追跡した相手の材料点と試験節点の相対変位から、回転による見かけの移動を除去する。完全な有限滑り接触理論の妥当性は未確認であるが、剛体回転・面内伸縮・周期像の仕事・解析的な接触ポテンシャル勾配を単体試験した。

法線の向きによる候補除外（内積−0.05以下）は従来から引き継いだ数値的なフィルターであり、これによる不連続性が一般に解消したとは扱わない。固体内部判定では、実際の周期オフセットに基づく局所隣接四面体を除き、非局所四面体への包含を調べる。同じ連結体の遠方の周期像は除外しない。これらは小規模な試験で確認した範囲で、任意の複雑な自己接触に対する正当性の証明ではない。有限食込みで摩擦力を節点へ分配した際のモーメント誤差も、一般条件では未評価である。

## 2. 接触中の内部再接続

検証用の固体表面に小さな先端を接触させ、滑らせる。面番号が変化した際に履歴の移送が1回発生し、ばねエネルギーが消えないことを確認した。履歴は自動で共有辺から対応づけており、前回のように領域の対応を外部から与えていない。

その状態で内部の2→3再接続を行った。接触数1、接線ばねエネルギー約1.0228×10⁻⁵ N mmで、次を確認した。

- 境界三角形と履歴キーを保持。
- 再接続前後の接触力変化0 N、接線エネルギー変化0 N mm。
- 基準体積変化0 mm³、初期の一様PEEQ=0.2を保持。
- 品質指標は0.3148から0.4963へ改善。

これは**接触が有効な静的状態での転送試験**である。動的な再接続に伴う速度投影、非一様塑性履歴、表面再生成の転送が合格したという意味ではない。

## 3. 辺―辺の検出と停止

移動する4端点について、2辺が共面となる条件を3次多項式として求め、ステップ内の実根で線分間距離を評価する。始点・終点では離れていても、ステップ途中で交差する試験を検出した。平行線分にも対応する。共面移動の境界箱が重なり、距離と移動量から非接触を証明できない場合は曖昧として停止する。

初版は離れた平行辺でも境界箱が重なるだけで停止した。その結果は `tracked-solver-verification-001` に保持した。002版では線分間距離のLipschitz境界に基づき、初期距離が全相対移動量より大きければ非交差と証明して除外した。停止を回避するために許容誤差を緩めた修正ではない。

この停止機構は線形な端点軌道、浮動小数点の根、現在の像探索範囲を使う研究用実装であり、一般の非線形時間軌道に対する完全な衝突検出を保証しない。交差する辺を押し戻す反力や摩擦の機構はなく、検出した場合は最後の受理状態を保存して停止する。

## 4. ソルバー結合と動的な反力試験

`explicit_solver.py` に新バックエンドの選択、受理状態の保存、接線仕事の数値補正の記録を追加した。後退Eulerの仕事恒等式の散逸をVelocity Verletへ直接加算することを避け、回転移送した前後のばねによる台形則の仕事から、弾性エネルギー増分と摩擦散逸を差し引いた符号付き補正を用いる。したがって、この補正は非負の物理散逸とは扱わない。002版と先端試験001は修正前の記録として保持し、003版と先端試験002で再計算した。CSVの既存列の位置は保持し、末尾に `contact_algorithmic_Nmm` を追加した。

均質体と小空隙モデルは監査をすべて満たして完了し、従来バックエンドとの最終空隙率・最終公称応力の差はともに0だった。ただし、これらでは接触が起こらないため、別途、実際に反力が発生する動的試験を実施した。

3 mm角の周期固体の中央に1 mm角の空孔を設け、その中の小さな四面体先端を1000 mm/sで壁に衝突させた。初期食込みはなく、先端の初期すきまは0.005 mm。これは**結合検証専用の形状と人工的初速**であり、粒径10 mmの充填体の条件を変更するものではない。E=10 MPa、ν=0.33、摩擦係数0.3、試験用密度・減衰・ペナルティの既存値を使用した。

| 項目 | CFL 0.2 | CFL 0.1 |
|---|---:|---:|
| 計算経路15 μs | 完了 | 完了 |
| 最大接触数 | 1 | 1 |
| 最大食込み mm | 0.00157886 | 0.00157973 |
| エネルギー相対誤差 | 0.0675464% | 0.0274390% |

食込みが増えて減少し、接触力が加速度へ戻ることを確認した。体積・材料体積・正のJ・Coulomb条件も合格した。`functional-checks.json` は動的機能試験用の判定である。元のソルバーの準静的判定（静力学残差・運動エネルギー比など）は不合格のまま保持しており、動的試験を準静的解と再分類していない。

## 5. スリット試験で残った不合格

元の入力を新バックエンドに切り替え、時間刻み上限だけを標準・半分で比較した。

| 項目 | 標準 | 半分刻み |
|---|---:|---:|
| 受理ステップ | 639 | 1278 |
| 最後の受理時刻 μs | 9.44878712 | 9.44878633 |
| 最大の節点接触数 | 0 | 0 |
| 停止理由 | 辺37と47の移動中の交差 | 同じ辺の交差 |

前回の節点接触開始（約9.478 μs）より先に辺の交差が現れる。節点―面だけで経路を追う方法では、この事象を扱えない。両試験の時刻はほぼ一致しており、刻みを半分にしても未対応の反力処理そのものは補えない。**この不合格を飛ばして一般的な圧密へ進めることはできない。**

次に必要なのは、辺―辺の接触反力と摩擦、その節点―面接触との切替えを、重複計上・エネルギーの跳びを起こさず扱う処理である。反力を加える前に、符号付きギャップ、作用反作用、モーメント、周期像の仕事、力とポテンシャルの差分、切替え時の履歴を検証する必要がある。その後、同じスリット試験、接触中の動的再接続、準静的載荷速度・メッシュ依存性へ進む。

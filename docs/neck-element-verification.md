# 焼結ネックの形状固定細分化と要素形式の検証

前回の30 mm角充填層では1→0.75 mmの再ボクセル化で応力が約20%変わった。
形状の階段近似と力学的な離散化の影響を分けるため、今回は部品試験を実施した。
**本試験は周期境界の充填層や100 mm角・0.1 MPaの本計算ではない。**

## 部品の定義

- 直径10 mmの2球（中心z=6,18 mm）と直径2 mmの円柱状焼結ネックを合併。
- z=3,21 mmで球を切断して平坦な載荷・支持端面を作る。間隔18 mm。
- x,yの対称性から四分の一領域を解析する。
- まず0.5 mm格子で階段形状を定義し、その**同じ領域を細分割**する。
- ネック周辺x,y≤1.5 mm、z=10〜14 mmに格子線を追加し、ネック要素幅を0.5、0.25、0.125 mmへ変更。
  適合格子とするため格子線を肩部にも延長する。ハンギング節点の拘束はない。
- 各段階の要素数は1,904、4,052、11,936。全段階で四分の一体積238 mm³、
  四分の一ネック断面積0.75 mm²を維持する。再ボクセル化や球数の調整は行わない。

この部品はネックの力学的離散化を比較するための開発者定義モデル。
球中心・境界条件・空隙率はランダム充填層と異なり、部品の応力を充填層の巨視的応力と解釈しない。
円形表面の階段誤差やネック根元の角は固定したままなので、細分化しても真の曲面形状へは近づかない。

## 材料・圧縮・除荷

温度依存性なしの率非依存J2弾塑性。E=10 MPa、ν=0.33、仮の降伏応力0.05 MPa、
仮の等方硬化係数0.2 MPa。これまでの試験設定を維持する。実験同定は未実施。
x=0でUx=0、y=0でUy=0、下端でUz=0。上端を0.18 mm（18 mmの1%）圧縮後、
上端の変位拘束を解除して外力ゼロへ除荷する。横方向の上端変位は拘束しない。
圧縮・除荷ともNLGEOM、初期刻み0.025、最大刻み0.05。
新規接触・損傷・破断は含めない。
メタデータのconfigは既存モデルから材料・数値設定を引き継ぐために記録している。
その中のlength_mm、porosity、target_mpa、mesh_mm等は、この固定形状の部品条件には適用していない。
実際の形状・格子条件はgeometryを参照する。

標準の完全積分C3D8と、非適合変位モードを含むC3D8Iを、同じ節点・要素接続で比較する。
CalculiX 2.20がC3D8Iを実際に扱えることを実行で確認した。
ローカルのCalculiX資料 `node376.html` にC3D8Iの記載があり、
公開ソース `src/e_c3d.f` では物理頂点8と内部モードを含む11節点の扱いが区別されている。

## 評価方法

- **反力**：上端の物理節点RFの総和。この部品入力にMPCはない。
- **残留変形**：除荷後の上端Uzを、初期端面の面積で重み付けした平均。
  局所細分化で節点密度が変わるため、単純な節点平均は使用しない。
- **仕事**：各上端節点のRFと変位の積を増分間で台形積分し、ソルバーのELSEと比較。
  静止した拘束面の外力仕事はゼロ。ELSEは回復可能な弾性エネルギーだけではない。
- **幾何**：角節点からの体積JacobianとソルバーEVOLを検査する。
  C3D8Iの内部モードによる局所変形勾配を再構成した検査ではない。
- **相当塑性ひずみ**：PEEQの最大値を記録。ただし階段形状の根元の角により局所ピークが
  メッシュに依存するため、これだけで局所ひずみの収束を宣言しない。

細かい側を分母にしたピーク反力差と残留変形差がともに2%未満なら、
固定した部品形状におけるネック細分化の探索的な基準内とする。
これは肩部メッシュ・真の曲面・充填層全体・塑性ひずみピークの収束証明ではない。
仕事差の基準は2%、全サイクルの正規化にはサイクル中の内部エネルギー絶対最大値を使う。

C3D8Iへ既存の「8頂点からFを再構成する局所仕事監査」をそのまま適用していない。
周期充填層の既存バックエンドはC3D8専用のままとし、C3D8I指定を黙って無視せず拒否する。

## 独立した梁試験

長さ20 mm、断面1×1 mm、E=10 MPa、ν=0.33の片持ち梁に、端面合計1e-5 Nの横荷重を与える。
同じ20個の立方体要素を使用し、微小変形の線形静解析でTimoshenko梁の変位式と比較する。
梁の式は δ=PL³/(3EI)+PL/(κGA)、I=1/12 mm⁴、κ=5/6。
理論変位は0.03206384 mm。参照に対する5%以内を試験基準とする。

| 要素 | 端面平均変位 mm | 理論値に対する誤差 | 5%基準 |
|---|---:|---:|---|
| C3D8 | 0.02025158 | 36.84% | 不合格 |
| C3D8I | 0.03181266 | 0.783% | 合格 |

この条件ではC3D8が曲げ変形を硬く評価している。
ただし、梁の試験だけで焼結鉱の材料則や充填層の精度を保証するものではない。

## 記録と再実行

新しい出力先を指定する。

```bash
python tools/verify_neck_elements.py --output results/neck-elements-new
python tools/summarize_neck_elements.py results/neck-elements-new exports/neck-elements-new
python -m pytest -q
```

2ケースまで並行実行、各ソルバー1スレッド。既存の同条件パイロットを再利用する場合は
`--pilot`で明示し、条件の一致を検査する。元のDAT・ログ・失敗記録は保持する。
本検証の実行中に、残留変位の集計を節点平均から面積平均へ改善した。
既に作成済みの元の集計は上書きせず、元のDATから面積平均を再集計して併記する。
反力・外力仕事の計算は節点ごとの総和なので、この平均方法の変更では変わらない。

## 部品の結果

全6部品ケースが圧縮・除荷まで完了し、実行時の体積・残留変形・仕事検査は合格。
**0.25→0.125 mmの比較でC3D8Iの部品応答は2%基準内、C3D8は反力が基準外。**
これは固定階段形状のネック部品の応答に限定した結果で、充填層全体の収束を意味しない。

| 要素 | ネック要素幅 mm | ピーク四分の一反力 N | 面積平均の残留圧縮 mm | 最大PEEQ |
|---|---:|---:|---:|---:|
| C3D8 | 0.5 | 0.07796601 | 0.13857829 | 0.087219 |
| C3D8 | 0.25 | 0.06663002 | 0.14333693 | 0.108518 |
| C3D8 | 0.125 | 0.06142127 | 0.14558977 | 0.135380 |
| C3D8I | 0.5 | 0.06054284 | 0.14741402 | 0.146804 |
| C3D8I | 0.25 | 0.05884020 | 0.14735885 | 0.164366 |
| C3D8I | 0.125 | 0.05795164 | 0.14736951 | 0.227015 |

| 比較 | 反力の相対差 | 残留変形の相対差 | 両者2%基準 |
|---|---:|---:|---|
| C3D8_1_to_2 | 17.0133% | 3.3199% | 基準外 |
| C3D8_2_to_4 | 8.4804% | 1.5474% | 基準外 |
| C3D8I_1_to_2 | 2.8937% | 0.0374% | 基準外 |
| C3D8I_2_to_4 | 1.5333% | 0.0072% | 基準内 |

最大の圧縮仕事・内部エネルギー差は約0.00635%、全サイクル差は約0.0454%で2%基準内。
この検査は境界の節点外力と変位からの積分であり、C3D8Iの内部モードの局所場の独立検証ではない。
C3D8Iの最大PEEQは細分化で0.1468→0.1644→0.2270と増加している。根元の角と塑性域の
局所ピークは収束したとは言えず、破断・損傷の判定値へ流用しない。

31件のテストが合格。固定体積の細分化、非一様格子での面積平均、梁の独立解析解、
周期バックエンドが未対応のC3D8I指定を黙って受け付けないこと、既存モデルの検証を含む。

## 結論と次の段階

C3D8Iは曲げ試験とネック細分化の結果から、次の検証に進める候補とする。
直ちに周期充填層の既定要素へ切り替えたわけではない。次はC3D8Iの内部モードと
整合する体積・平均応力・仕事の評価を用意し、小規模周期モデルへ導入して検証する。
肩部と曲面形状の細分化・形状近似の比較も残る。自己接触、材料校正、100 mm角・0.1 MPa到達は未検証。

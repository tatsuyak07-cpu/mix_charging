# 周期平面接触の検証：接触積分の位置依存を確認

追記：[参照面積による修正版 `area_guarded`](area-contact-fix.md)を追加しました。本書の従来方式・圧密結果は履歴として保持しています。

**現行の距離バリア接触は、物理的に同じ平面界面でメッシュの位置を変えると接触力が変わり、検証に不合格でした。** この問題を修正するまで、前回の0.1 MPa圧密結果を充填層の物理予測として採用しません。時間積分や最終平衡の合格だけでは解決しません。

## 検証条件と形状の独立確認

これは接触部分だけの規定形状試験で、100 mm角の球充填層や材料の載荷計算ではありません。水平な周期平面2枚（各面積1 mm²）を持つ2つの板状部分を用います。元の固体体積は合計0.8 mm³、初期間隙は0.2 mmです。現在間隙を0.015 / 0.010 mmに規定し、周期セルの高さも0.8+間隙へ整合させます。

面内分割数 n=1,2,4,8、上側メッシュの移動 `(s/n, 0.37s/n)` mm、s=0,0.01,0.25,0.5 の計32ケースを比較しました。面積と間隙は同じです。移動に合わせてセルのz格子ベクトルの面内成分も設定し、上下面の周期同一視を保ちます。独立のテストで、現在固体体積0.8 mm³、セル体積、間隙、各周期同値節点間の現在座標差が `H×整数画像ベクトル` と一致することを確認しました。板のメッシュ移動で物理界面の凹凸や間隙を変えていません。

接触設定は前回と同じくμ=0.3、ペナルティ係数20 MPa/mm、バリア幅0.02 mm、探索幅0.1 mmです。各位置で摩擦履歴を初期化しています。これは実際に摩擦滑りさせる時刻歴ではありません。Eや降伏応力、密度を変更して収束させる試験ではなく、構成則や時間積分から接触部分を切り離した検査です。

力・仕事の許容値は実行前に、合力の相対誤差1e-10、エネルギー微分・周期巨視的仕事1e-5としました。同一平面のメッシュ位置による力の広がり `(最大−最小)/平均` には開発用スクリーニング値2%を設定しています。これは普遍的な物理精度基準ではありません。

## 結果

間隙0.015 mmでの合計法線力は以下のとおりです。同じ物理界面のため、メッシュをずらすことによる差が小さくなる必要があります。

|面内分割数 n|重ねたメッシュ [N]|0.5 hずらしたメッシュ [N]|力の比|
|---:|---:|---:|---:|
|1|0.928093545|0.200383834|4.631579|
|2|1.075744791|0.237296645|4.533333|
|4|1.107384343|0.245206533|4.516129|
|8|1.123204120|0.249161477|4.507937|

8分割でも約4.5倍の差が残ります。n=8、間隙0.015 mmの4位置での力の広がりは127.65%で、設定した2%を超えました。間隙0.010 mmでも不合格です。この範囲ではメッシュ位置への依存が解消していません。1つの細分化結果で収束とみなしません。

一方、32ケースの最大相対誤差は合力1.62e-16、法線方向のエネルギー微分4.11e-10、周期巨視的仕事6.82e-10でした。力は現在実装されている離散ポテンシャルと整合しています。問題は、そのポテンシャルの総和が物理的に同じ平面に対して一定にならない点です。

追加のn=1、間隙0.015 mmで14位置を調べたところ、接線合力が最大0.11091 N生じました。初期摩擦ばねエネルギーは最大4.27e-31 N mm、摩擦散逸増分はゼロです。この力は摩擦滑りの応答として説明できず、面内メッシュ位置に依存する離散接触エネルギーから生じています。

## 寄与の分解から分かった原因

現行実装は、距離がバリア幅内にある点–三角形と辺–辺の拘束エネルギーを加算します。共有頂点・辺へ投影される点は複数の三角形に数えられ、辺–辺のエネルギーも加わります。実際に有効な拘束の集合を分解し、その力の和がソルバーの合計力に一致することを確認しました。

n=1、間隙0.015 mmでは、メッシュが重なる場合の点–面寄与は0.37967 N、辺–辺寄与は0.54842 Nです。0.25 hずらすと、それぞれ0.06328 N、0.13710 Nになります。両方が位置依存を持っています。単一の係数でペナルティを割っても、位置によって異なる倍率を同時には補正できません。

CSVの `area_spring_*` は、面積1 mm²に `B(gap)` を一様積分した比較指標です。既存の「拘束エネルギーの固定総和」の厳密解を倍率1だと主張するものではありません。物理的な不合格の根拠は、同じ平面界面に対する位置依存です。

## 判定と次に必要な修正

- **合格**：幾何・周期同一視、力の釣り合い、離散エネルギーの微分、周期巨視的仕事。
- **不合格**：平面界面でのメッシュ位置不変性。不要な接線合力も検出。
- **未解決**：曲面・自己接触での面積整合、接触正則化とメッシュの共同収束、表面再メッシュ、実際の充填層の40%→10%圧密。

修正には、接触面積に整合する積分と、共有面・辺・頂点での重複寄与の扱いを設計し直す必要があります。特徴の切替でエネルギーと力が飛ばないことも維持します。辺–辺の交差防止を単純に外して平面試験だけを通す方法は採りません。辺–辺の交差防止と物理的な面接触力をどのエネルギーとして組み合わせるかを定式化し、全微分を含めて検証する必要があります。

再設計後は、この32ケースと細かい位置走査、特徴遷移、周期仕事、摩擦履歴を再検証し、その後に圧密の載荷速度・刻み・接触設定・メッシュ比較をやり直します。今回、既存の接触係数や過去の結果を変更して合格にしていません。

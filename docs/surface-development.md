# 工程1〜3：接触判定・複数接触・表面分割の試験実装

工程3までに必要な機能を小さな検証モデルで実装した。**一般の球充填層で工程3を完了したという意味ではない。** 任意の接触面の分岐・合流、真の辺同士の接触の力積分、潰れた表面要素の再生成・粗大化は残る。初期空隙率40%→10%の圧密結果はまだない。

[表面分割の実メッシュ画像](../exports/surface-bisection-view-001/surface-bisection.png)、[検証全体の画像](../exports/surface-development-003/surface-development.png)、[保存結果](../exports/surface-development-003/summary.json)、[全データZIP](../exports/surface-development-003.zip)。不合格の初回は `exports/surface-development-001`、材料接触点修正後・分割時刻未整合の中間試行は `002` に残した。`003` はCFL比較の分割時刻も揃えた検証である。

## 仕様と検証用の条件

依頼された100 mm角、粒径10 mm、ネック径2 mm、E=10 MPa、ν=0.33、摩擦0.3、初期空隙率40%の条件は変更していない。ただし今回の計算はその充填層ではない。

* 接触判定：既存の4 mm角・初期空隙率0.25%の保存変形形状を5段階に補間した事前検査。
* 圧力積分の解析解対照：1 mm角の空隙なしの弾性体、名目圧力0.01 MPa。塑性を抑えるためこの対照試験のみ降伏応力を1e6 MPaとした。E=10 MPa、ν=0.33は維持。
* 履歴移行：周期的な平行な二つの材料層を所定位置へ動かす接触専用試験。圧力負荷による充填層の解ではない。摩擦0.3、接触有効距離0.02 mm、法線係数20 MPa/mmは既存と同じ。

## 工程1：参照材料近傍と現在の幾何形状

`certified_local_filter=true` の試験機能を追加した。参照状態で短い線分の全体が材料内にあり、生の材料連結成分も一致する候補に限定し、現在の写像について周期空隙補助写像の強単調性条件が成立するときだけ材料近傍として扱う。参照で空隙を横切る候補をこの規則で除去しない。源側の距離減少だけで積分点を除外する案は採用していない。

幾何証明だけを理由にすべての接触力を消す処理ではない。この**二条件の組み合わせ自体も試験的な接触モデル**で、任意の局所折れ曲がりで有限距離の接触則を適切に扱うという一般的保証はない。非重複の十分条件は浮動小数点による数値確認で、条件が不成立なら停止する。初期格子は既存の正準格子に限定する。内部2→3接続変更との併用は禁止した。

保存形状の段階1/2/3/4/6はすべて評価可能となった。法線エネルギーは約1.54636e-5、3.86590e-6、1.71818e-6、9.66474e-7、4.33972e-7 N mm、接触記録数は2/2/2/2/14。**メッシュによる差は大きく、収束していない。** 同じ補間形状での計算なので、独立した圧力履歴のメッシュ収束とも異なる。

## 工程2：互いに離れた接触パッチ

`multiple_patches=true` を追加した。同じ源節点の有効な相手三角形を接続したパッチにまとめ、各パッチの最短候補を1個ずつ面積積分する。パッチごとに従来と同じ半分の参照節点面積を用いる。三角形数だけばねを足す処理ではない。パッチごとに摩擦状態を持ち、隣接する相手面へ移るときも履歴キーを引き継ぐ。

二つの別々の接触面に挟まれた材料について、非等距離・等距離の両方で、エネルギーの数値微分と法線反力の一致、独立した摩擦履歴、客観性、各記録のCoulomb上限を検証した。同じ接続パッチ内の異なる等距離最短点、履歴の分岐・合流、未捕捉の真の辺接近は停止する。これらを無条件に統合する一般の複数接触積分は未実装である。

## 工程3：周期表面の分割と状態の引き継ぎ

`surface_remesh.py` は選択辺と周期的に対応する辺を同時に二分し、その辺に接続する**すべての**四面体を二分する。これにより宙に浮いた節点を作らず、表面三角形も分割する。子要素では親の弾性左Cauchy–Greenテンソルと相当塑性ひずみをそのまま保持し、基準体積を子の基準形状体積に比例配分する。要素内一定の材料状態については平均化を伴わない。

変位と節点速度を一次補間し、周期自由度と質量行列を作り直す。速度を周期質量で投影した**後**、質量、線形・角運動量、運動エネルギー、材料エネルギー、法線・摩擦エネルギー、巨視的な接触力、Coulomb上限を監査する。採用できない場合は元の配列・接触オブジェクト・積分状態を保ち、提案メッシュと理由を保存する。監査をすべて通過してから状態を一括更新する。

摩擦では旧節点の材料接触点を保持する。新節点には辺の両端の弾性滑りを空間ベクトルで補間し、材料接触点も補間する。補間点を参照・現在の両配置で同時に正確に表せる旧材料面がない場合や、相手パッチが一意でない場合は拒否する。単に現在の最近点へ接触点を付け直さない。

初回001ではエネルギーと層反力が一致しても、接触点の付け直しによって巨視的な接触力に相対7.9003e-6の差が生じ、事前に設定した1e-7の監査に不合格となった。材料点を保持する修正後は、この差は約5.13e-16、摩擦エネルギー差は約3.97e-16まで減少した。閾値を緩める変更はしていない。

空隙の幾何補助写像も同じ辺分割を施し、未知の空隙節点だけ幾何学的な調和拡張を解き直す。空隙に材料、構成則、質量は与えない。既存の分割系譜を保持する場合だけ利用でき、任意の再メッシュを証明できる仕組みではない。材料が重なる負例、周期境界不一致、保存誤差の大きい速度場、移行処理の失敗による元の計算の不変性も検査した。

圧力ソルバーには指定ステップ、および指定間隔で品質が閾値を下回ったときの呼び出しを組み込んだ。辺の自動選択は現在の表面最長辺である。1回・2回の分割後の継続計算を解析解と比較した。**この対照では最小品質は約0.756から0.560へ低下しており、分割は品質改善を保証しない。** 大きく潰れた要素を修復する再生成や粗大化とは区別する。接触停止が起きた試行ステップを自動的に再メッシュして再開する機能も未実装である。

## 検証結果

全体テストは224件合格（修正前の全体試行は222件合格・1件不合格として保存）。最終の一連の診断は10項目すべて合格した。

圧力対照の最終軸圧縮は、分割なし0.000998497806581、CFL0.2・分割あり0.000998497943322、CFL0.1・分割あり0.000998497929274。二つの分割計算の差は約1.40e-11。厳密な弾性伸長比は `-E ln(λ)/λ = 0.01 MPa` の根0.999001497338537であり、すべての誤差は設定した1e-7以内だった。分割時刻の一致も確認した。

最終成果物には、全体テストの完了ログ、初回不合格のログ、各圧力計算の設定・全ステップ履歴・最終状態、分割前後のメッシュ・材料状態、移行した摩擦履歴、ソースを含めた。83ファイルのSHA-256とZIPのCRCを照合した。表面の新節点を赤く示した補助画像は、保存NPZを `tools.plot_surface_bisection` で描いたものである。

## 利用方法と採用条件

通常設定は変更していない。以下は小モデルを検証するための追加設定例である。

```json
{
  "contact_backend": "area_guarded",
  "multiple_patches": true,
  "certified_local_filter": true,
  "edge_stationarity_filter": true,
  "remesh_every": 0,
  "surface_remesh_steps": [10, 20],
  "surface_remesh_max_events": 2
}
```

自動呼び出しには `surface_remesh_every` と `surface_remesh_quality` を指定する。監査許容値は既存の `remesh_energy_tolerance`、下限品質は既存の `minimum_quality` を用いる。設定したイベント上限に達した後は分割しないため、これだけで任意の大変形を続けられるとは限らない。

再現コマンド（出力先は毎回新しい場所）：

```bash
export PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
PY=/workspace/environment/mix_charging/.venv/bin/python
$PY -m pytest -q > results/new-surface-evidence/full-tests.log
MPLCONFIGDIR=/workspace/environment/mix_charging/mplconfig \
XDG_CACHE_HOME=/workspace/environment/mix_charging/cache \
$PY -m tools.verify_surface_development \
  --output exports/new-surface-validation --evidence results/new-surface-evidence
```

先に新しい証拠ディレクトリを作成する。圧力対照のCFL0.2は10ステップ、CFL0.1は20ステップで分割し、同じ物理時刻での分割を1e-12 s以内で確認する。この一回の刻み半減は一般の時間収束を意味しない。

次に必要なのは、接触停止と表面の再生成・再試行の連携、同一パッチ内の複数最短点と真の辺接触の処理、変形した空隙壁での接触積分収束、および接触と塑性が同時に進む圧力一周期の再メッシュ感度試験である。その後に球充填の小RVEへ進む。

# 周期自己接触を含む圧力制御・圧密計算の開発

**追試で接触積分の物理的な問題を特定しました。** 同じ平面間隙でメッシュ位置を変えると接触力が約4.5倍変わります。[平面接触の検証](plane-contact-verification.md)を参照してください。以下の圧密値は数値動作の記録であり、充填層の物理予測には採用しません。

今回追加したのは、有限変形弾塑性の陽解法FEMに、連続な距離バリア接触、巨視的圧力制御、空隙率目標による保持・平衡判定を組み込んだ研究用実装です。**0.1 MPaまで実行したモデルは4 mm角・初期空隙率0.25%の検証用連続体です。直径10 mmの球からなる初期空隙率40%の充填層の圧密解とは異なります。**

ユーザー仕様は100 mm角、球径10 mm、焼結ネック径2 mm、骨格E=10 MPa、ν=0.33、再接触時μ=0.3、円柱なし、初期空隙率40%から10%への圧密です。既存の粒子形状入力は25 mm角のRVEで、離散化後の空隙率は39.8592%です。この入力で接触探索と5増分の初期動作まで確認しましたが、100 mm角の計算、40%→10%の圧密は完了していません。

## 実装

- 四面体の有限変形Hencky弾性・Kirchhoff応力J2塑性を使用します。降伏応力0.05 MPa、硬化係数0.2 MPaは未同定の試験値です。温度項はありません。体積塑性・圧力依存降伏は含まず、粘土・焼結鉱の実測に基づく構成則とはいえません。
- 周期変位拘束を縮約し、6成分の平均対称変形を未知数として積分します。`nominal_pressure`ではzz成分に基準体積×公称圧力の一般化荷重を与え、横方向荷重はゼロです。**公称圧力**0.1 MPaであり、変形後面積によるCauchy応力を一定にする制御ではありません。
- `porosity_target`では圧力を滑らかに増加し、目標空隙率に達すると圧力を保持します。保持後に力残差と運動エネルギーを確認し、反発で目標から外れた場合は載荷を再開します。上限圧力、時間、増分予算で未達となる場合は診断結果として保存し、空隙率を補正・外挿しません。
- 空隙率は `1 − Σ四面体現在体積 / 周期セル現在体積` で求めます。四面体体積、材料の弾性体積比、閉曲面積分を別々に照合します。重なりの体積補正は行いません。
- 周期画像を含む非局所の点–三角形・辺–辺距離に同一形式のバリアを用います。最近接特徴が面から辺・頂点へ移ってもポテンシャルを切り替えません。摩擦履歴は回転する接触座標系で保持します。平行辺のモリファイアとその力の微分を含みます。公開IPC実装ではなく、接触積分の重み・バリア幅・モリファイアの収束は未検証です。
- 最後の受理形状からの相対移動と距離下限による線形増分の非交差検査を行います。検査に失敗した接触試行は状態を受理せず時間刻みを半減します。初期交差形状の修復や一般的な曲線軌跡の衝突保証ではありません。候補予算超過時は切り捨てず停止します。
- 近傍リストは未収録対の距離下限を保つ範囲で再使用します。複素ステップの12方向の微分をバッチ評価し、独立したスカラー微分・毎回探索との一致をテストしています。
- `assembled_mass_bound`は線形弾性の質量重み付き剛性行和に基づく刻み幅です。有限変形・接触での補正は推定であり、一般的な非線形安定性の証明ではありません。刻み幅半減による比較を併記します。
- 適応メッシュは内部2→3再接続のみです。境界形状と接触履歴を維持し、エネルギー・運動量の移送誤差を検査します。**表面再メッシュ、要素分割・粗化、一般的な大圧密への再メッシュは未実装**です。

## 慣性と数値設定

密度1e-9 tonne/mm³、減衰6000 /sは数値的な試験設定です。E、摩擦、形状を変更して判定を通していません。速い載荷は運動エネルギーの基準を超えました。載荷時間と時間刻み、減衰、接触ペナルティ、バリア幅を分けて比較します。

追加の `mass_frame=zero_momentum` は並進運動量ゼロの慣性縮約を明示的に解くオプションです。座標ゲージは従来と同じですが、速度は質量平均並進を除いたものを使います。質量行列は `AᵀWA − B Bᵀ/Mtotal`、`B=AᵀWT` とし、力・減衰・運動エネルギーも同じ射影に統一しています。ランク3のWoodbury補正で解きます。密度変更や、計算後に運動エネルギーだけを差し引く方法ではありません。密行列によるSchur補元、仮想仕事、運動量、均質弾性解を独立に検証しました。従来の `pinned` を既定として保持し、遅い載荷との比較を保存しています。外部の固定剛体を含む系への適用は別検討です。

接触の符号付き数値仕事補正は物理的な散逸とは区別し、絶対変動累積と解放履歴の和にもエネルギー基準を課します。新しい計算では全受理増分で最大エネルギー誤差・運動エネルギー比・摩擦比を監査します。開発途中の古い記録にはこの追加検査がないため、欠落項を合格と解釈しません。

## 再実行

既存出力は上書きしません。Python依存関係は従来のクラウド環境を使用します。

```bash
cd /workspace/mix_charging
source /workspace/environment/mix_charging/.venv/bin/activate
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=.
# 小規模検証セル。初期空隙率0.25%、100 mmの充填層ではない。
python tools/run_barrier_compaction.py --config configs/explicit-barrier-pressure.json --time-scale 2 --hold-seconds .002 --output results/new-small-pressure
# 既存入力の再実行（アーカイブ中の元設定・メッシュを使用）
python tools/replay_explicit.py --source exports/barrier-compaction-002/barrier-pressure-time32-001 --output results/new-pressure-replay
# 25 mm / 39.8592%入力の接触探索規模確認
python tools/preflight_barrier_model.py --candidate-budget 1000000 --output results/new-packing-preflight
# 未検証の40%→10%目標計算。1 MPaは探索上限であり達成荷重ではない。
python tools/run_barrier_compaction.py --config configs/porosity40-barrier-goal.json --case packing40 --output results/new-packing-goal
python -m pytest -q
```

検証セルの全方向2倍細分化は薄い空隙層に小質量節点を生み、刻み幅と計算費用が悪化したため中断・保存しました。`--refinement-pattern bulk --refinement 2` は空隙形状を変えず、薄層の厚さ方向分割だけを据え置く部分細分化で、全3次元メッシュ収束の代わりにはしません。100増分の費用試験のみです。

## 追加の接触・慣性比較

16 msのペナルティ2倍（40 MPa/mm）では最終空隙率0.2203661%、圧縮ひずみ16.30094%でした。標準設定との差は空隙率の分率で1.05e-5です。載荷中最大運動エネルギー比は1.0856%で不合格、最終力残差・エネルギー・接触数値仕事は合格です。ペナルティ収束を主張しません。

8 msの並進運動量ゼロの質量縮約では、最終空隙率0.2192557%、圧縮ひずみ16.30746%でした。従来32 msとの差は空隙率の分率で3.62e-7、ひずみで3.47e-5です。ただし載荷中最大運動エネルギー比は1.8598%で不合格です。材料や密度を変えず、力・質量・エネルギーを整合させた縮約の動作確認として保存し、速い載荷の解を準静的解として採用しません。既定の慣性設定も変更していません。

16 ms・減衰半分（3000 /s）では最終空隙率0.2192907%、圧縮ひずみ16.30518%でした。標準32 msとの差は空隙率の分率で1.16e-8、ひずみで1.18e-5です。ただし載荷中最大運動エネルギー比1.5224%で不合格です。減衰を変更したケースも診断用として保存し、標準設定の変更や物理解の採用には使いません。

## 空隙率目標制御・永久変形の独立試験

3 mm角・中央に1 mm角の空隙を持つセルで、初期空隙率3.7037037%から目標3.7032037%へ圧密する小変形試験を実行しました。載荷を4 msに遅くした試験は、目標で圧力保持・平衡確認して終了し、最終空隙率3.7032029%、載荷中最大運動エネルギー比0.1359%で全検査を通りました。これは制御ロジックの試験で、40%→10%の代用ではありません。速い初回試験の運動エネルギー超過も保存しています。

1 mm角の均質体では0.08 MPaまで載荷後に除荷し、ゼロ荷重で約10.1378%の永久圧縮ひずみを確認しました。16 msの載荷・16 msの除荷を用いた試験は運動エネルギー比0.3476%で全検査を通りました。空隙のない材料試験です。別に0.1 MPaの均質塑性平衡を `P λ = σy + H εp` と `log λ = −εp − Pλ/E` の独立スカラー根と比較しています。

この2試験の載荷を遅くして全検査の合格まで強化しました。周期画像の探索範囲変更時の非交差検査を追加し、最後に全123件を再実行して合格しました。元の失敗ログも結果ZIPに含みます。

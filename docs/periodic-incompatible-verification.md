# 周期C3D8Iの内部モードと圧縮・除荷の検証

実験用バックエンドで、周期境界・有限変形弾塑性のC3D8Iを実行した。
内部モードを含めたひずみ、平均応力、仕事の整合性と、圧縮分割数への依存を確認した。
これは本仕様100 mm角・0.1 MPaの計算完了や、メッシュ収束を意味しない。

[比較PNG・CSV・入力・メッシュ](../exports/periodic-modes-001/) /
[ZIP](../exports/periodic-modes-001.zip)。

## 条件と比較結果

ユーザー指定の粒径10 mm、ネック径2 mm、E=10 MPa、ν=0.33を使用。
降伏応力0.05 MPa、等方硬化係数0.2 MPaのJ2モデルは開発者定義の未校正試験材料である。
温度依存は入れていない。粘土の圧力依存性や実材料の圧密を再現した材料とは扱わない。

計算量を抑えた25 mm角、12粒子、39接合候補、1 mmメッシュ、6,372要素の
同一形状を3ケースで使用した。離散化後の初期空隙率は59.2192%。
20 mm角案は周期接続の独立方向数が2だったため除外し、3方向に連結する25 mm角を選択した。
乱数種は変更していない。この選択はRVEサイズ収束ではなく、本仕様の寸法も変更しない。
ネック径に対して要素幅は粗いままである。

| ケース | 最大Cauchy圧縮応力 MPa | 除荷後の残留圧縮 % | 除荷後の幾何空隙率 % |
|---|---:|---:|---:|
| C3D8・20分割 | 0.00319817 | 0.510248 | 59.042950 |
| C3D8I・20分割 | 0.00273575 | 0.568328 | 59.028798 |
| C3D8I・40分割 | 0.00273627 | 0.568223 | 59.028900 |

1%の巨視的軸方向圧縮後に軸荷重を解放した。C3D8Iの20→40分割で、最大Cauchy応力差は
0.0190%、残留圧縮ひずみ差は0.0184%。今回の探索用2%基準を満たす。
C3D8とC3D8Iの応力差は残り、メッシュや要素形式への依存は解決していない。
最大PEEQも0.113992→0.114104であり、局所ひずみのメッシュ収束を示さない。

巨視的変形勾配は既存実装と同じ対称6成分で表し、軸方向以外の一般化荷重をゼロとする。
有限変形で全Cauchy横応力を厳密に制御する手法とは区別する。
設定中のtarget_mpa=0.1はこの変位制御試験の到達応力ではない。
CSVは公称応力とCauchy応力を分けている。

## 内部モードの独立確認

CalculiX 2.20の実行ファイルを変更せず、ネイティブrestartから内部自由度を取得した。
形状関数の参照元はCalculiXソース
`fd588701edd6a92fde06e99b1bdf01f3b0f80f2c` の `shape8hu.f`、`genmodes.f`。
8角節点の勾配に3内部モードの寄与を加えて、各積分点のFを再構成する。
Fから得るGreen–Lagrangeひずみと、ソルバーが独立に出力したEを比較した。

restartリーダーはバージョン2.20、レコード構造、要素接続、内部節点座標、
物理節点・巨視自由度のDATとの一致を検査し、不一致は拒否する。
小端・4 byte整数・8 byte実数の当該レイアウト専用であり、他バージョンには一般化しない。
VOLDは材料名・材料割当の後という構造から特定する。
ゼロ荷重付近では速度配列VEOLDもほぼゼロになるため、値の近さだけでは識別しない。

40分割ケースのひずみ最大絶対差は5.00×10⁻⁹。
内部モードを省くと差は0.02196に増加した。内部モード変位の最大値は0.011395 mm。
旧8節点だけの後処理をC3D8Iに適用すると誤ることも確認できた。
通常の塑性CLIと旧エネルギー監査は、この実験用結果を明示的に拒否する。

## 応力、仕事、空隙率

各積分点で P=JσF⁻ᵀ を計算し、参照体積平均Pと現体積平均σを評価する。
周期条件による `P平均 F巨視ᵀ = J巨視 σ平均` も検査した。
MPCの寄与が欠ける節点RFを巨視反力として使用していない。

40分割ケースでは、周期変位残差2.76×10⁻¹⁵ mm、応力恒等式の相対差2.02×10⁻⁸、
巨視仕事 `V0∫P平均:dF巨視` と微視仕事 `∫∫P:dF dV0` の相対差7.87×10⁻⁷。
台形積分とソルバーELSEとの差は、圧縮端で0.00122%、全圧縮・除荷で0.145%。
ELSEは塑性仕事を含む累積内部仕事として比較し、回復可能な弾性エネルギーとは呼ばない。
除荷中の細かい経路の観測はしていない。

空隙率は、角節点の変形した幾何体積による値と、内部モードを含む∑J dV0による値を併記した。
両者の最大絶対差は3.77×10⁻⁷で、試験基準10⁻⁴以内。
今回の小変形範囲の整合性であり、大変形時の唯一の空隙体積定義が確定したとは扱わない。
**CalculiXの今回のEVOL出力は参照体積であり、変形後体積ではない。**
実行中は6,372 mm³の参照値との一致を別に検査した。

## 基礎試験、失敗記録、再実行

全35テストが合格した。新規試験では均質周期セル、中央空隙付き周期セル、
公称荷重既知の弾性セル、誤ったrestart/DATの拒否、旧後処理の拒否を確認した。
均質弾塑性セルの残留圧縮ひずみは約0.02465で解析的な材料応答と整合。
空隙付き荷重制御セルでは、公称応力0.001 MPaに対する相対誤差4.47×10⁻⁸。
この荷重試験も本仕様0.1 MPaの試験ではない。

クラウドの `results/periodic-mode-probe-001`〜`005` と
`periodic-modes-solid-001` には、内部節点NSET拒否やFRDからモード変位を
取得できなかった初期試行を保持した。FRDの出力件数だけから内部変位が含まれるとは判定しない。
`periodic-modes-force-002` の初期後処理はVOLD/VEOLDを識別できず拒否し、
元データを保持したまま `postprocess-v2-001` に構造判定で再処理した。
ソルバー本体・物理条件を変更して成功させたものではない。

圧縮の各観測点を独立した静的ステップにし、各端点でrestartを出力する。
ステップ内では自動増分を許す。正規化した観測段階は実際の時間や温度ではない。
主計算は `results/periodic-mode-verification-001` に保存。
初期ヘルパーのC3D8テンプレートメタデータは配布から除き、実行条件は
`mode-metadata.json` と `plastic.inp` に記録した。大容量DAT/FRD/restartはクラウドに保持する。

```bash
python tools/verify_periodic_modes.py --output results/periodic-mode-verification-002
python tools/summarize_periodic_modes.py --source results/periodic-mode-verification-002 --output exports/periodic-modes-002
pytest -q
```

既存フォルダは拒否する。実験用実装は `packing_fem/incompatible.py`。
次の課題は、周期C3D8Iの形状固定メッシュ細分化、自己接触、材料校正、
RVE寸法依存、0.1 MPaまでの荷重経路の検証である。

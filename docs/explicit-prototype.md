# 準静的陽解法FEM・周期自己接触・局所再メッシュの研究用初版

実行可能な新バックエンドを追加した。既存CalculiXモデルとは別の実装である。
**初期約40%のモデルは準備済みだが、40%→10%の圧密計算や100 mm角の検証済み解は得ていない。**

| 機能 | 今回の実装・確認 | 残る範囲 |
|---|---|---|
| 有限変形FEM | 適合線形四面体、有限ひずみ弾塑性、陽的時間積分 | 塑性の体積ロッキング・曲面形状・メッシュ収束 |
| 周期拘束 | 6成分の対称巨視変形、周期変位差、拘束を含む質量・仕事 | 非一致境界の補間/mortar、境界再生成 |
| 自己接触 | 同一骨格の非隣接面、自分の周期コピー、摩擦係数0.3 | 辺―辺接触、全面的な非貫入保証、圧密での接触収束 |
| 適応再メッシュ | 内部の2四面体→3四面体の再接続、履歴・体積・運動量の監査 | 自由表面の全面再生成、任意のゆがみの解消、粗大化 |
| 永久変形 | 拘束解放後に荷重をゼロへ下げる除荷で確認 | 実材料の校正と大規模な粒子層の除荷 |

## 構成と定式化

- [explicit_solver.py](../packing_fem/explicit_solver.py)：時間積分、収支・停止判定、除荷。
- [explicit_material.py](../packing_fem/explicit_material.py)：四面体、有限変形Hencky J2。
- [explicit_periodic.py](../packing_fem/explicit_periodic.py)：周期自由度と質量投影。
- [periodic_contact.py](../packing_fem/periodic_contact.py)：周期接触と摩擦履歴。
- [adaptive_tet.py](../packing_fem/adaptive_tet.py)：内部再接続と状態移送。

物理節点の質量を集中化し、`x = X + w[class(X)] + (Fbar-I)X` により周期自由度へ投影する。
対称Fbarの6成分を使い、軸成分の変位を指定し、他の一般化荷重はゼロとする。
周期変位差を厳密に満たし、揺らぎの並進を1クラスで固定する。
投影後の質量行列は一般に対角ではないため、拘束された質量方程式を解く。
剛性行列のNewton反復は行わず、質量の分解は再メッシュ等で質量が変わったときに更新する。

時間積分はVelocity Verletを基にし、弾性波、要素高さ、接触ばね、節点移動量から時間刻みを選ぶ。
これは大変形域での厳密な固有値安定限界の証明ではなく、時間刻み依存を別途確認する。
密度1e-9 tonne/mm³、質量比例減衰、載荷時間は数値試験用であり実測物性・実時間ではない。
選択的な質量スケーリングは実装していない。

E=10 MPa、ν=0.33、試験用降伏応力0.05 MPa、硬化係数0.2 MPaを初期設定とする。
温度依存性と材料の粘性は導入しない。
材料点は弾性左Cauchy–Greenテンソルbと相当塑性ひずみを保持し、増分変形でbを更新する。
弾性対数ひずみからKirchhoff応力を求め、等方硬化のJ2リターンマッピングを行う。
塑性流動は等容、弾性は圧縮性を保つ。

**降伏・硬化はKirchhoff応力で定義する試験モデルであり、CalculiXの有限変形積分と同一とは扱わない。**
E・ν・初期の数値を合わせただけで、既存ソルバーと大変形応答が一致するとは仮定しない。
骨格材の圧力依存圧密、破壊、ネック破断は未実装。塑性ひずみ5を超える試行は材料範囲の上限として停止する。

## 周期自己接触

自由表面の節点―三角面ペナルティ接触を二方向から評価する。
参照節点負担面積A0を用い、法線力を `kn A0 δ`、蓄積エネルギーを `kn A0 δ²/2` とする。
二方向の重複を避けるため各方向の負担面積を半分にする。
面積が変形しただけでペナルティポテンシャルを変えない定式化である。
接触ばねの値は物性ではなく、貫入と応答の感度検証が必要な数値設定である。

接線ばねにCoulomb上限 `|ft| ≤ 0.3 fn` を適用し、すべり散逸、接線蓄積、履歴消失に伴う
数値的なエネルギー解放を区別して記録する。接線履歴は面の局所座標に保持する。
物体全体がつながっているという理由で自己接触を除外しない。
近傍除外は材料の参照座標での隣接関係と**周期移動量**から判断する。
同じ節点クラスを含む遠い周期コピーを、隣接面と誤認して一律に除外しない。

反対側に対応する三角面があるセル切断面だけを接触対象から除く。
セル平面上でも対向材料面がない面は実際の空隙表面として残す。
周期画像は現格子から探索範囲を計算し、上限超過時は画像を切り捨てず停止する。
周期画像に作用した力の巨視的な仕事も加える。節点の力だけを足して周期仕事を欠落させない。

本版は一致した周期境界メッシュを前提とし、辺―辺衝突等は扱っていない。
移動量制限と観測した貫入量の上限だけでは全面的な非貫入を保証しない。
許容貫入0.02 mmは試験設定であり、実用圧密の許容値として確定していない。

## 局所再メッシュと保存

要素品質 `q = 12(3V)^(2/3)/Σ(edge length²)` を用いる（正四面体は1）。
既定ではq<0.35を調査対象とし、凸な2要素の空洞を3要素へ再接続する。
境界三角面が変わらず、体積が等しく、空洞内の最小品質が5%以上改善する候補だけを試す。
参照体積を保存し、弾性対数ひずみ・相当塑性ひずみを体積で移送する。
一様な状態は再現し、非一様な状態では塑性履歴を平滑化する誤差があるため、エネルギー誤差で受否を判断する。

質量投影後の一般化運動量を保つよう速度を写し、運動エネルギー、物理的な並進・角運動量の差も検査する。
状態移送・速度投影の試験用許容値は0.001。超過した候補は受理しない。
自由表面が変わらないため接触面の識別と履歴は保持できるが、接触が進行中の再メッシュ受理はまだ未検証である。
要素の削除や塑性履歴のゼロ初期化で継続しない。
最小品質0.03を下回り修復できない場合などは停止する。この方式は任意の表面つぶれを解消するものではない。

## 体積、準静的性、停止

適合四面体の体積和、閉じた境界面の発散定理による体積、材料状態の体積変化を照合する。
空隙率は `1 - Vsolid/(det(Fbar) Vcell0)`。
体積和と境界体積が一致しても、重なりを含む形状の物理的な正しさを保証するわけではない。
負の空隙体積、非正のJ、移送誤差、品質、接触移動・貫入、時間刻みやステップ上限の違反で停止する。
失敗した次の試行点を解として保存せず、最後の有効な形状と停止理由を診断として残す。

十分に載荷された区間で運動エネルギー/内部仕事変化が1%未満、最終の静的残差が代表力の2%未満、
エネルギー収支差が2%未満等を試験用の個別条件とする。
エネルギー収支には外部仕事、弾塑性内部仕事、接触蓄積、摩擦、減衰、運動エネルギーを含める。
初期の塑性仕事の定数分は増分の正規化から除き、衝突試験の非ゼロ初期運動エネルギーは入力エネルギーに含める。
途中の反力に慣性が混じるため、比率だけでなく載荷時間・密度・減衰・刻みの感度も確認する。

全個別条件を満たしても `prototype_checks_passed_not_mesh_or_contact_validated` とする。
不合格は `diagnostics_only`。この版に「検証済みの実材料圧密解」という自動状態はない。
旧8節点の仕事監査やCalculiXの実行経路は新しい結果を明示的に拒否する。

## 実行した検証

ソフトウェア全体は **60テスト合格（新規18件）**。
客観性、塑性等容、静水圧弾性、周期変位・仮想仕事、同一骨格と自分の周期画像の接触、
摩擦上限、周期画像の接触仕事、保存的な接触ポテンシャル、再接続の境界・履歴・体積、
不適切な状態移送の拒否、除荷、旧監査の拒否を確認した。

| 計算試験 | 結果と適用範囲 |
|---|---|
| 均質周期セルの自由横変形 | 有限Hencky弾性の解析値と一致。弾性限界の分離用に大きな降伏応力を使用 |
| 中央空隙付きセル | 初期空隙率3.7037%、0.5%圧縮。40%粒子層とは別の基礎試験 |
| 載荷時間2倍 | 最大公称応力差0.01463%、最終空隙率差4.55e-8 |
| 時間刻み係数0.2→0.1 | 最大公称応力差0.000367% |
| 数値密度半分／減衰半分 | 最大公称応力差0.00392%／0.01005%。大規模・接触中の不変性は未検証 |
| 塑性履歴付き再接続 | 製作した不良メッシュで5回受理。PEEQ=0.2は状態移送試験の人工初期値。補正したKE比0.3224% |
| 3%圧縮後に軸荷重をゼロへ解放 | 約2.4651%の残留圧縮。変位をゼロへ戻す試験ではない |
| 動的衝突による統合確認 | 同じ計算内で初期再接続を1回受理し、その後最大8接触を観測。貫入上限で停止し不合格 |

最後の衝突試験は、内部自由表面に与えた人工的な初速による**動作確認**であり、
準静的検証ではない。接触前の時刻0での再接続と、その後の接触は確認したが、
接触が発生中の再メッシュ受理を実証したとは扱わない。
最終有効貫入は約0.019997 mm、エネルギー残差約0.003024 Nmm、
初期運動エネルギー0.1764 Nmmに対する収支差約1.714%。
貫入上限・経路完了・準静的性の問題をエネルギー合格で相殺しない。

`results/explicit-contact-integration-002` の別試験は接触が発生せず、10万ステップ上限と
準静的性で不合格になった。全記録を配布に含めた。
初期のJSON出力エラー、毎ステップの再メッシュ探索を中断した試行、衝突の初期試行も保持した。
非ゼロの初期運動エネルギーを正規化に含めなかった初期の報告値も上書きせず、
配布の `verification.json` に入力エネルギー・内部仕事変化から再評価した値を併記した。
数値条件を緩めて準静的な接触解を得たとは報告しない。

## 初期約40%のモデルと実行方法

元の18粒子・ネック径2 mm、25 mm角、初期空隙率39.8592%を、
14,320節点・56,382適合四面体へ変換した。
ボクセルの各六面体を整合する6四面体に分割したもので、球曲面の解像度改善ではない。
[準備済みモデル](../exports/explicit-fem-prototype-002/prepared-40percent-model/)にはメッシュと設定を収録した。
軸圧縮45%は探索幅であり、空隙率10%との対応を仮定していない。
数値載荷時間0.02、保持0.01は実測の秒数ではない。初期約40%モデルの圧密経路は未実行。

既存のNumPy/SciPy等を使用し、新しいソルバーやライセンスを導入していない。
リポジトリの作業ディレクトリと既存仮想環境で実行する。既存結果フォルダは拒否する。

```bash
python tools/verify_explicit_backend.py --output results/explicit-verification-007
python tools/verify_explicit_remesh.py --output results/explicit-remesh-003
python tools/run_explicit_model.py --output results/explicit-porosity40-model-002 --prepare-only
# 保存した入力を新しい結果ディレクトリへ再実行する
python tools/replay_explicit.py --source results/explicit-unload-001 --output results/explicit-unload-002
```

大規模実行は研究用の5,000要素制限を超えるため `--allow-large` が必要。
これは資源予算の明示指定であり、計算精度の承認や計算時間の保証ではない。
`progress.jsonl`、`history.csv`、`summary.json`、内部状態NPZ、最終VTUを出力する。
次の必須課題は、曲面・間隙のメッシュ収束、接触が進行中の再メッシュ、
辺―辺等を含む接触と非貫入の検証、自由表面の再生成、40%モデルでの準静的な圧密検証である。

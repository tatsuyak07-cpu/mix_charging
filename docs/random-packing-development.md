# ランダム充填層：工程1〜4

## 条件と範囲

16粒子の単一ランダム実現を用いる。球径10 mm、焼結ネック径2 mm、E=10 MPa、ν=0.33、
新規接触の摩擦係数0.3を維持する。降伏0.05 MPa・硬化0.2 MPaは従来の開発用試験値。
横方向の周期ベクトルを初期値に固定し、軸方向の巨視的圧縮だけを与える。
変位制御で軸圧縮し、反力から公称圧力を計算する。
今回は工程4までなので、載荷状態の空隙率約10%への圧縮を対象とし、保持・除荷は行わない。

これは重力投入・製造時の焼結履歴を再現するモデルではない。
球中心をランダムに初期化し、周期的な重なり解消最適化で初期形状を生成する。
その生成器から荷重・応力の計算結果を出さず、以後の圧縮を3次元固体FEMで計算する。
規則格子を初期化したり、その格子を微小に乱した配置ではない。

## 工程1：周期ランダム配置

乱数シード20261109、16粒子。先行シード20261107と20261108は、それぞれ0.18684 mm、
0.03324 mmの球の重なりが残ったため不採用とし、最適化後の配置・ログ・理由を保存した。
あらかじめ設けた連続20シードの予算内で、最初に幾何学条件を満たした配置を採用した。
FEMの荷重結果を見てシードを選んではいない。

採用配置の最小中心間距離10.01247 mm、球の重なりはゼロ。
同じシードから同一の中心位置と接続を再生成できることを試験した。
接続方向テンソルの固有値は0.2674、0.3628、0.3698。
小さい1標本なので、統計的等方性・代表体積要素としての妥当性は認定しない。

## 工程2：焼結形状

初期配置で表面間隔0.4 mm以内の近接粒子を接続し、空隙率調整後の間隔を0.5 mm以内に制限した。
接続は56本、平均配位数7、最小配位数4。最終的な最大表面間隔は0.31666 mm。
周期画像を含めた接続グラフは1成分で、3方向の周期巻付きランクが3。
長い空隙を任意の棒で架橋する接続は追加していない。

球径とネック径を変えず、初期セル長を24.109757 mmに決めることで、
ネックも含めたCAD空隙率を40%に合わせた。これは初期形状の設定であり、
**圧縮中に横周期寸法を変える操作ではない**。

非重複球と各円柱の球外部分を独立に積分した体積と、OpenCASCADEのブール和体積を比較した。
円柱長d、球半径R、ネック半径rに対する追加体積は、
`π r² d − (4π/3)[R³ − (R²−r²)^(3/2)]`。
CAD空隙率0.3999999783と解析積分値0.4の差は2.18e-8。
当初の1e-8という比較閾値を超えたため、積分APIの数値誤差として1e-7を明示した。
形状・材料パラメータや体積の補正は行っていない。

## 工程3：周期メッシュ

球・円柱の和集合を周期セルで切断し、対向する切断面にGmshの周期対応を設定する。
セル内では複数のCAD片に分かれていても、周期的には同じ骨格としてつながる。
Gmshの節点に最大2.49e-8 mmの周期対応差があり、保存されたアフィン対応から
slave座標を再構築した。許容する数値補正予算は1e-6 mmとし、これを超える場合は拒否する。
元のメッシュファイルも保存し、再構築後の正体積と周期トポロジーを確認した。

初期空隙率の許容差を±0.5パーセントポイントとして、次の幾何学近似を比較した。

| メッシュ | 初期空隙率 | 判定 |
|---|---:|---|
| 004：h=1.2 mm | 40.6685% | 初期空隙率許容差を超過 |
| 005：h=1.0 mm | 40.5720% | 同上 |
| 006：表面距離によるサイズ指定 | 40.6031% | 同上 |
| 007：表面サイズ上限を明示 | 40.4037% | 工程4の入力に採用 |

採用メッシュは21751節点・66060四面体。粒子表面のサイズ上限0.7 mm、
ネック付近0.65 mm、粒子内部のサイズ上限2.5 mmの段階的な分割を使用する。
初期最小要素品質0.1081、正の要素体積、周期対応差ゼロ、周期骨格1成分・巻付きランク3を確認した。
これは形状近似の確認であり、圧縮応答のメッシュ収束が合格したという意味ではない。

## 圧縮計算の記録方法

`loading_only=true` とし、収束した載荷状態の空隙率が10.1%以下になったところで終了する。
この0.1パーセントポイントは従来からの目標判定幅であり、厳密に10.000%へ補正しない。
力の最大自由残差0.005 N未満、巨視的圧縮量の誤差1e-6未満、摩擦更新後の釣り合いを
各増分で確認する。反復上限を超える場合は失敗配置を保存し、増分を半減して再試行する。
未収束配置を空隙率曲線に含めない。

保存済み10%圧縮状態の接線行列で、疎行列並べ替えの計算時間も比較した。
COLAMDは分解3.46秒、MMD_AT_PLUS_Aは176.40秒で、解の最大相対差5.54e-13、
連立残差はいずれも6e-11未満だった。後者は採用せず、従来のCOLAMDを維持した。
これは同じ連立方程式の計算費用の比較であり、材料・接触・増分の収束検証ではない。
比較結果と実行ソースも保存する。

`tools/audit_compaction_history.py` は保存された各収束状態で、正の四面体体積、
基準材料体積の保存、材料履歴の `Σ(V0 J)` と実要素体積の一致、CSV空隙率の再計算、
横方向の巨視的変形および力残差の基準を監査する。
J2塑性変形は等積だが、ν=0.33の弾性部分は圧縮可能であり、現在の固体体積の厳密な保存は課さない。
既知の20%弾性体積圧縮を受理する試験と、体積と整合しない材料履歴を検出する試験に合格した。
周期接触は `tools/audit_implicit_states.py` で周期画像27個と125個の接触数・力・エネルギー、
表面の非交差を比較する。これらの整合確認だけで、空間・増分収束を認定しない。

## 接触後の反復の安定化

2.5%増分の17.5%圧縮では、摩擦更新後の釣り合いが15回の外側反復内で収束せず、
失敗配置を保存して増分を半減した。別に15%圧縮状態から5%増分の分岐を開始した。
両方の未加速計算を保存し、同じ摩擦平衡式に対するAnderson加速を追加した。

加速は既定では無効。試験設定では4状態の写像残差を用い、mm単位の変位として
巨視的ひずみ成分をセル長で重み付けする。係数のL1ノルムが10を超える提案は棄却する。
CCD・正の要素体積・巨視的目標誤差を確認し、摩擦を更新した実際の力残差が減る提案だけを使う。
材料テンソル・塑性ひずみを平均化せず、候補位置で元の構成則を再評価する。
反復予算は50回へ増やすが、力0.005 N・巨視的誤差1e-6の判定基準は維持する。
既知の線形写像の固定点、加速有無の有限弾性一軸ひずみ解など、関連38テストに合格した。
実充填層での比較・完走の判定は、計算結果として別途記録する。

さらに `implicit_project_material_tangent=false` では、要素ごとの正定値化をせず、
構成則から得た整合接線を使う。連立方程式を解けない場合や下降方向を得られない場合は、
従来の正定値化接線へ戻る。塑性状態の力の中心差分と整合接線の積を独立に比較した。
初期推定配置の有無・接線方式・加速有無の全8条件で有限弾性の解析解を確認し、関連45テストに合格した。

初期推定配置を用いる弾性試験では、厳密なエネルギー減少判定が丸め誤差で停止する2条件を検出した。
探索中のエネルギー差が `32 eps max(E ΣV0, |Π|)` 以下の場合に限り、
同じ外側摩擦状態で力残差が減ることを確認して探索点を受理する修正で解消した。
最終の力・巨視的変位の合格基準は変更しない。修正前の失敗ログも保持する。

`--initial-iterate` は失敗配置を反復の初期推定値として再利用するためのオプション。
その旧配置・材料テンソル・塑性ひずみが指定した収束済み再開状態と一致することを確認する。
材料履歴・積分重みは収束済み状態から読み、失敗配置を解や新しい材料履歴として採用しない。
初期推定配置自体の非交差・正体積も確認し、以降の全判定は通常通り行う。

`ipc_project_tangent=false` では接触のヘッセ行列も正定値化せず、実接触力の差分と一致する接線を使う。
この場合の下降方向判定に失敗したときは、材料・接触の両方を正定値化した方式へ戻す。
滑らかな頂点／面接触で接線と接触力の差分を比較した追加試験を含め、関連46テストに合格した。
材料・摩擦則と収束基準は維持し、反復方式を変えた試行の設定とソースを別々に保存する。

## 増分エネルギーの直接最小化

実メッシュ・保存済み塑性履歴でも、材料と接触の接線は力の差分に対して約1e-7の相対誤差で一致した。
Newton方向のエネルギー微分も実エネルギー差分と一致したが、全更新ではエネルギーが増え、
探索で小さい更新に戻る非線形性が確認された。単に接線の正定値化を外すだけでは反復は速くならなかった。
診断配置・設定・ソース・更新候補は保存し、診断候補を解として使わない。

追加した `implicit_optimizer=lbfgs` は、同じ増分エネルギーと同じFEM力を最小化する。
軸方向の周期寸法を厳密に指定し、自由な微視的変位だけを最適化するため、
Newton方式で使った数値アクチュエータは使わない。横周期寸法は固定のまま。
正定値化したFEM・接触接線を前処理に使い、25反復ごとに更新する。L-BFGS履歴は10組。
接触数が10%以上変化するか、残差が前処理作成時の5倍を超えた場合も前処理を更新し、
古い接触状態で作ったL-BFGS履歴を破棄する。
CCD・正体積・エネルギー減少を満たす更新だけを採用し、力の最大残差0.005 Nは維持する。
摩擦を更新した後も同じ力の基準を満たすまで反復する。
初期推定に非一様変位を加えた有限弾性解析解など、関連55テストに合格した。
この開発用バックエンドの範囲は横寸法固定・変位制御の圧縮までとする。

実充填層では17.5%圧縮・空隙率27.9983%まで収束し、旧方式の停止区間を通過した。
摩擦更新後の最大残差は0.001414 N、両横周期寸法24.109757 mmを維持した。
以降の20%圧縮と空隙率10%への計算を継続している。

## 再実行

依存関係は既存の `requirements-implicit.txt`。新しい出力先を指定する。

```bash
PYTHONPATH=. python tools/generate_random_packing.py \
  --config configs/random-periodic-compaction-lbfgs-fine.json --seed-start 20261107 --out results/new-random-input
PYTHONPATH=. python tools/build_random_sintered.py \
  --config results/new-random-input/resolved-config.json \
  --packing results/new-random-input/packing.npz --out results/new-random-mesh
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python tools/run_implicit_compaction.py \
  --config results/new-random-input/resolved-config.json \
  --mesh results/new-random-mesh/mesh.npz --out results/new-random-compression
```

初期形状と失敗試行は `results/random-packing-001`、採用メッシュは `mesh-007`、
圧縮は `compression-001` に保存する。規則配置の過去結果は変更していない。

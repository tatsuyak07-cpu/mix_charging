# 工程4：小周期焼結充填セルへの組み込み

直径10 mmの球、直径2 mmのネック、E=10 MPa、ν=0.33、摩擦0.3を使う小周期セルを実装した。低荷重の圧縮計算は独立な線形FEM解、応力平均、時間刻み半減と照合した。**0.1 MPaまでの準静的な大変形圧密と、空隙率40%→10%は未完了**。工程4の小セル基盤を実装した段階であり、任意の充填体の大変形が検証済みという意味ではない。

[判定結果](../exports/packing-rve-001/summary.json)・[検証図](../exports/packing-rve-001/packing-rve-validation.png)・[実メッシュ](../exports/packing-rve-001/actual-packing-mesh.png)・[計算・不合格試行・ソースZIP](../exports/packing-rve-001.zip)。

## 小モデルと元の依頼の関係

100 mm角のランダム充填層をそのまま小さくしたものではない。2個の周期的な球と、8本の対角方向のネックを持つBCC単位セルを、結合実装の開発対照に用いた。セル長12.1 mmは開発者が選んだ値で、粒径とネック径を変更して空隙率を合わせる処理はしていない。剛体円柱、温度依存性、粒子の摩擦接触への置き換えは含まない。球とネックの和集合を四面体の**固体FEM**で解く。

形状はボクセル化し、各立方体を適合する6四面体に分割する。基本メッシュは16分割、3,791節点、14,784四面体、初期空隙率39.84375%。ボクセル幅0.75625 mmでネック径当たり約2.64セルしかなく、ネックの形状・剛性は未収束である。周期の面連結成分が1、巻き付き階数が3、初期接触力が0であることを確認した。

連続形状の空隙率は約40.066185%。球半径R、ネック半径a、最近接中心間距離d=√3 L/2について、細いネックが端部の球の外で互いに重ならない条件では、1本の露出ネック体積は

`π a² d − (4π/3) [R³ − (R²−a²)^(3/2)]`

となる。セル体積から球2個と露出ネック8本の和を差し引いて求め、64分割の独立な形状積算とも照合した。連続形状と離散形状の空隙率を混同していない。

材料は従来と同じ、Kirchhoff応力で定義した有限変形Hencky J2の試験則である。降伏応力0.05 MPa、硬化係数0.2 MPaは粘土様の残留変形を試すための未校正値であり、焼結鉱の実測値ではない。数値密度1e-9 tonne/mm³、減衰6,000/sも従来と同じ。ネック内部は連続した固体で、摩擦0.3は新たな自己接触にだけ用いる。

## 工程3から追加した機能

* **接触停止からの再試行**：真の辺接近を検出した試行を破棄し、その直前に採用した状態で対応辺を分割する。全移行監査に合格したときだけ、新しい質量・周期自由度・履歴で同じ時刻からステップを計算し直す。人工的な辺ばねは加えない。分割の採用失敗、イベント上限、他の未対応接触は引き続き停止する。
* **等距離の最短点**：`closest_tie_rule="clarke"` という試験機能を追加した。通常設定は `"stop"` のまま。相手が同じ接続パッチの場合、法線エネルギーは従来と同じ `B(min d_i)=max B(d_i)` の1個分とし、等距離で異なる最短点に限って枝の勾配の凸結合を用いる。別々の面のエネルギーを二重に加算しない。
* **周期変位の直接復元**：反復的な最小二乗解法を、固定した巨視的ひずみと周期クラスごとの微視変位による直接復元に置き換えた。周期的に不整合なデータを平均して隠す処理はしない。

等距離の試験則は、滑らかな枝の最大値のClarke劣勾配に基づく。現在の実例では2本の枝が等距離で、中心差分で両者の平均勾配を独立に照合できる。法線方向は平均反力方向とし、摩擦ばねの上限には平均反力の大きさを用いる。新しい接触の摩擦ばねをゼロで初期化し、既存の材料接触点と輸送される履歴は保持する。相反する法線で摩擦平面が定まらない場合は停止する。

保存した実際の停止形状で、法線ポテンシャルと力、力・モーメントの釣り合い、回転客観性、非ゼロの摩擦履歴を含む全ポテンシャルの数値微分、Coulomb上限を検証した。**この試験則を用いた大変形一周期の刻み・メッシュ収束は未検証**である。低荷重の刻み半減は自己接触がないため、この試験則の時間収束の証拠には用いていない。

## 計算負荷への対応

接触候補を捨てたり、密度・材料・接触有効距離を変えることでは対応していない。

`triangle_mass_bound` は、従来の組み立てGershgorin上限を三角不等式で上から評価する計算経路である。Lamé係数が負になる弾性定数も含めて、従来の上限を下回らないことを照合した。`active_contact_timestep=true` は、有限距離バリアの範囲外では接触剛性が0になることを使う試験設定で、採用した接触の対角上限、運動量による刻み制限、非交差の線形ステップ検査は維持する。低荷重での刻み半減を別途実施した。

C++17の要素カーネルを明示的なオプションとして追加した。ネットワーク接続や自動インストール・ビルドを計算コードへ入れていない。既存のNumPy経路が通常設定であり、ビルドは別のコマンドで行う。コンパイルに `fast-math` は使用しない。対称3×3テンソルのJacobi固有値計算には収束検査を設け、不正な固有値をクリップして計算を続ける処理はしない。

材料更新、力・エネルギー、要素形状、時間刻み上限、反転負荷、圧力積分をNumPy経路と照合した。実際の塑性充填セルについても、停止までの3,722ステップを比較し、停止理由とステップ数が一致した。最大節点差2.26e-12 mm、弾性テンソル差7.86e-13、相当塑性ひずみ差7.66e-13。これは計算経路の整合性検査であり、停止した計算を物理解として認めるものではない。

## 低荷重の圧縮対照

0.001 MPaのCauchy圧力を8 msの五次ランプで加え、2 ms保持した。荷重値は実装の弾性極限を検査するための対照であり、依頼された0.1 MPaの代わりの結果ではない。CFL0.2と0.1の同じプロトコルを計算し、最終値と全履歴を照合した。

CFL0.2の計算では、既存の全判定に合格。最終軸圧縮約0.0472092%、空隙率約39.8322383%、最大の判定対象KE/内部エネルギー比約0.003857、エネルギー残差約1.61e-6、静的残差比約3.69e-7となった。自己接触は発生しておらず、この対照だけで摩擦応答や接触積分を検証したとは扱わない。

独立した疎行列の線形FEMで周期微視自由度を緩和し、巨視的な6成分剛性の正値性、仕事と弾性エネルギーの一致、応力の体積平均を確認した。非線形計算の軸圧縮と線形解の差は約0.0208%。保存状態からの別の面力積分による力の再組み立ても照合した。刻み半減による最終軸圧縮差は1.34e-12、最終空隙率差は1.90e-12、全履歴の最大空隙率差は7.08e-11だった。全体247テスト（C++専用テストも実行）と、小セルの総合照合11項目に合格した。詳細は公開JSONとCSVを参照する。

同じ12.1 mmの連続形状を32分割すると、初期空隙率39.55078125%、24,891節点、118,848四面体となる。初期軸剛性は基本メッシュの約2.118 MPaから約1.186 MPaへ約44%変化した。**メッシュ収束していないため、材料の均質化定数や物性予測とは呼ばない。** BCCの幾何対称性も統計的等方性の証明ではない。

## 大変形の試行と残る課題

0.1 MPaを4 msで加える高速の開発試行では、適応処理なしの場合、軸圧縮約12.51%で真の辺接近により停止した。辺分割だけを有効にすると、2回の状態移行後、隣接する2三角形への異なる等距離最短点で停止した。実際の形状と候補を再現して保存している。

等距離の劣勾配を有効にした試行では、10回の表面分割を採用し、最大12個の接触記録を扱った。停止時の途中状態は軸圧縮約15.67%、空隙率約34.27%、指令圧力約0.05674 MPa。エネルギー・体積・Coulombの判定は通過したが、運動エネルギー比約0.1057で準静的条件を満たしていない。**これらを圧密の平衡曲線や0.1 MPaの解として扱っていない。**

最後の再分割提案は、周期変位の反復復元誤差1.8635e-9 mmが許容値1.21e-9 mmを超えて拒否された。直接復元への修正後、同じ保存済み提案の誤差は1.7764e-15 mmとなり、材料状態・摩擦履歴・エネルギー・巨視的接触力の移行監査にも合格した。ただし**修正後に大変形の全履歴を計算し直した結果はまだない**。

また、繰り返す辺分割により最小品質は約0.756から約0.052へ低下し、最後の提案では約0.033となった。単なる細分化では品質回復を保証できない。次には、局所的な再生成・粗大化、接触履歴を持つ材料点の移行、より遅い負荷と刻み比較を組み合わせ、大変形の圧力履歴全体を再検証する必要がある。既存の品質下限0.03や移行監査の許容値を緩める変更はしていない。

## 再現方法

Python環境は既存のものを使用する。単位はmm、N、MPa、tonne、s。コマンドの出力先は、毎回新しいディレクトリにする。

```bash
export PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
PY=/workspace/environment/mix_charging/.venv/bin/python
$PY -m tools.build_native_kernel \
  --directory /workspace/environment/mix_charging/native > /tmp/rve-native-build.json
```

ビルド結果JSONの `library` のパスを、次の `LIBRARY_PATH` に指定する。

```bash
$PY -m tools.run_packing_rve \
  --config configs/packing-rve-elastic-check.json \
  --native-library LIBRARY_PATH --output results/new-rve-elastic-check
PACKING_FEM_NATIVE_LIBRARY=LIBRARY_PATH $PY -m pytest -q
```

コンパイラはg++を使用した。C++経路をビルドしない場合は `--native-library` を省略してNumPy経路で実行できる。C++専用テストは環境変数がないときだけ明示的にskipされる。今回の全体検査ではビルド済みライブラリを指定し、これらのテストも実行した。

`configs/packing-rve-development.json` は高速の0.1 MPa試行の準備用で、成功や準静的条件を保証する設定ではない。各公開計算には実際の設定、実行当時のソース、使用ライブラリのハッシュ、全採用ステップ履歴、最終保存状態、不合格理由を含めた。最新ソースと実行当時のスナップショットを区別している。公開成果物の全ファイルのSHA-256とZIPのCRCも照合した。

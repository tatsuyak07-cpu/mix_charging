# 非中点の辺分割における状態・摩擦履歴の移行検証

**保存した停止直前の状態では、接近する両側の辺を最短位置で分割する2案とも移行監査を通過した。追加節点が接触中になる別試験でも、摩擦履歴の補間と分割後の滑りを確認した。** 圧縮の時間積分は行っておらず、非中点分割の自動選択はまだソルバーに組み込んでいない。

[比較画像](../exports/weighted-transfer-001/weighted-transfer.png)、[判定JSON](../exports/weighted-transfer-001/summary.json)、[全データZIP](../exports/weighted-transfer-001.zip)。前段は[分割位置の幾何検証](refinement-diagnostics.md)。

## 変更した移行処理

`surface_remesh.bisect` に、向き付きの辺A→Bの挿入位置fを指定できる機能を追加した。位置は(1−f)A+fBで、既定値は従来どおりf=0.5。周期コピーで節点の番号順が逆の場合は補間重みも反転する。

参照位置・現在位置・速度は同じ重みで補間する。子要素は親の弾性状態テンソルと相当塑性ひずみをコピーし、参照体積は子と親の実際の参照幾何体積の比で配分する。塑性ひずみを節点平均していない。

追加接触節点の材料アンカーは参照・現在の両配置で同じ重みを使う。弾性すべりは世界座標のベクトルとして重み付き補間し、追加節点の接線座標系へ戻す。既存節点の材料アンカーは保持する。接触履歴が一意に対応しない場合や、アンカーを両配置で正確に表現できない場合は従来どおり拒否する。

すべての非中点分割が保存則を自動的に満たすという保証はない。節点集中質量の再配分や接触積分点の追加で運動・接触エネルギーが変わり得るため、監査は引き続き必要である。保存済みの重みを持たない旧提案は従来の中点として扱う。

## 保存状態での監査

前回の0.1 MPa載荷試行が停止した直前の**採用状態**を使用した。最短位置fは拒否された次の試行の形状から求めた値で、監査の対象は採用状態で作成した分割案である。前段の試行形状だけの品質値とわずかに異なる。

材料・荷重・周期条件・摩擦係数は変更していない。E=10 MPa、ν=0.33、試験J2降伏応力0.05 MPa、硬化係数0.2 MPa、μ=0.3。監査許容値0.001、品質下限0.03は維持した。

監査は質量、並進・角運動量、運動・材料・接触・法線・接線エネルギー、巨視的接触力、Coulomb上限を確認した。エネルギー等の正規化は既存の `surface_remesh.audit` と同じで、誤差が小さく見えるように分母を変更していない。速度は補間後、既存の周期質量行列により周期自由度へ射影した。

法線接触エネルギーは前後とも約0.00226011 N mm、接線接触エネルギーは約0.000382664 N mmである。この保存状態では追加節点が新しく接触履歴を持たないため、12件の既存履歴の保持だけでは追加節点への補間を検証したことにならない。

## 追加接触節点と回帰テスト

周期的な平面接触試験でf=0.2、0.5885708790、0.8を使用した。追加節点が接触履歴を持つこと、分割前後の接線エネルギーと巨視的接触力が許容値内にあることを確認した。さらに接線変位を加え、滑り時の摩擦仕事が正で、摩擦力と法線力の比がμ=0.3となることを確認した。

端点の弾性すべりが異なる試験では、追加節点の世界座標の弾性すべりが幾何重みの補間と一致し、単純平均とは異なることを検証した。この非一様場の試験は補間そのものを確認するもので、任意の非一様場の接触積分誤差が必ず許容値に収まるという主張ではない。接線エネルギーを意図的に消した場合は監査が拒否した。

新規の最終9テストが合格。従来の中点分割については保存済み旧実装との位置・要素・材料状態・参照体積・速度・親子対応の各配列が完全一致した。逆順の周期対応辺、向き付き辺の反転、参照体積とアフィン速度場の保持も確認した。

全体260テストも合格し、失敗・skipはない。ネイティブ要素カーネルのテストも実行した。全体実行の収集後に追加した2件は、最終の新規9件の実行で確認した。

初回の新規テストは6件合格・1件失敗だった。失敗は試験用の逆順四面体を正の向きへ並べ直していなかったためで、試験形状を修正した。失敗ログは削除せず保存している。

## 未完了の範囲

非中点分割の自動的な候補比較・選択、品質回復、試行棄却からの再分割・再試行への接続は未実装である。既存ソルバーは引き続き中点分割を使う。今回の監査で通過した提案も時間積分の状態として採用していない。

次は、接近する両側の辺について候補を作り、品質・保存則・接触履歴監査を通過した案だけを選ぶ処理を検証する。その後、接触ガードを解消して積分が継続するか、全圧力履歴と載荷速度・刻み依存性を確認する。0.1 MPaの準静的解、初期空隙率40%→10%の圧密は未達成である。

## 再現

既存環境を使用し、追加インストールや設定変更は行っていない。出力先は毎回新しくする。

```bash
export PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
PY=/workspace/environment/mix_charging/.venv/bin/python
CALC=exports/packing-rve-replay-001/validation/corrected-run/calculation
$PY -m tools.audit_rve_remesh_proposal --source "$CALC" \
  --edge 3793 3795 --fraction 0.5885708790180821 --output results/new-target-audit
$PY -m pytest tests/test_weighted_surface_transfer.py -q
```

ZIPには入力状態、接触履歴、両分割案、補間重み、監査結果、診断時ソース、失敗を含むテストログを保存した。
`proposal.npz` の速度は周期射影前の補間値であり、監査ではツール内で周期質量行列への射影を再実行する。

# 連結セルの初期剛性細分化と弾性除荷の対照試験

4 mm角・初期空隙率0.25%の連結セルを検証する。直径10 mmの球充填層、初期空隙率40%→10%の圧密結果ではない。
E=10 MPa、ν=0.33、試験用Hencky/Kirchhoff J2材料（降伏0.05 MPa、硬化0.2 MPa）、新規接触摩擦0.3を維持する。
本試験では圧力0.02 MPaで塑性化しないことと、除荷後に元の形状へ戻ることを対照として検査する。塑性域の永久変形の検証は別途必要。

## 形状を固定した初期弾性の細分化

周期微視自由度を静的縮約し、6成分の巨視的変形に対する接線剛性を計算した。側面自由の一軸応答の軸方向コンプライアンスは縮約行列の逆行列のzz成分。単位は1/(N mm)。

| 細分化 | 節点 | 四面体 | 軸コンプライアンス | 前段との差／当段 |
|---|---:|---:|---:|---:|
| 1 | 100 | 264 | 0.001593163376 | — |
| 2 | 558 | 2,112 | 0.001639505174 | 2.8266% |
| 3 | 1,640 | 7,128 | 0.001663474996 | 1.4409% |

全段で同じ初期空隙率を保持する。今回の第3段では微視・縮約巨視剛性が正で、有限変形FEM内力を正負に摂動した独立な6方向の力勾配との相対差は最大6.23×10⁻⁹だった。隣接差は減ったが、収束値・収束次数は確定していない。接触・塑性・圧縮経路のメッシュ収束を意味しない。

## 連続した圧縮・除荷

同じ第1段メッシュを静止状態から使用する。真応力圧縮0→0.02 MPaを8 ms、保持2 ms、0へ除荷8 ms、無荷重保持2 msとした。準静的性を満たした前回の8 ms載荷を引き継いだ数値設定で、材料固有の時間ではない。密度1×10⁻⁹ tonne/mm³、減衰6,000/s、CFL 0.2は変更していない。

途中再始動をせず、材料・摩擦の履歴を一つの計算中で保持する。除荷を指定した検証ドライバーは、終点の目標応力をゼロとし、応力誤差の規格化には最大指定圧力0.02 MPaを用いる。通常の保持試験の終点目標は従来どおり。

ソルバー既存の判定と追加診断を区別する。追加診断は巨視変形勾配の単位行列からの最大差1×10⁻⁶未満、節点復元誤差1×10⁻⁵ mm未満、軸圧縮残り1×10⁻⁶未満、空隙率復元差1×10⁻⁸未満、出力履歴中の最大塑性ひずみ1×10⁻¹⁰未満、全過程の最大運動エネルギー／全サイクルのエネルギー尺度1%未満とした。これらは既存のソルバー判定を置換しない。

全採用ステップの監査CSVと履歴CSVを保存する。塑性ひずみ履歴は履歴CSVの出力時刻で確認する。圧力が最大値の1%を超える窓での瞬間KE比と、全サイクル尺度による絶対KE比は異なる指標である。弾性エネルギーがゼロへ戻る除荷終盤の比率には分母の影響があるため、単独で解の正当性を主張しない。

## 再現

リポジトリルートで、環境のPythonと `PYTHONPATH=.`、`OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1` を用いる。出力先は毎回新規にする。

```sh
python tools/verify_connected_initial_stiffness.py --refinement 3 --output results/connected-initial-refinement3-NEW
python tools/verify_connected_pressure.py --pressure .02 --ramp-seconds .008 --unload-seconds .008 --recovery-seconds .002 --output results/connected-elastic-unload-NEW
python -m pytest tests/test_explicit_backend.py tests/test_cauchy_unloading.py -q
```

中実立方体の真応力圧縮・除荷試験を追加し、無荷重終点で変形勾配が単位行列に戻り、塑性ひずみと応力がゼロへ戻ることを検査した。既存18件と追加1件は合格。温度依存性や材料校正は導入していない。

## 結果と未解決事項

[比較PNG](../exports/connected-refinement-unloading-002/refinement-unloading.png)、[結果ZIP](../exports/connected-refinement-unloading-002.zip)、[機械可読の判定](../exports/connected-refinement-unloading-002/verification-summary.json)。

56,400ステップ、全20 msを完了した。終点の節点位置の復元誤差は最大1.91×10⁻¹⁰ mm、軸圧縮の残り1.53×10⁻¹¹、空隙率の復元差−1.81×10⁻¹³、最大残留応力成分1.11×10⁻¹⁰ MPa。出力履歴の塑性ひずみはゼロで、材料・幾何・閉境界の体積検査、終点釣合い、エネルギー収支も合格した。接触は発生しておらず、摩擦や接触履歴の除荷を検証したものではない。

**既存ソルバーの総合判定は不合格（diagnostics_only）を保持した。** 後半区間のKE／弾性エネルギー比が24.453%となり、既存の1%基準を超えた。最大の時刻17.82175 msでは圧力2.14×10⁻⁶ MPa（最大荷重の0.0107%）、KE=3.21×10⁻¹² N mm、弾性エネルギー=1.31×10⁻¹¹ N mmだった。比率の大きさにはゼロへ戻る分母が影響している。

最大圧力の1%を超える窓での瞬間比は最大0.8379%、全サイクルの最大KE／エネルギー尺度は0.003990%。追加の復元診断は全項目を満たすが、既存判定の代わりに採用していない。ソルバーの閾値や規格化を今回の結果に合わせて変更しなかった。現段階では「弾性復元の対照データが得られた」と解釈し、全過程の準静的性・塑性除荷の検証完了とは扱わない。

次は、無荷重へ戻る過程に適した準静的性の判定を解析解と時間刻み・除荷速度の比較で検証し、その後0.1 MPaで塑性・接触後の除荷へ進む。塑性圧縮経路のメッシュ収束、一般的な辺接触、表面適応再メッシュ、球充填層の40%→10%圧密は未完了。

出力ツールの初回にはNumPy真偽値のJSON変換で失敗した。組込みboolへの変換を修正し、別の新規出力先で再実行した。計算は再実行していない。失敗した出力スクリプトとログもZIP内 `logs/export-failed-001.*` に保持した。ZIP CRC検査と格納ファイルのSHA-256照合を実施した。

# 接触の面・辺・頂点通過の検証

## 結果と適用範囲

前回の不連続の原因を踏まえ、**閉じた三角形表面に対する摩擦なし法線接触の試験用演算子**を作成し、面・辺・頂点に関する検証を行った。最近点は三角形内部だけでなく辺・頂点を含む。内外は閉じた表面の立体角和（winding number）で判定する。

**この演算子は圧縮ソルバーには組み込んでいない。周期自己接触の改修完了、準静的圧密の合格、空隙率40%→10%の到達を意味しない。** 従来ソルバーの不合格履歴と接触実装は保持した。

## 検証条件

mm、N、N mmを使用。単一の試験点に対するペナルティ剛性を100 N/mmとした。これは形状演算子検証の数値であり、材料・粒径・摩擦係数や実モデルの接触ペナルティを変更するものではない。

L字の閉じた立体（2×2×1 mmの領域から1×1×1 mmの角を除去）の凹辺を、半径0.1 mmの経路で通過させた。面から辺へ、辺からもう一方の面へ遷移する。経路の角度は−0.3～π/2+0.3 rad、中央の辺領域では距離が0.1 mm、エネルギーは0.5 N mmで一定となる。中央では力が角度に沿って回転する。

- 同じ形状を1 mmと0.5 mmの表面メッシュで比較した。
- 各メッシュで101点と201点の経路を比較した。これは変位を直接与える幾何学検証であり、陽解法の時間刻み試験ではない。
- 平面の三角形分割線を横断する101点で、食込み0.02 mmに対する力2 Nとエネルギー0.02 N mmを確認した。
- 3 mm角の立体の中央に1 mm角の空洞を設けた閉じた表面で、凹頂点への3水準の食込みを解析式と比較した。
- 固体外部3点の接触力とエネルギーがゼロとなることを確認した。

## 確認できたこと

試験用演算子の解析式との誤差は、凹辺について力約7.2×10⁻¹⁵ N以下、エネルギー約10⁻¹⁵ N mm以下だった。表面細分化によって曲線は変化しない。経路点数を倍増すると最大の隣接サンプル間の力の差は約0.2171 Nから0.1085 Nへ減少した。これは滑らかな解析曲線を細かくサンプリングした結果と一致する。

平面分割線、凹頂点、外部点の試験も合格した。さらに単体試験で以下を確認した。

- 面・辺・頂点に対する最近点と重心座標が解析式に一致する。
- 面・凹辺・凹頂点で、試験点と相手表面の節点を摂動したエネルギー差分が、返される力の負値と一致する。
- 作用反作用とモーメントが釣り合う。
- 剛体回転・並進に対してエネルギーと力が適切に変換される。
- 閉じた立体を周期像として移動した場合、像の移動に対するエネルギー差分と巨視的仕事が一致する。これは**一つの閉じた像の検証**であり、全周期像の探索やセル切断面の同定を検証したものではない。
- 開いた表面はエラーとして拒否する。

新規9件と既存バックエンド18件、計27件の単体試験が合格した。

図の「Plane-projection criterion only」は、従来の面内投影判定だけを抽出した比較である。凹辺の中央で接触を見逃すことを示すが、従来ソルバーの摩擦・面積・隣接除外・二方向評価を含む完全な再計算ではない。

## 次に必要な検証

1. セルで切断された周期表面では閉じた表面の立体角和をそのまま使えない。周期の内外判定と像の探索を設計し、切断位置・像の数・巨視的変形に依存しないことを確認する。
2. 新しい法線方向に対し、辺・頂点を通過する接線ばね履歴の移送とCoulomb摩擦、摩擦仕事を検証する。今回の演算子には摩擦履歴がない。
3. 節点を伴わない辺―辺交差を捕捉する処理と、その力・仕事の整合性を追加検証する。最近点の辺対応だけでは辺―辺接触の実装にはならない。
4. これらをソルバーに組み込み、前回の動的スリット試験を同条件・時間刻み半分で再試験する。その後、接触中の再メッシュ、準静的載荷速度依存性の検証へ進む。

閉じた表面の最近点距離を使うペナルティは、内部の等距離面（medial axis）で力が一意に決まらない場合がある。今回の滑らかさの検証経路には、そのような点を含めていない。自己交差や非多様体表面の一般的な修復処理も実装していない。

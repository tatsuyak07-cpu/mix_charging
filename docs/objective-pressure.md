# 大変形時の一軸真応力制御

2026-10-17。大変形で変わる断面とセルのせん断を考慮した
`loading_mode: cauchy_pressure` を追加しました。従来の
`nominal_pressure` と既存の設定・結果は保持しています。
公称荷重と真応力の指定は異なる境界条件なので、新方式は明示的に選びます。
`porosity_target` は従来の公称荷重制御のままです。

## 問題と修正

周期セルは対称な6成分の平均変形勾配 F を使います。
従来の外力は zz の一般化力だけを −p V0 とする一定基準の荷重です。
F にせん断が生じた場合、これは現在の空間で横方向・せん断応力をゼロにする指定と一致しません。
過去の `area-pressure-layered-002` の保存形状に同じ外力を写すと、
仕事等価な対称Cauchy応力の xz / yz 成分は約 −0.000216 MPa でした。
これは過去の形状を固定した外力診断で、過去の圧密解析を再計算した結果ではありません。
実際に残ったセルせん断の全てが荷重定義に起因するとは断定しません。

新方式は空間固定の応力 σ = diag(0, 0, −p) を指定し、各ステップで

```
J = det(F)
P = J σ F^(-T)
f_macro[k] = V0 P : B[k]
```

と変換します。B は6成分それぞれの F の微分で、せん断では両側の成分を含みます。
このため δW = V0 P:δF = V σ:(δF F^(-1)) が成立します。
せん断DOFは固定していません。横方向のポアソン変形も自由です。
荷重軸とセルを同時に回転した際の変換と、剛体回転に対する仕事ゼロを検査しています。
現行のセル運動学そのものは対称6成分のゲージであり、一般9成分への拡張ではありません。

外力は形状に依存する追従荷重です。一般に変位終点だけのポテンシャルでは扱えません。
外力仕事は前後の外力の台形則で経路積分し、全エネルギー収支で監査します。
独立な高精度積分との刻み幅比較で2次精度を検査しています。
これは任意の自己接触経路の時間収束を保証するものではありません。

## 出力

- `history.csv` の既存の `nominal_compression_MPa` は、引き続き
  −f_macro[zz]/V0 です。真応力そのものではありません。
- 末尾の `command_pressure_MPa` が、新方式では指定した真応力の圧縮正値です。
  既存の列順は変更していません。
- `summary.json` の `pressure_measure` と `peak_command_pressure_MPa` で指定を判別できます。
  `peak_nominal_pressure_MPa` は出力スナップショットの最大値です。
- `final_work_equivalent_cauchy_stress_MPa` は、材料と接触を含む内部一般化力から復元した
  セルの仕事等価な対称応力です。骨格材料だけの体積平均応力とは異なります。
  外力についても同じ復元値を出します。SPDゲージ外では復元値を null とし、失敗記録を保存します。

## 検証の区別

`results/objective-pressure-001`、公開データは
[結果ZIP](../exports/objective-pressure-001.zip)、
[計算比較PNG](../exports/objective-pressure-001/pressure-verification.png)、
[実メッシュPNG](../exports/objective-pressure-001/mesh-at-0.1MPa.png)、
[外力定義の比較PNG](../exports/objective-pressure-001/load-definition-comparison.png)。

接触を含む平衡残差検査は、1 mmの層状検証セル、平面空隙20%、
細分化 n=1,2,4 と 0.02 / 0.1 MPa の6ケースです。
均質な対角変形の解析状態を構成してFEMと接触の合力を検査します。
これは陽解法によって到達した状態ではありません。
参照面積による接触力は、真応力×現在の断面積と一致するよう独立に求めます。

実際の荷重増加計算は、空隙を持たない1 mm立方体の周期FEMです。
E=10 MPa、ν=0.33、試験用降伏応力0.05 MPa、硬化係数0.2 MPa、
密度1e-9 tonne/mm3、減衰6000/s、増加4 ms、保持2 ms。
物性と数値密度・減衰は従来設定を変えていません。
0.02 MPaは n=1,2 × CFL=0.2,0.1、0.1 MPaは n=1 × CFL=0.2,0.1 の6ケースです。
空隙も有効な自己接触もありません。均質応答の既知解・準静的基準・エネルギーを確認します。

この既知解では塑性体積変化がゼロなので、骨格体積比 J は
log(J) + (1−2ν)pJ/E = 0、Kirchhoff軸応力の大きさは τ=pJ。
累積相当塑性ひずみは max(0, (τ−y)/H)、軸伸長は exp(−τ/E−ep)、
横伸長は exp(ντ/E+ep/2) です。FEMの解から当てはめていません。

詳細な数値・全判定はZIPの `summary.json`、`transient-cubes.csv`、
`contact-equilibrium.csv` とケース毎の `summary.json` に保存します。
1回の細分化比較は一般的なメッシュ収束の証明には使いません。
陽解法の刻み幅推定は追従外力の全接線まで含む厳密な非線形安定限界ではありません。

## 今回の判定と追加比較

コードの回帰試験は **154件合格**。上記の製造解による接触平衡6ケースも合格し、
最大の相対合力残差は3.63e-11でした。実荷重試験は次のように区別します。

| 条件 | ソルバー監査 | 対角解析枝・せん断検査 |
| --- | --- | --- |
| 0.02 MPa、4 ms、n=1,2、CFL=0.2,0.1 | 4ケース合格 | 合格 |
| 0.1 MPa、4 ms、固定代表点、CFL=0.2,0.1 | 運動エネルギー比約3.21%で不合格 | 不合格 |
| 0.1 MPa、4 ms、並進運動量ゼロ、CFL=0.2,0.1 | 同約2.40%で不合格 | 不合格 |
| 0.1 MPa、16 ms、固定代表点、CFL=0.2,0.1 | 2ケース合格 | せん断が残るため全検証合格とはしない |

最初の不合格を受け、物性・接触・公差は変更せず、刻み幅、荷重速度、
既存の質量フレームを比較しました。増加時間を延ばすのは準静的近似への速度依存を
調べるためで、密度や摩擦を調整して合格させるものではありません。
追加試験は `sensitivity/objective-pressure-zero-momentum-001` と
`sensitivity/objective-pressure-slow-pinned-001` に元データ・失敗判定・ソースを保存します。

16 ms、CFL=0.2 のケースは、運動エネルギー比0.6164%、エネルギー相対誤差3.83e-7、
軸伸長の解析解との差8.39e-7、PEEQの差1.53e-6、
仕事等価応力の相対誤差2.75e-9でソルバーの監査を満たしました。
一方、平均Fのせん断ノルムは3.45e-4で、事前に定めた1e-8の対角枝検査には不合格です。
せん断を固定する、判定値を緩める、またはこのケースを一般的な圧密の検証完了とする対応は行いません。

`mass-coupling-diagnostic.json` は、同じ初期メッシュに zz の一般化力だけを与えた瞬間の
加速度と6×6質量行列です。粗い6四面体の集中質量行列には軸・せん断の結合があり、
並進運動量ゼロにしても完全には消えません。したがってこの過渡試験では、
対称な連続体の慣性と離散慣性との差、および塑性履歴への影響も調べる必要があります。
これは残留せん断の全原因の証明ではありません。
不合格の集計を保持するため、追加比較を含め検証ツールは全体として終了コード2を返します。

## 実行

既存環境で `PYTHONPATH=.`、`OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1` を指定します。
出力先は未使用の名前にします。

```bash
python tools/verify_cauchy_pressure.py --output results/objective-pressure-NEW
python tools/run_barrier_compaction.py --config configs/explicit-area-cauchy-pressure.json --case small --output results/cauchy-small-NEW
```

2行目は新方式を選んだ試験セルの実行例で、この記録で完了したケースではありません。
既定の `run_barrier_compaction.py` の設定は従来の公称荷重のままです。

## 残る課題

層状空隙セルの接触を伴う過渡計算は新方式で未再検証です。
従来の3.4%の運動エネルギー比による不合格を取り消していません。
一般的な辺だけの接触の反力、複数接触パッチ、表面再メッシュは未対応です。
したがって100 mm球充填層の空隙率40%→10%の圧密計算も未完了です。
次段階は同じ層状セルで新旧の応力定義・保持時間・刻み幅を比較し、
接触過渡の準静的基準と応力条件を独立に確認することです。

# 0.1 MPaでの塑性圧縮・接触後の除荷検証

[比較PNG](../exports/plastic-contact-unloading-001/plastic-unloading.png)・[実メッシュPNG](../exports/plastic-contact-unloading-001/residual-mesh.png)・[CSV・全結果ZIP](../exports/plastic-contact-unloading-001.zip)・[判定JSON](../exports/plastic-contact-unloading-001/verification-summary.json)。

今回の対象は、独立な一軸塑性解を持つ中実1 mm立方体と、4 mm角・初期空隙率0.25%の連結検証セル。100 mm角、直径10 mm球、ネック径2 mm、初期空隙率40%→10%の球充填層の結果ではない。剛体円柱は入れていない。

E=10 MPa、ν=0.33、摩擦係数0.3はユーザー指定値。Hencky/Kirchhoff J2の降伏0.05 MPa・等方硬化0.2 MPa、密度1×10⁻⁹ tonne/mm³、減衰6,000/s、時間設定・検査閾値は未校正の開発用設定である。温度依存性は導入していない。有限要素の運動方程式、材料更新、接触則、ソルバーの既存判定は変更していない。

## 連結セルの連続圧縮・除荷条件

前回0.1 MPaで検査を満たした32 ms載荷を使用し、最大荷重で2 ms保持、除荷8 msまたは16 ms、無荷重で2 ms保持する。除荷時間以外は同じ条件とした。CFL 0.2、100節点・264初期四面体、全6巨視変形自由度を持つ周期境界、横変形・せん断自由。接触は `area_guarded`、バリア厚さ0.02 mm、ペナルティ20 MPa/mmを保持する。

中間再始動は行わない。静止初期状態から除荷完了まで一つの計算で塑性・摩擦履歴を保持する。通常の最終状態NPZだけでは摩擦履歴を完全再始動できないため、過去の圧縮最終メッシュを初期状態にして摩擦をリセットする方法は使わなかった。ステップ上限300,000は除荷区間追加のためで、時間刻みや物性の変更ではない。

全採用ステップの圧力・圧縮・空隙率・エネルギー・接触数CSVと、出力時刻のPEEQ・Coulomb比等の履歴を保存する。監査CSVの圧力列は指令Cauchy応力、履歴CSVの `nominal_compression_MPa` は公称成分なので同じ量ではない。

事前の追加速度比較基準は、最終軸圧縮の差<10⁻⁴、最終空隙率の差<10⁻⁷とした。比較は全採用時刻を除荷位相に換算した和集合で補間する。これらの比較だけで、接触を含む全過程の刻み・メッシュ収束を認定しない。

## 中実モデルの独立な一軸塑性解

横方向自由、純粋な一軸Cauchy圧縮p≥0、同軸変形、ゼロから一つの最大圧力を経てゼロへ除荷する。sを軸Kirchhoff圧縮の大きさ、a=1−2ν、αを累積相当塑性ひずみとすると、

```
s exp(a s/E) = p
s = (E/a) W(a p/E)
α(t) = max(max_{τ≤t} s(τ) − y, 0) / H
対数軸ひずみ = −s/E − α
横方向対数ひずみ = νs/E + α/2
J = exp(−a s/E)
単位参照体積のエネルギー = s²/(2E) + yα + Hα²/2
```

WはLambert W関数の主枝、y=0.05 MPa、H=0.2 MPa。この解では除荷中に逆方向降伏せず、αは最大圧力時の値を保持する。材料のFEM応力更新や内力を使わず計算した静的解で、動的運動方程式の厳密解ではない。一般の非比例・逆負荷や接触形状には適用しない。

0.1 MPaの基準解は最大軸圧縮0.227617040401、除荷後0.219880852641、残留PEEQ=0.248308617940。ゼロ応力時には弾性変形が戻り、塑性変形が残る。J=1へ戻るため、中実モデルの材料体積は初期値へ戻る。

| 中実モデル | 載荷 | 除荷 | CFL | 全経路軸誤差／解析解最大圧縮 | 除荷後軸圧縮 |
|---|---:|---:|---:|---:|---:|
| 基準 | 32 ms | 8 ms | 0.2 | 0.85526% | 0.219880928816 |
| 除荷を遅く | 32 ms | 16 ms | 0.2 | 0.85526% | 0.219880928816 |
| 刻み半減 | 32 ms | 8 ms | 0.1 | 0.85571% | 0.219880928979 |
| 載荷を遅く | 64 ms | 8 ms | 0.2 | 0.42847% | 0.219880854699 |

32 msでの誤差は降伏付近の有限速度応答が支配するため、載荷時間も独立に2倍とした。材料・密度・減衰は変更していない。残留値の照合と全経路の追従誤差を区別する。事前の解析解比較基準は経路誤差1%、残留ひずみ相対誤差1%、PEEQ相対誤差1%、除荷後応力／最大圧力2%、除荷後体積誤差10⁻⁶。ソルバーの既存検査も別に実行する。

中実モデルは接触のない材料・時間積分の対照であり、連結セルの空隙率や摩擦をこの解析解で予測しない。局所残留応力を持つ多孔質体では、巨視応力ゼロでも各要素の弾性ひずみがすべてゼロになるとは限らない。

## 終点の力の独立な検査

接触が残らない終点では、各節点に対向する四面体面の外向き面積ベクトルAから節点内力σA/3を積分し、既存の体積勾配方式とは別に組み立てる。材料応力には既存の検証済み構成応答を用いる。周期自由度へ投影し、巨視成分をセル長で割ってNへ揃えた力のノルムを最大圧力×初期面積で規格化する。材料体積で積分した平均Cauchy応力も初期最大圧力に対して評価する。追加基準はいずれも2%。既存の終点釣合い判定はそのまま残す。

接触が残る終点では、最終NPZに摩擦履歴が含まれず独立な全反力を再構築できないため、この追加検査は未実施と明記する。接触履歴をゼロにした別状態の反力を本計算の反力として扱わない。ソルバーが計算した履歴付きの終点釣合い・応力・Coulomb検査と区別する。この検査は終点のみで、全経路の静的力の再構築ではない。

## 連結セルの結果

両ケースとも全予定区間を完了し、ソルバー既存の全検査、独立な体積検査、ソルバー応力の終点比較に合格した。ただし終点応力比較はソルバーの履歴付き反力に基づき、独立な接触反力組立ではない。

| 除荷時間 | ステップ | 終了時刻 | 最大圧縮 | 除荷後圧縮 | 除荷後空隙率 | 終点釣合い比 |
|---|---:|---:|---:|---:|---:|---:|
| 8 ms | 142,355 | 44 ms | 22.852495% | 22.071236818% | 0.221729979% | 0.00210083 |
| 16 ms | 171,150 | 52 ms | 22.852495% | 22.071236824% | 0.221729978% | 0.00030559 |

初期空隙率は0.25%、全過程での最小値は0.2126942%。除荷で一部が回復するが初期値へ戻らず、軸圧縮も残る。数値試験モデルでは永久変形と空隙率の残留変化が得られた。元の物性・形状の校正やメッシュ収束を含む物理予測の認定ではない。

除荷時間を2倍にしたときの残留圧縮差は6.12×10⁻¹¹、残留空隙率差1.95×10⁻¹²。同じ除荷位相での最大圧縮差は2.87×10⁻⁶。事前の残留差の追加基準も満たした。今回の2速度では残留値の速度依存は小さいが、接触を含む一周期のCFL依存を確認したものではない。

最大PEEQは両者0.2581763785、載荷後半の既存低KE比と、圧力が最大値の1%を超える全採用ステップ窓のKE比はいずれも0.503004%、エネルギー相対誤差1.93×10⁻⁷。出力履歴のCoulomb比は最大0.3、累積摩擦仕事は3.6663×10⁻⁷ N mm。接触数はtwo-pass参照面積積分の点記録数で、独立な粒子接触ペア数ではない。最大・終点とも2記録で、除荷後も接触が残った。

したがって**終点の独立な全接触反力の再構築は両ケースとも未実施**。ソルバーの履歴付き釣合いは合格だが、最終NPZに摩擦履歴がないため、条件付き面力検査で代替しなかった。この制限を `independent-face-audit.json` と集計JSONへ明示した。

前回の32 ms載荷・2 ms保持の圧縮専用ケースと、新しい除荷ケースの共通載荷区間も照合した。全採用時刻の和集合上での軸圧縮差は最大1.75×10⁻¹⁵。既存の載荷応答を維持した連続計算であることを確認した。

比較PNGと、初期・8 ms除荷後・16 ms除荷後の実メッシュPNGを保存した。変形倍率は1で、全パネルを共通の座標範囲で表示する。全ケースとも264四面体で、表面再メッシュの実証ではない。ZIPには全採用ステップCSV、履歴CSV、メッシュ・材料状態・ソース・失敗記録を含め、CRCとSHA-256を照合した。

## 再現

リポジトリルートで環境のPythonを使い、`PYTHONPATH=.`、`OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1` とする。出力先は新規にする。

```sh
python tools/verify_connected_pressure.py --pressure .1 --ramp-seconds .032 --unload-seconds .008 --recovery-seconds .002 --cfl .2 --max-steps 300000 --output results/plastic-unload8-NEW
python tools/verify_connected_pressure.py --pressure .1 --ramp-seconds .032 --unload-seconds .016 --recovery-seconds .002 --cfl .2 --max-steps 300000 --output results/plastic-unload16-NEW
python tools/verify_plastic_cycle_reference.py --output results/plastic-reference-NEW
python tools/verify_plastic_cycle_reference.py --slow-loading-only --output results/plastic-reference-slow-NEW
python -m pytest tests/test_plastic_cycle_reference.py tests/test_unload_reference.py tests/test_explicit_backend.py tests/test_explicit_audit.py tests/test_cauchy_unloading.py -q
```

中実対照の最初の試行では、FEM完了後に後処理が応力リストへ `abs()` を適用して失敗した。NumPy配列への変換を修正し、新しい出力先を使用した。完了済みの8 ms除荷FEMは設定と構成ソースの全一致を検査して再利用し、元の全結果ファイルとのSHA-256一致も確認する。失敗ドライバー・ソースハッシュ・ログを保持する。計算の失敗と後処理の失敗を混同しない。

関連テスト27件は合格（26.77 s）。独立な塑性解と材料更新の一致、塑性なしの極限、面積ベクトルによる内力の手計算値・合力・モーメントも検査した。

## 残っている検証

連結セルの接触・塑性・除荷を通したCFL半減とメッシュ依存、独立な全接触反力の再構築、一般的な辺接触と表面適応再メッシュ、材料の校正は別途必要。今回の中実モデルでのCFL比較を、接触を含む連結セルのCFL比較と呼ばない。球充填層の初期空隙率40%→10%圧密は未完了。

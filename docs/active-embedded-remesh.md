# 接触中の表面細分化：保存積分点による限定的な移行

工程1・2に続き、工程3の「接触中の再メッシュ」を進めた。今回の実装は、**既存の材料積分点を増減せず、分割前に用意した積分則と整合する辺分割**に限る。一般の表面再生成や、充填層の大変形での品質回復を完了したものではない。空隙率40%→10%、保持・除荷・空間収束は引き続き未達成。

## 実装した移行

`embedded_remesh.refine_rules`は、元の面と分割後の子面の参照座標の対応を求める。各積分点の位置・面積重みを保持し、子面ごとの重み和が参照面積に一致する場合だけ移行する。点を追加したり、重みを変更したり、未知の履歴をゼロで補ったりしない。既存のpose-atlasがある面の分割は、過去姿勢データの明示的な移行が未実装のため拒否する。

`embedded_remesh.transfer`は、確定した摩擦履歴と、実際に力を評価した遅れ状態を別々に移す。ばね、塑性すべり、局所方向、材料アンカーを保持する。アンカーは「現在の最近接面」とは異なる過去の面にある場合があるため、その**アンカー自身の親面**から子面を探す。参照配置と現在配置の両方で同じ点を表せなければ拒否する。

分割後の節点力を辺上の補間の転置で元の節点へ戻し、周期画像の仕事も含む全周期自由度の力を照合する。許容値は検証用1e-8、本体では既存の`remesh_energy_tolerance`。力とエネルギーだけでなく、質量・線形/角運動量・運動エネルギー・Coulomb限界も既存監査で判定する。すべての計算が通るまで元のソルバー状態を変更しない。

本体では`active_embedded_surface_remesh=true`を明示した場合だけこの経路を使う。既定値はfalse。`surface_remesh_steps`の0は、初期の接触状態を最初の時間積分前に移行する検証・初期細分化用である。接触前の積分則再初期化を、接触履歴のある状態に流用しない。

完全な面積分則で置換した面の節点面積について、以前は「全面積から置換分を引く」ことで正の微小残差が生じ、存在しない節点履歴を作る場合があった。未置換面の面積だけを直接加算する方式へ変更した。小さい正の面積を閾値で切り捨てる変更ではない。

## 確認した範囲と不合格

検証形状は周期平面接触であり、球充填層の変形解ではない。E=10 MPa、ν=0.33、摩擦係数0.3、接触剛性20 MPa/mmを維持する。積分則の準備では、規定した幾何軌跡に対する**法線積分だけ**を調べ、必要なら接触前から準備し直す。この幾何対照で接線計算を省略しても、検証対象の摩擦則や物理解の摩擦係数を変更したことにはしない。

- 平面の辺分割位置0.2、0.5、0.8と、固着側/滑り側の変位0.0001、0.01 mmを検査する。周期コピーを含む面分割も対象。
- 独立な一様面積ばねの法線ポテンシャルとCoulomb限界に比較する。
- 逆方向すべり、その後の離間まで、未分割モデルとの周期自由度の力、弾性エネルギー、散逸、履歴解放を比較する。これは規定運動であり、自由な圧密・除荷の完走ではない。
- 対応しない位置での分割は、面積重みを調整せずに拒否する。

失敗・変更の記録：

1. 単純にGauss点を保持した初回は、分割後の節点反力の積分精度で不合格。分割後の形状関数を積分する対照を接触前の準備へ追加した。
2. 微小な節点面積残差による履歴生成、現在の面とアンカーの面を取り違えた移行を修正した。
3. 逆方向の幾何を準備しない試行は、継続時に新しい積分則を要求して停止した。過去の履歴をその場で初期化して続行していない。
4. 規定変位を一度に大きく動かした試行は、線形移動の非交差認証で停止。検証軌跡を小刻みに評価し、接触判定は変更していない。
5. 結果保存時のNumPy真偽値のJSON変換エラーを修正した。中断した出力も保存している。
6. ソルバーの速度のある状態（1刻み後）では、接触の仕事誤差約9.02e-15に合格したが、角運動量の正規化誤差約0.0100と運動エネルギー約0.00480が既存許容値0.001を超えた。**分割は拒否され、これを合格にするための許容値変更は行っていない。**
7. 静止接触の初期移行は全保存監査に合格した。その後の動的継続は、異なる最近接投影の同距離分岐を参照積分が扱えず1刻みで停止した。移行そのものと、移行後の運動を最後まで解けることを分けて判定する。

### 固着を塑性すべりと誤認する丸め誤差の修正

未分割と分割後の比較では、修正前の6条件すべてで移行直後は合格したが、逆方向運動の周期力差は最大2.71423e-5となり、検証用の1e-7基準に不合格だった。固着中にも`coordinate - spring`の差を塑性すべりと判定し、アンカーを最近接点へ更新していた。新しい回帰試験では、Coulomb限界の内側に戻っているのにアンカー面・座標が変わることを埋込積分点で再現した。

Coulomb限界`kt * |trial| > μ * Fn`により実際にばねを補正する場合だけ、滑りとして扱うよう変更した。固着側では既存の塑性オフセットをそのまま使う。μ、接触剛性、材料、境界条件、検証基準を変更していない。丸め誤差の閾値を追加する変更でもない。この修正前後で同じ6条件と同じ検証基準を比較した。**修正後は6条件すべてで、移行・21段階の逆方向すべり・10段階の離間が合格**。移行直後の周期力の最大正規化差2.09e-14、継続中1.88e-14、法線/接線エネルギー1.57e-12、散逸1.34e-12。継続の判定値1e-7は維持した。許容値0.001、0.0005、0.00025の独立な履歴試験も合格した。これらは規定運動の平面接触に限る。

## 実充填層への適用判定

前工程の保存状態（90250刻み、接触履歴69個）から、接触源面1521の3辺を調べた。**適用可能0/3**。2辺はpose-atlasの過去姿勢を子面へ移す機能が必要で、残る1辺は既存の積分則が分割に適合しない。診断だけを実施し、この状態のメッシュ・履歴・空隙率は更新していない。

したがって、今回の限定移行を有効にするだけで既存の充填層計算を10%まで続行できる、とは判断しない。次に必要なのは、過去姿勢と材料積分領域の子面への移行、積分点を増減する場合の履歴移行、速度を持つ状態の運動量・エネルギー保存、同距離接触分岐の参照積分である。今回の初期移行対照では最小品質が0.5487→0.4323と低下した。辺分割だけでは任意の要素品質を回復できず、品質を改善する再接続・節点再配置等を別途検証する必要がある。

## テストと保存状態

摩擦判定の修正前には、周期コピーを含む辺分割・固着/滑りの6条件と不適合分割の拒否の計7試験が合格した（640.54秒）。しかし長い逆方向軌跡の比較は6条件とも不合格だったため、これだけで履歴移行を合格としなかった。

最終の摩擦判定では、関連23試験（214.85秒）、保存・再開・既存ソルバー・面積ゼロの回帰17試験（156.68秒）、独立な積分許容値3水準の履歴試験1件（353.00秒）が合格した。全リポジトリの全試験を再実行した件数ではない。過去の未修正コードのログと最終コードのログを`source-cohorts.json`で区別し、ソースも保存する。

旧コードで接触した充填層の保存履歴は、今回の摩擦判定へそのまま差し替えて継続しない。接触前の認証済み保存状態から再計算する必要がある。今回の保存充填層に対する3辺の検査は幾何と積分則の適用診断だけであり、新しい摩擦判定による充填層の圧密結果ではない。

## 再現

```bash
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  /workspace/environment/mix_charging/.venv/bin/python tools/verify_embedded_remesh.py \
  --output results/active-remesh-plane-NEW

PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  /workspace/environment/mix_charging/.venv/bin/python tools/verify_active_remesh_solver.py \
  --output results/active-remesh-solver-NEW
```

すべての出力先は新規にする。後者は**3刻みの上限を設けた動的な接続検証**で、準静的解の判定器ではない。継続の未解決条件を含めるため、未合格なら終了コード2となる。保存・再開は、元設定の積分則を明示的な上書きと誤認せず、保存状態の移行済み積分則を復元する。明示的な積分則変更は従来どおり接触前の認証済み状態に制限する。

# 空隙率40%から10%に向けた大変形計算手法の変更案

## 推奨する方針

**粒子・焼結ネック・空隙を明示した有限変形FEMを維持し、体積評価が整合する適合メッシュ、
大すべりの周期自己接触、必要に応じた適応再メッシュを導入する。多数の接触が切り替わる
圧密経路には準静的な陽解法を第一候補とし、陰解法との小規模比較で採否を決める。**

陽解法に替えるだけでメッシュのゆがみや体積誤差が解決するとは扱わない。
再メッシュでも形状・内部状態を維持できない場合に、MPMへの移行を次の候補とする。
本書は手法選定・検証計画であり、新手法の実装や空隙率10%への到達を報告するものではない。

## 前回の停止をどう解釈するか

[前回の計算](porosity40-to10.md)は既に `NLGEOM` と有限変形弾塑性を使っている。
「小変形ソルバーだったので大変形へ切り替える」という状況ではない。

- 指定初期空隙率40%、実際の初期メッシュ39.8592%、25 mm角の試験モデル。
- 軸圧縮9.8%で、幾何空隙率36.36724%、材料体積による空隙率36.35640%。
- 差は **0.01084パーセントポイント**。試験用の上限0.01パーセントポイントを超えて停止した。
- この完全な端点では積分点J・巨視的Jは正。ソルバーが要素反転や非収束を宣言した停止ではない。

この差は二つの評価方法の不一致であり、真の空隙率に対する誤差が確定した値ではない。
9.8%が材料やFEM一般の変形限界という証拠にもならない。
許容値は独立した体積検証と必要精度から再検討できるが、10%に到達させる目的だけで緩めない。
現在の停止条件・結果は変更しない。
入力の「軸圧縮50%未満」という試験用ガードも材料限界ではない。
新バックエンドでは空隙率の目標と変形・接触の品質から探索範囲を設計し、
ガードの改訂は検証後に行う。前回9.8%での停止原因はこの入力上限ではない。

別の課題として、自己接触未実装、ネック径2 mmに対して要素幅1 mm、
ボクセルによる曲面・狭い間隙の誤差、材料未校正、メッシュ収束未確認が残っている。
圧密では新しい接触面が増えるため、これらを解決せず荷重だけを延長しても検証済みの解にならない。

## 手法の比較

| 手法 | 本件に対する利点 | 必要な対策・制限 | 採用位置 |
|---|---|---|---|
| 陰解法の有限変形FEM＋自己接触＋再メッシュ | 慣性を導入せず準静的な釣合いを評価でき、既存結果と比較しやすい | 座屈や多数の接触切替で反復が難しくなる。再メッシュと状態移送が必要 | 小規模の基準解・陽解法との比較 |
| 準静的な陽解法FEM＋自己接触＋再メッシュ | 大規模な全体Newton反復を避けられ、多数の接触・塑性変形を追いやすい | 微小な安定時間刻み、慣性、アワーグラス、要素ゆがみを別々に監査。速いとは未確認 | 圧密経路の第一候補 |
| MPM（GIMP/CPDI等を含む） | 固体を物質点で追跡し、通常のラグランジュ要素の極端なつぶれを避けられる | 周期自己接触、同一物体の再接触、空隙境界、格子通過誤差、体積の再構成が難しい | FEMの再メッシュでも継続困難な場合の次候補 |
| 均質な圧密モデル（キャップ型等） | 巨視的な応力―空隙率曲線を低負荷で計算できる | 圧密曲線等による校正が必要。個々の粒子・ネック・空隙形状を直接評価できない | 巨視応答だけを求める別モデル |
| 剛体粒子DEM＋接合ばね | 粒子の移動や接触の計算は軽い | 粘土状の粒子変形と三次元空隙体積を固体FEMと同じ精度で表さない | 今回の主手法には採用しない |

MPMは接触を自動的に正しく解く方法ではない。単一の格子速度場で近接した表面を扱うと、
意図しない固着や空隙の消失が起こり得る。複数の速度場・接触処理と空隙体積の検証が必要である。
ALEも、固定格子にするだけで粒子表面や閉じる空隙を保持できるものではない。
今回の形状には自由表面・材料境界の移送と接触との整合を確認する必要がある。

## FEMで優先して変える部分

### 1. 適合する形状メッシュと体積評価

球とネックの和集合を形状として保持し、曲面と狭い間隙を表現する体積メッシュを作る。
メッシュサイズを決めるための開発者案として、ネック周辺0.5 mm、次に0.25 mmを比較する。
これは最初の比較幅であり、収束済みの推奨サイズではない。
初期40%は形状体積とメッシュ体積の両方で確認し、格子位相の選択だけで精度を保証しない。

要素には、ほぼ等容の塑性流動と曲げに対応する定式化を選ぶ。
混合u-p、B-bar/F-bar、安定化した低減積分等は候補であり、選ぶソルバーの有限変形実装を確認する。
ν=0.33は維持する。数値上の都合でνを0.499等に変更しない。
C3D8Rに替える場合はアワーグラスと接触を検証し、C3D8や高次要素へ単純に替えて解決したとは扱わない。
C3D8Iの既存実験用後処理は比較用として保持する。

空隙率は `φ = 1 - Vsolid / (det(Fmacro) V0)` とする。
適合要素の変形体積積分を、閉じた表面からの体積等の独立な評価と比較する。
周期境界で切れた表面は正しく閉じ、必要なら周期コピーを現セルへ切り取って評価する。
コピーを全て足して体積を重複計上しない。
要素体積の和が意味を持つには、正のJだけでなく表面の非貫入も必要である。
幾何学的な和集合を用いる場合も、重なりを除いて貫入を隠すのではなく、体積和との差を監査に使う。

### 2. 大すべりと周期自己接触

焼結部は連続体として接合を保ち、自由な粒子表面には新しい接触を許す。
同じ焼結骨格の異なる自由表面同士の接触と、周期コピーとの接触を含める。
接合済みの内部面や隣接要素面を接触面として二重拘束しない。
新たなすべり接触の摩擦係数は以前の指定0.3を引き継ぐ初期案とし、焼結接合の摩擦には置き換えない。

周期コピーの位置は変形した格子ベクトルから更新する。
大きな圧縮・せん断時も固定の27コピーだけで十分とは仮定せず、探索距離と現格子から範囲を決める。
接触ペナルティや拘束精度は感度を比較し、貫入量、接触力、摩擦限界、接触仕事を記録する。

### 3. ゆがみに応じた再メッシュ

Jが正という条件に加え、要素の形状品質と狭い空隙の解像度で再メッシュを判断する。
再メッシュでは形状・周期対応・塑性内部変数を移送する。
塑性ひずみをゼロへ戻したり、要素を削除して計算を続けたりしない。
応力・塑性変形・硬化状態を整合させ、質量、再メッシュ前後の瞬間的な体積、仕事の差を監査する。
骨格体積は弾性圧縮で変化するため、荷重経路全体で一定に強制するわけではない。

境界の節点対応が変わる場合は周期拘束も再構築し、非一致メッシュなら補間・mortar等の
周期拘束を検証する。剛体回転、均一変形、周期境界をまたぐ物体の試験を必須とする。

### 4. 材料モデルを計算手法と区別する

最初の比較ではE=10 MPa、ν=0.33、既存の試験用降伏・硬化を保ち、有限変形J2の
客観性・単軸応答・除荷を照合する。計算を通すために軟化・粘性を追加しない。
温度効果は引き続き導入しない。

本当の粘土・焼結鉱の圧力依存性や骨格内部の圧密を再現する段階では材料校正が必要になる。
粒子間空隙を明示した骨格へ、巨視的なキャップ型圧密則をそのまま追加すると、
同じ空隙の閉鎖を二重に表すおそれがある。均質化モデルと骨格材料の役割を分ける。
破壊・ネック破断も別の物理モデルであり、今回は自動的に追加しない。

## 陽解法を準静的と認める検査

陽解法では密度と載荷時間が必要になる。現在の入力には実測密度がない。
数値的な密度を使う試験では、その値を実測物性や実際の時間と解釈しない。
滑らかな載荷履歴を使い、載荷時間を2倍・4倍にした応答と質量スケーリングの感度を比較する。
マススケーリングで安定時間刻みを拡大しても、接触力や空隙率が変化すれば準静的解として採用しない。

運動エネルギーが内部仕事に比べ十分小さいことを必要条件とする。
試験用には、十分に載荷された区間で1%以下を最初の目安とするが、普遍的な合格値ではない。
初期や除荷末期のゼロに近いエネルギーで単純に割らず、絶対量と外部仕事も確認する。
この比だけでなく、力の釣合い、載荷速度・質量への不変性を確認する。

外部仕事を、弾性エネルギー、塑性散逸、摩擦散逸、運動エネルギー、
接触ペナルティの蓄積、数値的な安定化・減衰の寄与と照合する。
ソルバーの内部仕事に塑性散逸等が既に含まれる場合は二重加算しない。
接触の導入後は、既存の「骨格内部仕事だけ」の監査をそのまま使わない。
周期拘束力を含む巨視的な仕事と、骨格・接触を含む微視的な仕事を比較する。

## 導入の順序と判定

1. **体積と接触の基礎試験**：均質セル、空隙付きセル、2物体の圧縮・すべり、
   同一骨格の自己接触、周期境界をまたぐ接触を確認する。陰解法と陽解法を比較する。
2. **再メッシュの試験**：既知の変形の前後で質量・体積・塑性状態・仕事・周期性を確認する。
   弾性・塑性除荷の残留変形も確認する。
3. **40%の小規模モデル**：同じ物理形状でメッシュ、載荷速度、接触設定の感度を比較し、
   空隙率30%、20%、10%を順に確認する。小さな除荷・保持で慣性と永久変形を区別する。
4. **100 mm角へ拡張**：RVE寸法と配置の依存を確認してから本仕様へ進む。
   25→100 mmは体積が64倍であり、現在の実行時間から単純に完了時刻を予測しない。

必要な荷重は各空隙率での応答として求める。0.1 MPaで10%になるとは仮定しない。
骨格体積一定の理想化では40%→10%にセル体積比2/3が必要だが、
横荷重自由の本条件で軸圧縮率が33.3%になるとは限らない。
メッシュ差・時間刻み差・体積の独立評価から空隙率の精度を決め、達成・未達成を記録する。

## ソルバー選定上の留意点と参照

既存CalculiXは検証結果の保存・比較に使う。
参照ソースの文書には通常の陽解法と接触の説明があるが、それだけで本件に必要な
周期自己接触・再メッシュ・塑性状態移送の一式が、使用中の2.20で利用できるとは判断しない。
特にMASSLESS接触は通常の陽解法とは別方式で、参照文書には非ゼロ境界条件の制限もある。
現在の変位制御の入力をそのまま置き換える案にはしない。

Abaqus/Explicit、LS-DYNA等は必要機能を確認する候補だが、
この環境でのライセンス・導入・本件の周期拘束と再メッシュの組合せは未確認。
製品名だけで適合を宣言しない。オープンソースで進める場合も、必要機能の小規模実証を先に行う。
ソルバーの導入や切替はまだ実施していない。

# 連結多孔質セルの真応力圧縮と全採用ステップ監査

2026-10-19。前回確認した層状セルの無剛性閉鎖モードを避け、
初期弾性接線が正定値と確認済みの連結検証セルを圧縮します。
実際の有限要素時間積分と、後処理での体積・応力・エネルギーの検査を保存しました。

## 仕様と検証用の数値条件

対象は既存の **4 mm立方体、中央に2×2×0.04 mmの平面状空隙を持つ連結セル**。
初期空隙率0.25%、100節点・264四面体、周期境界、せん断と横変形は自由です。
これは球充填体ではありません。100 mm角、粒径10 mm、ネック径2 mm、
初期空隙率40%→10%の本モデルの結果とは区別します。

試験材料はE=10 MPa、ν=0.33、Kirchhoff降伏応力0.05 MPa、硬化係数0.2 MPaのHencky J2。
温度依存性なし。降伏・硬化値はユーザーの実測材料値ではなく、従来からの試験用設定です。
接触は参照面積による `area_guarded`、μ=0.3、バリア厚さ0.02 mm、ペナルティ20 MPa/mm。
数値密度1e-9 tonne/mm3、減衰6000/s、質量フレーム `pinned` は変更していません。
荷重はCauchy応力diag(0,0,−p)。[荷重変換と公称荷重列の定義](objective-pressure.md)を参照してください。

| 目標真応力 | 増加時間 | CFL | 目的 |
| --- | --- | --- | --- |
| 0.02 MPa | 4 ms | 0.2, 0.1 | 低圧の刻み幅比較 |
| 0.02 MPa | 8 ms | 0.2 | 増加時間を倍にする速度比較 |
| 0.1 MPa | 16 ms | 0.2, 0.1 | 目標荷重での接触・塑性と刻み幅比較 |
| 0.1 MPa | 32 ms | 0.2 | 16 msのKE基準未達を受けた速度感度試験 |

保持は全て2 ms、公差と物性・摩擦・接触係数を保っています。
32 msケースを追加した理由は `followup-reason.json` に計算開始時に記録しました。
16 ms・CFL 0.2が0.1 MPaに到達して塑性変形した一方、運動エネルギー比が約1.26%となったためです。
刻み幅半減の試験と速度変更の試験を分け、物性を調整して合格させる操作は行いません。
減衰仕事と外力仕事の比も集計します。16 msの0.1 MPaケースでは約2.46%でした。
KEが小さいことだけから減衰の影響がゼロとは結論せず、減衰係数自体の感度検証は未実施です。
この試験を密度・減衰の感度検証や一般的な時間・メッシュ収束の証明とは扱いません。

## 監査の改善

前回、200ステップ毎の出力では接触開始のピークを取り逃がすことを確認しました。
そこで `accepted-step-audit.csv.gz` を追加しました。初期状態と**全採用ステップ**の
時間、軸圧縮、空隙率、指定圧力、KE、材料内部エネルギー、外力仕事、
エネルギー残差、法線・接線接触エネルギー、接触数を保存します。
接触探索で棄却された試行は採用ステップに含めず、既存の再試行ログで区別します。

監査の保存を追加したもので、力・材料・接触則・積分・既存合否条件は変更していません。
表示用の `output_every` を1と53に変えた独立実行で、全採用ステップの数値配列と
集計結果が完全に一致することをテストしました。圧縮ファイルのタイムスタンプの一致を要求するものではありません。
回帰テストは **160件合格** です。

判定は次のように区別します。

- **既存のソルバー検査と終点検査**：後半のK/内部エネルギー比1%未満、
  エネルギー相対誤差2%未満、静力釣合い、Coulomb上限、正のJ、体積一致、経路完了など。
  既存のKE監査区間は増加時間の半分より後です。
- **追加の圧力窓監査**：指定圧力が観測最大値の1%を超える全採用ステップについて、
  K/(|材料内部エネルギー変化|＋法線接触エネルギー＋接線接触エネルギー)を求め、
  既存と同じ1%を目安として別に判定します。分母の床はエネルギースケール×1e-8。
  その窓の最大KE、最大値の時刻、エネルギースケールに対する比も保存します。
  内部エネルギーがゼロに近い時点の比だけから精度や速度収束を結論しません。
  圧力1%以下を含む全時間が準静的だと主張する検査でもありません。
- **独立な体積検査**：終点で四面体幾何体積、参照体積×弾性体積比、閉曲面体積を比較します。
  仕事等価Cauchy応力はソルバーの内部一般化力から復元した出力を指定値と比較します。
  摩擦接触力を別実装で再組立てした検査ではありません。
- **出力完全性**：監査行数が採用ステップ数＋1と一致し、終点空隙率とKE極値が
  圧縮CSVから再計算した値と一致することを確認します。

初期接線の一次予測も併記します。これは前回の6×6接線に初期断面の一般化力を与えた
小変形の比較で、塑性が生じたケースには適用しません。
0.02 MPa・4 ms・CFL 0.2の軸圧縮は一次予測との差約0.17%でした。
この差をゼロとすべき有限変形の解析解と混同しません。

## 初期弾性の形状固定細分化

同じ4 mm形状と空隙率0.25%を保ったまま、558節点・2112四面体に細分化した
初期弾性接線も求めました。微視自由度を消去した6×6接線は正定値で、
有限要素力の中心差分微分との最大相対差は3.84e-9でした。
一方、軸方向コンプライアンスは粗いメッシュと細分化メッシュで**約2.83%**異なります
（細分化側を分母とした差）。

これは初期弾性でも空間離散化の影響が残っていることを示します。
1回の比較から収束や誤差上限を主張せず、塑性圧縮・接触のメッシュ収束とも区別します。
今回の圧力経路は全て100節点・264四面体の初期メッシュから計算しています。
内部再接続が受理された場合は別途ログに残り、形状の変更で合格させる調整は行っていません。

## 実行結果

6ケース全てが目標圧力と保持時間まで完了しました。既存のソルバー・終点検査は4ケース合格、
追加した圧力1%超窓のKE目安は2ケース合格です。不合格ケースも全て保存しています。

| P | 増加時間 | CFL | 最終空隙率 | 追加窓の最大KE比 | 既存検査 | 追加KE目安 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 0.02 MPa | 4 ms | 0.2 | 0.246578% | 3.125790% | 合格 | 未達 |
| 0.02 MPa | 4 ms | 0.1 | 0.246578% | 3.128788% | 合格 | 未達 |
| 0.02 MPa | 8 ms | 0.2 | 0.246578% | 0.797688% | 合格 | 合格 |
| 0.1 MPa | 16 ms | 0.2 | 0.212691% | 1.256310% | KE未達 | 未達 |
| 0.1 MPa | 16 ms | 0.1 | 0.212691% | 1.256275% | KE未達 | 未達 |
| 0.1 MPa | 32 ms | 0.2 | 0.212695% | 0.503004% | 合格 | 合格 |

0.1 MPa・32 msでは、最終の軸圧縮約22.85%、空隙率0.25%→0.212695%、
最終時点の最大相当塑性ひずみ約0.25818でした。接触発生後の追加窓の最大KE比も0.4271%で、
圧力窓全体の0.5030%と併せて1%の目安を満たします。
仕事等価応力の終点相対誤差1.09e-8、エネルギー収支相対誤差1.93e-7。
減衰仕事／外力仕事は約1.31%で、16 msの約2.46%より減少しました。

0.1 MPa・16 msでCFLを半分にしたときの最終空隙率差は3.02e-11、軸圧縮差は1.57e-9でした。
KE比は1.2563%からほぼ変わらず、刻み幅半減だけでは未達が解消しません。
増加時間16→32 msでは最終軸圧縮差7.68e-5、最終空隙率差4.24e-8でした。
この比較を一般的な時間・速度収束の証明や、塑性・摩擦履歴の一致の保証とはしません。

全採用ステップのCSV行数・最終値・KE極値の照合は6ケース全てで合格しました。
低圧0.02 MPaのケースは接触数0かつ塑性ひずみ0で、自己接触・塑性の実績には含めません。
CSVの接触数は両面積分のソース点レコード数で、独立した接触面の個数ではありません。
大きな軸圧縮と空隙率の減少は同じ量ではありません。横方向への変形も許す条件です。

各ケースの設定、計算時ソースとSHA256、全採用ステップCSV、表示用履歴、初期・終点メッシュ、
材料状態、検査結果と失敗理由を保存します。初期と終点のメッシュ接続はそれぞれの実データを使います。
空隙周囲の図は参照y=2 mmにあるメッシュ辺のx-z投影で、孔の節点中心に並進して比較します。
縦横の軸は独立に拡大し、実際の寸法をmmで示します。Euler断面や接触パッチの再構成ではありません。
接触履歴のチェックポイントは未保存なので、NPZを完全な再開ファイルとは扱いません。

リポジトリ直下で既存仮想環境を使い、`PYTHONPATH=.`、
`OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1` を設定します。
必ず未使用の出力名を指定してください。

```bash
python tools/verify_connected_pressure.py --pressure .02 --ramp-seconds .004 --cfl .2 --output results/connected-low-NEW
python tools/verify_connected_pressure.py --pressure .1 --ramp-seconds .016 --cfl .1 --output results/connected-plastic-NEW
python tools/verify_connected_pressure.py --pressure .1 --ramp-seconds .032 --cfl .2 --output results/connected-slow-NEW
```

CFLや増加時間を変える比較では、他の設定を変更しません。
初期弾性の細分化は `python tools/verify_connected_initial_stiffness.py --refinement 2 --output results/connected-refined-NEW`。
`tools/export_connected_pressure.py` の `--inputs` に完了した各ケース、`--initial-refinement` にこの細分化結果、`--output` に未使用の保存先を指定すると
全採用ステップから比較と図を再生成できます。描画は既存のMPLCONFIGDIR・XDG_CACHE_HOMEを使います。

## 適用限界

接触の一般的な辺反力、複数パッチ、表面適応再メッシュ、メッシュ収束、材料校正は未完了です。
局所塑性ひずみが出ても、除荷後の巨視的な残留変形を今回確認したとは扱いません。
低圧で接触しなかったケースは、摩擦・自己接触の検証実績に数えません。
この連結セルの検証から球充填層の40%→10%圧密の完了は主張しません。

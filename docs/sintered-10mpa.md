# E=10 MPaの計算：診断用

ユーザー指定でヤング率を10 MPaへ変更し、圧縮応力0.1 MPaまで再計算した。
設定は `configs/sintered-10mpa.json`。100 mm角、ν=0.33、直径10 mmの球750個、
焼結ネック直径2 mm、周期境界、剛体円柱なし。E以外の設定と使用メッシュは
1 GPaケースから変更していない。形状NPZのSHA256一致を確認した。
C3D8要素400,706個、要素幅1 mm。従来の入力と出力は保持。

## 判定

CalculiX 2.20 / SPOOLESは428.018秒で正常終了したが、結果は **diagnostics_only**。
局所ひずみ成分の絶対最大値が0.9257859（約92.6%）に達し、既存の小ひずみ基準1%に
不合格。CLI終了コードは2。ソルバー自身の終了コード0と、物理的な採用判定を区別する。

| 線形モデルの診断値 | 値 |
|---|---:|
| 平均圧縮応力（初期体積基準） | 0.099999999975 MPa |
| 軸圧縮ひずみ | 0.1539235（15.39235%） |
| セルの軸方向短縮量 | 15.39235 mm |
| 初期空隙率 | 59.9294% |
| 変形節点から算出した空隙率 | 55.51104019% |

上表の変形・空隙率は **適用範囲外の線形外挿値** で、採用可能な予測ではない。
応力目標、他の平均応力ゼロ、正の要素Jacobian、正のセル体積、空隙率の数値的範囲は
合格したが、小ひずみ不合格を補うものではない。メッシュ収束も未検証。
空隙率変化の一次評価-0.0307171と変形座標による体積評価-0.0441836の差も大きい。

同じメッシュの1 GPa計算と比較し、変位100倍の線形関係の最大相対誤差は5.82e-7、
軸ひずみ比は100。出力変位による周期対応節点の残差は7.4e-6 mmで、比較スクリプトの
固定絶対基準1e-6 mmには不合格。変位増大に伴う出力桁数の影響も考えられるが、
この検査を合格へ変更せず、元の判定を記録した。

## 保存と再実行

[診断用記録・CSV](../exports/sintered-10mpa-diagnostics-001/)、
[診断用記録ZIP](../exports/sintered-10mpa-diagnostics-001.zip)。
CSVは線形解の比例荷重履歴であり、非線形増分計算ではない。
大容量の元出力はクラウドの `results/sintered-10mpa-001/` に保持した。
誤解を避けるため、採用済み結果を意味する変形メッシュ画像は作成していない。

```bash
python -m packing_fem.cli run --config configs/sintered-10mpa.json --output results/sintered-10mpa-new --allow-large --timeout 900
```

同条件でも診断用の判定になる見込み。基礎テスト20件は合格。
E=10 MPa・0.1 MPaで妥当な変形・空隙率を評価する次の段階には、幾何学的非線形、
大ひずみに適した材料則、変形で新たに生じる骨格間接触の扱いを整える必要がある。
ヤング率とポアソン比だけでは、大ひずみ域の材料挙動までは特定できない。

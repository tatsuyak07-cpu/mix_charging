# 初期空隙率40%から10%を目指す圧縮試験

ユーザー指定を初期空隙率40%、圧縮後の目標空隙率10%へ変更した。
粒径10 mm、焼結ネック径2 mm、E=10 MPa、ν=0.33は維持した。
剛体円柱なし、温度依存なし、周期境界、準静的圧縮を使用する。
降伏応力0.05 MPa、硬化係数0.2 MPaのJ2塑性は、引き続き未校正の試験材料である。

## 初期形状と数値的な選択

前回と同じ25 mm角の小規模モデルを使う。これは当初100 mm角の本計算やRVE寸法収束とは区別する。
粒子数は18、周期接合候補60、1 mmのC3D8Iメッシュである。
指定40%に対して、最初の離散化では空隙率39.5008%だった。
粒子相互の位置・直径・周期接合グラフを変えず、全粒子を一様に周期移動して、
格子との位置関係だけを変える257候補の体積感度を調べた。
乱数種や焼結寸法を収束のために調整したものではない。

選択した格子位相は `[0.7109375, 0.34979423868312753, 0.872]` mm。
離散メッシュの初期空隙率は **39.8592%**、9,397要素、物理節点14,320。
40%に完全一致したとは扱わない。試験用の初期空隙率許容差を絶対値0.005とし、
実際の差0.001408はその範囲内。元の球・円柱の和集合の正確な体積とも区別する。
細分化・位相平均による形状誤差の検証は未実施であり、特に密充填での
曲面間隙や接合の表現には注意が必要である。

元の形状と位相調査は `results/porosity40-to10-001` に保持した。
`tools/scan_mesh_phase.py` で同じ調査を再現できる。選択した位相自体は設定JSONに保存した。
追加テストは一様移動で周期粒子間距離が変わらず、3方向の接続と初期空隙率条件を保つことを確認する。
目標判定で2つの体積定義を確認し、監査不合格や負の空隙率を目標達成にしない試験も含め、全42テストが合格した。

## 10%の判定と圧縮経路

`target_final_porosity=0.1` を設定し、軸方向の変位を段階的に増加させる。
横方向の一般化荷重は既存の周期モデルと同じくゼロ。
軸圧縮率を空隙率そのものとして扱わず、各端点の変形体積から空隙率を計算する。
幾何体積と内部モードを含む材料体積の両方が10%以下になることを観測上の到達条件とする。
独立した監査の合格も必要であり、目標値を越えたという理由だけで採用しない。

参考として、骨格体積一定の場合、初期40%から10%には巨視的体積比
`J = (1-0.40)/(1-0.10) = 2/3` が必要となる。
これは横寸法固定なら軸圧縮約33.3%に相当するが、今回の横荷重自由の条件には
そのまま適用できない。必要な荷重や軸圧縮量は解から求める。

当初65%の軸圧縮探索幅を指定した `porosity40-to10-002` は、既存の
「試験圧縮は50%未満」という入力検査で拒否された。この失敗設定と記録を保持し、
上限を迂回せず、`porosity40-to10-003` では探索幅49%、100観測段階とした。
この49%は目標10%との対応を仮定した値ではない。
設定中の `target_mpa=0.1` は共有入力の参照値であり、今回の変位制御では荷重上限・到達条件に使わない。

幾何空隙率と材料空隙率の絶対差10⁻⁴という既存監査条件は変更しない。
超過、要素不正、非収束、計算時間上限などの場合は、10%へ外挿せず未到達と記録する。
監視は `ramp-stop.json`、完全な端点の抽出は `recovery.json` に記録する。
中断されたDAT末尾や未収束の反復値は結果に含めない。

## 現モデルの限界

粒子表面同士の自己接触と破壊は実装されていない。
したがって空隙率10%付近で重要となる再接触・圧密を検証できず、
表面の非貫入も保証できない。粗いボクセルによる人工的な接続も未検証である。
圧密曲線を物理予測として採用するには、周期自己接触、空隙体積評価、
メッシュ細分化、材料校正が必要である。

再実行例（既存フォルダは上書きしない）：

```bash
python tools/run_porosity_target.py --config configs/porosity40-to10-trial.json --output results/porosity40-to10-004 --timeout 1200
# 別のプロセスで監視する
python tools/monitor_pressure_ramp.py results/porosity40-to10-004
# 中断後は完全な端点だけを新しいフォルダへ抽出する
python tools/recover_pressure_endpoints.py --source results/porosity40-to10-004 --output results/porosity40-to10-004/recovered-endpoints-001
python tools/export_porosity_target.py --source results/porosity40-to10-004/recovered-endpoints-001 --output exports/porosity40-to10-002
```

軸圧縮9.8%で、幾何空隙率36.36724%、材料空隙率36.35640%、
両者の絶対差0.00010840が監査上限0.0001を超えた。
これはソルバーの非収束宣言とは異なり、既存の体積精度条件による意図した停止である。
公称圧縮応力は0.0161001 MPa。**目標10%は観測されず、到達応力も求まっていない。**
この停止点はPNGで赤×、CSVの `volume_definition_check=False` で示した。
それ以前の端点も、自己接触・メッシュ収束・材料校正が未検証なので物理予測として採用しない。

停止時には次の21段階目の出力が不完全だったため、通常の監査はDATを拒否した。
元ファイルと `analysis-error.json` を保持し、完全な20端点を
`results/porosity40-to10-003/recovered-endpoints-001` へ抽出した。
21段階目の反復値や欠落したひずみを補完せず、元の完全なDAT接頭部とrestartレコードを用いた。
大容量のネイティブDAT/FRD/restartはクラウドに保持し、配布にはCSV・入力・ログ・
幾何NPZ・最終VTU・停止/抽出記録を含めた。
PNGのメッシュはC3D8Iの角節点の変形を実倍率1倍で表示している。
体積・応力・仕事の監査では内部モードも含めている。

個別検査では積分点J・巨視的Jは正、周期変位残差2.78×10⁻¹⁵ mm、
ネイティブGreenひずみとの最大絶対差4.92×10⁻⁷、
巨視・微視仕事の相対差3.43×10⁻⁸、観測経路の仕事とELSEの差0.9701%。
最大PEEQは0.988725で、塑性蓄積は単調かつ硬化表の範囲内だった。
荷重増分・メッシュへの感度は今回の40%モデルでは未検証である。
`cycle_work_relative_error` は継承した名称で最終観測点までの仕事差を表すが、
除荷未完了なのでサイクル検証や残留変形の評価とは扱わない。
総合判定は **diagnostics_only**、残留ひずみはnull。

この試行だけから空隙率10%への到達荷重や変形を外挿しない。
10%を扱う計算には、体積評価のメッシュ精度の改善と周期自己接触を含むモデルの検証が必要である。

# 荷重増加と空隙率の試験計算

前回の1%変位制御から、公称圧縮荷重を段階的に増加させる荷重制御に変更した。
巨視的公称応力Pzzの大きさを指定し、現断面積に対するCauchy応力は別に出力する。
これは有限変形中のCauchy応力を0.1 MPaに追従制御する計算ではない。

物性と形状は前回の小規模検証から変更していない。
25 mm角、12粒子、粒径10 mm、焼結ネック径2 mm、C3D8I・1 mmメッシュ、
6,372要素、E=10 MPa、ν=0.33。
初期の離散メッシュ空隙率は59.2192%。
降伏応力0.05 MPa・硬化係数0.2 MPaのJ2塑性は未校正の試験材料である。
温度依存、自己接触、破壊は含めない。100 mm角の本仕様や、粒子充填層の
定量的に検証された圧密曲線としては採用しない。

`pressure-ramp-001` は0.1 MPaまで100分割（0.001 MPa刻み）、
`pressure-ramp-002` は低荷重域の比較として0.01 MPaまで100分割（0.0001 MPa刻み）。
各観測点の静的ステップ内ではソルバーの自動細分化を許す。
最後に除荷ステップを指定するが、途中で停止した場合は除荷完了とは扱わない。
物性・接合形状・ソルバーの収束許容値は、収束させるために変更していない。

CSVは完了した圧縮ステップ端点のみを収録し、初期状態を幾何から追加する。
未収束反復値は収録しない。途中停止や監査不合格の場合、端点の計算値も
探索用の診断値として表示し、全荷重経路の検証済み解とは呼ばない。
空隙率は角節点の幾何体積と、内部モードを含む材料体積による値を併記する。
定義・restartリーダーの制限は[内部モードの検証](periodic-incompatible-verification.md)を参照。
自己接触の検出自体は未実装であり、非貫入の保証はない。

実行例（既存結果は上書きしない）：

```bash
python tools/run_pressure_ramp.py --output results/pressure-ramp-003 --target-mpa .1 --steps 100 --timeout 900
python tools/export_pressure_ramp.py --source results/pressure-ramp-003 --output exports/pressure-ramp-003
pytest -q
```

均質周期セルに公称0.06 MPaまで荷重を与え、降伏後の塑性蓄積と除荷を確認する
試験を追加した。除荷未完了時に残留ひずみを出さない試験も含め、全37テストが合格。
最初の新規試験では荷重誤差1e-5という厳しい仮定で不合格になった。
ネイティブの既定反復収束で最大誤差はフルスケールの約6.3e-5だったため、
この検査はフルスケールの1e-4未満（0.01%）とし、ソルバー設定は変更していない。
試験用ログは `/tmp/pytest-of-agent/pytest-29` に保持した。
これは本体監査の1%基準より厳しい独立荷重確認である。


## 停止と完全な端点の抽出

前回からの体積定義の監査条件（空隙率の絶対差10⁻⁴未満）をそのまま使用する。
`tools/monitor_pressure_ramp.py` は、この条件を超えた時点で当該計算のネイティブ
ソルバーだけを停止する。監視は別プロセスで実行する：

```bash
python tools/monitor_pressure_ramp.py results/pressure-ramp-003
```

親プロセスの実行引数と出力ディレクトリを確認して停止対象を特定する。
停止理由・しきい値・観測値は `ramp-stop.json` に保存する。
この停止はソルバーが非収束を宣言したこととは区別する。

最初の停止では、0.007 MPaの節点変位とrestartから体積差を検出したが、
DATのひずみ・エネルギー末尾はバッファから完全に書き出されていなかった。
通常の監査は不完全データを拒否した。元ファイルと `analysis-error.json` を保存し、
完全な0.006 MPaまでの6端点を `recovered-endpoints-002` に抽出して監査した。
最初の抽出 `recovered-endpoints-001` も保持する。後者では「除荷未完了なら残留ひずみはnull」
という表示修正を適用した。計算値の補間や欠落したひずみの生成はしていない。
監視側も、ひずみ・応力・PEEQ・エネルギー・EVOLの全出力を確認してから停止するよう修正した。

抽出は新しいフォルダにDATの完全なバイト列接頭部と対応するrestartレコードを保存する。
元の中断計算は変更しない。完全な端点も含め、途中停止した経路は `diagnostics_only`。
荷重中の圧縮を残留・永久ひずみとして扱わない。

```bash
python tools/recover_pressure_endpoints.py --source results/pressure-ramp-003 --output results/pressure-ramp-003/recovered-endpoints-001
```

監視が完全な0.0065 MPa端点で超過を確認して停止した。

軸圧縮14.5299%、Cauchy圧縮応力0.00624952 MPa。
**これらの超過点は物理予測として採用しない。** PNGでは赤×、CSVでは
`porosity_definition_check=False` として表示した。0.0066 MPaのDAT末尾は不完全で除外した。
元の中断ファイルと監査拒否を残し、完全な65端点は
`results/pressure-ramp-002/recovered-endpoints-001` に抽出した。

0.006 MPaまでは体積定義差の検査内だが、自己接触、メッシュ収束、材料校正、
RVE寸法依存の検査は未実施であり、その範囲も定量的な実材料予測とは扱わない。
初期60%という指定と離散化後59.2192%も区別する。
両経路は除荷・目標荷重に未到達であり、総合判定は `diagnostics_only`。
0.1 MPaへ外挿していない。

## 荷重刻みと監査

共通の荷重点における粗い刻みと細かい刻みの最大圧縮ひずみ相対差は1.524%。
0.006 MPaでの空隙率差は0.05954パーセントポイント（空隙率の絶対差0.0005954）。
ひずみの探索用2%基準内でも、空隙率を絶対差10⁻⁴以内で確定するにはさらに荷重刻みを
細分化して比較する必要がある。荷重刻みの収束達成とは宣言しない。

粗い刻みの6端点では、台形積分による観測経路の仕事とソルバーELSEの相対差は15.04%。
細かい刻みの65端点では0.00773%に減少した。
後者の巨視・微視仕事の相対差は1.82×10⁻⁷、公称荷重との相対差は3.51×10⁻⁷、
ネイティブGreenひずみとの最大絶対差は4.77×10⁻⁷、周期変位残差は2.78×10⁻¹⁵ mm。
積分点Jは正、PEEQは単調、最大PEEQは1.3347で硬化表の範囲内だった。
これらの個別合格によって体積監査不合格や接触未実装を相殺しない。
旧名称の `cycle_work_relative_error` は最終観測端点までの仕事差であり、
除荷未完了の本結果ではサイクル全体の検証を意味しない。`unload_complete=False` を併記している。

次の作業には荷重刻みの追加細分化、C3D8Iでのメッシュ細分化、空隙体積の評価方法の確認、
周期自己接触の導入が必要となる。現モデルをそのまま0.1 MPaまで延長した結果は採用しない。

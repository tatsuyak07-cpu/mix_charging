# 塑性・接触・除荷一周期の時間刻み検証

物性・接触条件・荷重履歴を固定し、CFLを0.2から0.1へ半減します。
対象は4 mm角、初期空隙率0.25%の連結検証セル（100節点、264四面体）です。
要求仕様の100 mm球充填層、初期空隙率40%から10%への圧密計算ではありません。

## 条件と事前判定

E=10 MPa、ν=0.33、試験用J2降伏応力0.05 MPa、硬化係数0.2 MPa、
摩擦係数0.3を共通とします。温度依存性は含めません。
一軸Cauchy圧力0.1 MPaまで32 msで増加し、2 ms保持、8 msで除荷、2 ms回復させます。
数値密度1e-9 tonne/mm³、減衰6000/s、接触ペナルティ20 MPa/mmも変更しません。
横方向とせん断方向は自由、周期境界を使用します。

細刻み計算の完了前に、残留圧縮ひずみの絶対差1e-4、全過程の空隙率の絶対差1e-7、
全過程ひずみ差/基準最大ひずみ1e-3、最大PEEQ相対差1e-3を判定閾値として保存しました。
時系列は両計算の採用時刻の和集合へ線形補間して比較します。
既存ソルバー判定、終点の体積・応力検査、細刻み計算の独立反力監査も必要条件です。

独立監査の `--force-only` は過去の同刻み計算とのビット一致検査だけを省略します。
反力・モーメント・Coulomb則・ポテンシャル・釣合いの閾値は変更しません。
既定モードの過去結果の完全一致検査も維持します。
保存反力を意図的に改変した負例で、独立監査が不合格になることを検査しています。

## 結果

事前に設定した比較11項目、細刻みの独立反力監査12項目がすべて合格しました。

| 指標 | CFL 0.2 | CFL 0.1 |
|---|---:|---:|
| 採用ステップ数 | 142,355 | 284,709 |
| 残留圧縮ひずみ | 0.220712368178 | 0.220712362568 |
| 最終空隙率（%） | 0.221729978598 | 0.221729970951 |
| 載荷区間の最大KE/内部エネルギー比（%） | 0.503003909 | 0.503007263 |
| エネルギー収支相対誤差 | 1.93074e-7 | 9.65633e-8 |
| 既存の終点静的残差比 | 0.00210083 | 0.00196272 |

残留ひずみの絶対差は5.61e-9、全過程の最大空隙率差は1.136e-8、
最大ひずみ差/基準最大ひずみは3.819e-6、最大PEEQ相対差は2.191e-7です。
この比較の範囲では、時間刻みを半分にしても変形・空隙率の変化は小さくなりました。

細刻み終点の独立反力再構成誤差は、差分幅4e-7 / 2e-7 mmで
1.235e-10 / 2.051e-11 Nです。自由度釣合い残差は約1.57e-9 N、
終点Coulomb比は0.233446で上限0.3以内です。
既存の終点残差比はゼロ荷重用の小さな力下限で正規化されるため、
独立監査の最大荷重基準の残差比約9.82e-10とは分母が異なります。
関連テスト4件に合格し、従来のビット一致監査も再実行して合格しました。
ソルバー本体・材料・接触力計算・合否閾値は今回変更していません。

## 再現

```sh
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m tools.verify_connected_pressure \
  --output results/NEW_FINE_RUN --pressure 0.1 --ramp-seconds 0.032 \
  --unload-seconds 0.008 --recovery-seconds 0.002 --cfl 0.1 \
  --max-steps 300000 --save-contact-audit
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 python -m tools.audit_contact_capture \
  --input results/NEW_FINE_RUN --output results/NEW_FINE_AUDIT --force-only

  --coarse exports/contact-reaction-audit-001/simulation --fine results/NEW_FINE_RUN \
  --fine-audit results/NEW_FINE_AUDIT --output exports/NEW_COMPARISON
```

## 適用範囲

一回の時間刻み半減による感度の確認であり、漸近収束次数やメッシュ収束を確立しません。
監査対象は記録された接触集合であり、接触探索の独立な検証ではありません。
辺接触や複数接触パッチへの一般化、表面の適応再メッシュ、40%→10%圧密の検証は継続課題です。
保存状態は積分器全体の再始動チェックポイントではありません。

## 修正した式

既存の材料点と正の積分重みを保持する。各親面の残差を `r=Mw−reference`、参照応答の尺度を `s`、相対精度を `τ` とすると、監査の条件は次のとおり。

```
energy_excess = max(|r[0]| − τ s[0], 0)
force_excess  = Σ_i max(|r[i]| − τ s[i], 0)   (i > 0)
```

親面ごとの上限と、同じ配置に属する親面全体の超過合計の上限を課す。エネルギーと力の予算は別々であり、単位はそれぞれN mmとN。受理済み配置と試行配置は別の時点なので、各配置に独立した全体予算を適用する。過去/制御姿勢の絶対予算0という既存条件は維持する。

`conservative_quadrature.py` のLPに非負の超過変数を追加し、L1合計を直接制約した。親面/成分への均等配分は廃止した。`redistribute` は受理済み・試行の各グループに、実際の監査と同じ全体上限 `B/2` を渡す。各親面の監査上限も維持する。解いた後に独立した `response_audit` で同じL1条件を再検査する。

元の重みが監査と固定重み範囲に合格する場合は、そのまま返す。これにより、監査境界上にある認証済み状態も許容される。変更が必要なLPの内部には、丸め誤差対策として相対許容/予算を1e-6だけ縮めた安全余裕を置く。最終判定は元の監査基準で行う。従来の半分の許容量を全ての状態に強制する方式は廃止した。

全旧周期自由度に対する仮想仕事、法線・確定/力評価用摩擦・実接線ポテンシャルのエネルギー、面積/2次モーメントの保存制約、固定基準重みの0.5～2倍という範囲は維持する。材料・摩擦・形状・載荷・周期条件・参照積分・物理的な誤差予算は変更していない。

## 結果

| 検証 | 結果 |
|---|---|
| 新規5テスト | 集中した成分誤差、親面共有予算、実際の再配分、エネルギー/力/時点の独立性、監査境界の許容性が合格 |
| 関連回帰・ネイティブ要素検証 | **84件合格、スキップ0**。ネイティブ要素のNumPy/解析解との比較も含む |
| 平面接触 | 相対精度3水準×初期滑り2条件の全6条件で正逆増分、Coulomb境界、接触状態の保存/再開が合格 |
| 動く平面の陽解法 | 再メッシュ、3刻み継続、保存/再開の配列一致、棄却時の軌道不変が合格。時間刻み収束の試験ではない |
| 保存済み充填層の受理済み配置 | 力超過L1=1.19823719e-7 N ≤ 1.25e-7 N。**重み変更0で合格** |
| 同じ行列の試行配置のみ | 保存制約を維持すると実行不能 |
| 過去/制御姿勢を含めた条件 | 次配置を除いても実行不能。全条件も実行不能 |
| 実充填層 | 接触前から再計算し、90,250刻みの再メッシュを承認。90,262刻みの次の試行で保存射影が実行不能となり停止 |

平面12増分の受理済み反力保存誤差は最大6.53e-16、エネルギー誤差は最大2.78e-15、保存/再開後の反力誤差は0。最大接線力/法線力は0.3000000000000002で、μ=0.3の境界を丸め誤差内で満たした。

充填層の最後の受理空隙率は36.94169748%という過渡値。試行の親面3166では力超過1.34212430e-7 Nで精度監査に不合格となり、修正後の射影も `HiGHS Status 8: Infeasible` を返した。元の状態を維持して停止した。前回と共通する56刻みで時間・空隙率・軸圧縮・圧力・運動/内部エネルギーが完全一致した。静的平衡・目標空隙率・保持/除荷完走は未合格。

補助診断では、保存行列の面積/2次モーメントだけを残すと試行配置に適合する重みが得られたが、力・エネルギーの保存を満たす物理解としては採用していない。エネルギーとモーメントを残す診断も独立保存監査で棄却された。これは既存点の重み調整の自由度と、保存制約の両立をさらに検討すべきことを示す。誤差予算の修正だけで大変形が解決したとは扱わない。

## 環境・入力の復元と再実行

今回の環境には前回の一時resultsと仮想環境がなかったため、GitHubのZIPから入力を復元し、`requirements-lock.txt` の固定ライブラリを導入した。ネイティブ要素は同じソース・同じ-O3/C++17/no-fast-math条件で計算前に再ビルドした。復元途中の回帰試験はmeshio不足で12件が失敗し、任意ネイティブ検証6件がスキップされた。依存関係とライブラリ指定を整えて84件を再実行し、全件合格した。失敗ログも保持する。

初期の新規単体テスト1件は、成功を検査する参照値自体が重みの下限と両立しなかった。正の重み範囲内に入る参照値へ修正し、別の実行不能テストを維持した。物理計算の条件は変更していない。

接触前90,206刻みの認証済みチェックポイントを開始点とし、前回の最終試行で準備済みだった**分割前**の4親面の積分則を使った。接触中の古い状態を新演算子で時間発展させていない。全体誤差予算はエネルギー・力ともB=2.5e-7、監査上限はその半分。入力行列のハッシュと実行時ソースをZIPに保存する。

```bash
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m pytest -q tests/test_l1_budget.py
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python tools/verify_l1_matrix.py --matrices <復元したconstraint-matrices.npz> --output results/new-l1-matrix
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python tools/verify_runtime_parent.py --output results/new-l1-plane
```

次は、保存制約を保ったまま試行配置の精度を満たせるよう、積分点追加と接触前からの履歴再生、再配分を行う時点、再メッシュに伴う自由度の増加を比較検証する。履歴を消したり、保存条件を外した診断解を圧密結果に使ったりしない。

# ほぼゼロ離隔の辺対：丸め誤差と接触確認条件の検証

**保存した辺対では、丸め誤差による誤った除外判定を確認し、修正した。別の位置にある端点の接触だけで辺対を通過させる確認条件の不足も再現したが、こちらは未修正である。** 今回は保存形状の検証で、圧縮の時間積分は実行していない。

[判定比較図](../exports/near-edge-001/near-edge-checks.png)、[局所形状図](../exports/near-edge-001/near-edge-geometry.png)、[CSV](../exports/near-edge-001/classification-variants.csv)、[判定JSON](../exports/near-edge-001/summary.json)、[全データZIP](../exports/near-edge-001.zip)。前段は[候補選択と再試行の検証](closest-selection.md)。

## 対象と独立計算

前回、移動中の表面の非交差チェックで刻み縮小を繰り返し、既存下限10⁻¹⁴ sで停止した採用状態を使用した。対象は辺[175,384]と[385,401]、周期シフト[0,0,0]。倍精度での離隔は約2.9863×10⁻¹⁰ mmだった。

入力に保存された倍精度座標を、`Decimal.from_float` でその値を正確に表す十進数へ変換した。辺同士の内点・内点の最短点を80桁と100桁で独立に計算した。この参照式は内点・内点に限定し、端点や平行辺には適用せず拒否する。FEMの接触ソルバーを高精度演算へ置き換えたわけではない。

最短位置は元の辺でs≈0.5899021917、相手の辺でt≈0.3578660215、離隔は約2.9863032316×10⁻¹⁰ mmとなった。80桁と100桁の離隔差は10⁻⁷⁰ mm未満だった。これは保存された数値形状の計算精度の確認であり、物理的な寸法精度を表さない。

## 誤った距離減少の根拠

従来の表面方向微分判定は、相手の辺の端点385へ向かう方向を「距離が減る根拠」としていた。倍精度の方向余弦は約+2.86×10⁻⁶だった。

しかし、辺同士の最短点では、元の辺に沿う方向は距離減少の根拠にならない。内点なら直交条件で方向微分がゼロ、端点なら元の線分内への移動で距離を減らせない。80桁の独立計算では、両側の辺端点への方向余弦は絶対値10⁻⁶⁰未満となった。最短点の世界座標同士を引く際の丸め誤差が、ほぼゼロの離隔で増幅されていた。

一方、元の辺を外れる各三角形の第3頂点への方向余弦は、約−0.02014、−0.81271、−0.82047、−0.09428で、いずれも負だった。この辺対を除外する正しい距離減少方向は得られなかった。

`SurfaceStationarity.classify` を修正し、元の辺の端点への方向を除外の根拠に使わないようにした。周期コピーでは参照座標と周期シフトで対応を判定する。判定閾値1e-10、接触厚さ、材料、摩擦、刻み下限は変更していない。追加の任意の丸め許容値で通過させる変更ではない。

回転・平行移動9条件と、対象4節点の各座標への±10⁻¹² mmの摂動24条件、計33条件を検証した。従来判定は33条件すべてで誤って辺対を除外した。修正後は33条件すべてで除外せず、辺を外れる最大方向余弦は約−0.02012〜−0.02017となった。この試験で旧判定の真偽が回転ごとに変わったという結果ではない。

## 保存状態では局所三角形はまだ交差していない

独立計算で得た法線を使い、両側の辺に隣接する三角形の全頂点を投影した。法線自体は80桁参照計算の近似値でよい。選んだ法線・基準点を正確な有理数とし、保存された各倍精度頂点も `Fraction.from_float` で正確な有理数にして、投影の積和を丸めなしで計算した。

両側の投影区間が厳密に分離しており、それぞれの局所凸包が交わらないことを確認した。したがって、**この保存時刻の対象辺に隣接する局所三角形**はまだ交差していない。モデル全体や、採用時刻と次の試行の間の非交差を証明したものではない。既存の移動中の非交差チェックを外してよいという結論ではない。

## 端点の接触だけでは辺対を解像できない

対象4端点のうち、端点401は接触履歴を持っていた。その接触対象は三角形[3793,400,191]で、端点401からの点・三角形距離は約0.01358 mm。問題の辺対の最短点は端点401から約0.51990 mm離れている。端点の接触が存在することだけでは、離隔約3×10⁻¹⁰ mmの辺内部を接触積分が捉えていると確認できない。

既存のガードは「対象辺のいずれかの端点が選択された点接触を持つ」場合に辺対を通過させる。修正後の方向微分では対象辺対を除外しなくなったが、保存状態の評価はこの端点条件により引き続き通過した。この事実を診断で再現した。**丸め誤差の修正だけで接触問題を解決したとは判断していない。**

次は辺対と接触積分点の幾何的な対応を確認する条件を設計し、実際の交差辺を止める試験と、平面の分布接触を不必要に止めない試験の両方で検証する。平面の接触では、同じ隙間を多数の節点が積分できるため、単純に「最短点が辺内部なら常に分割」とするだけでは不十分である。監査付きの再分割・再試行へ接続するのは、この確認後とする。

## 検証の範囲

診断9項目が合格した。このうち「端点条件で通過することの再現」は既知の不足を確認する項目であり、物理モデルの合格を意味しない。新規テストでは保存辺対、回転・平行移動、交差辺の解析的離隔、有理数投影による分離・交差の対照を確認した。既存の正しい距離減少方向の検出試験も維持している。

全体272テストが合格し、ネイティブ要素カーネルのテストも実行した。失敗・skipはない。全体実行の収集後に追加した有理数投影の2件を含む、最終の関連15テストもすべて合格した。

初回の高精度診断は、補助計算の符号反転でDecimalの既定28桁へ精度が落ちたため、ゼロ微分の確認が不合格だった。値を丸めずに符号反転する処理へ修正した。初回の不合格出力とソースも保存している。

圧縮の時間積分は行っていないため、今回の修正によって前回の停止点を越えたという結果はない。0.1 MPaの準静的な圧密解、空隙率40%→10%、接触積分のメッシュ収束は未達成である。

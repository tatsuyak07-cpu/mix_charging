# 浮遊剛体円柱：工程1〜3

現在は工程3の圧縮計算を実行中。載荷空隙率10%への到達までは完了と判定しない。
既存の剛体なし結果は変更せず、今回の形状・計算・不採用試行を別の保存先に残す。

## 条件と今回の範囲

最終物理条件は100mm角の充填層中の直径20mm・高さ20mm円柱。
今回の数値結合試験は16粒子、球径10mm、焼結ネック径2mm、円柱直径4mm・高さ4mmとする。
これは100mm系の相似モデルや定量的な影響予測ではない。
骨格E=10MPa、ν=0.33、開発用の降伏0.05MPa・硬化0.2MPa、摩擦0.3を維持する。
円柱は非接着で自由並進・自由回転。位置固定の支持や大きいヤング率による擬似剛体は導入しない。
温度・重力・空隙内圧・保持・除荷は今回の対象外。

目標は「円柱体積を除いた領域」の空隙率40%→約10%。
`phi_matrix = (Vcell - Vsolid - Vrigid)/(Vcell - Vrigid)`、
`phi_total = (Vcell - Vsolid - Vrigid)/Vcell` を区別する。
骨格の弾性圧縮は許し、基準材料体積を保存する。剛体の形状・体積は一定。

## 工程1：剛体の有限運動と接触

独立未知数は並進3成分と、半径で長さに換算した回転3成分。
XYZオイラー角の有限回転と一次・二次微分を用いる。
円柱頂点は `H (center + image_shift) + translation + R local_vertex`。
セルの圧縮は中心と周期画像の間隔に作用し、剛体表面の相対座標には作用しない。
オイラー座標がジンバルロック近傍になる場合は受理せず、再チャートが必要と明示する。
接触していない剛体の位置は静力学だけでは一意でないため、初期推定では中心をセルに追従させる。
その動きを慣性運動の予測とは解釈しない。

固体と円柱を同じ周期IPC接触集合に入れ、前状態との実際の頂点位置差から摩擦すべりを計算する。
瞬間ヤコビアンに回転増分を掛けた近似変位は使わない。
接触の非対称ヤコビアンには、回転写像の二次微分と接触力による幾何項も加える。
一般化力の残差に加え、世界座標の剛体力と「トルク／半径」を確認する。
最終の許容力は各成分0.005N未満。

円柱は64分割の閉じた三角形面で表す。接触形状の体積50.184776mm³と、
公称円柱の解析体積50.265482mm³の差は約0.161%。形状分割依存性は未認定。

## 工程2：周期境界・履歴・再メッシュ

X・Y周期寸法を固定し、巨視的せん断はゼロ。微視的な周期変位と剛体6自由度は自由。
再メッシュ時は材料積分点履歴と基準体積を転送し、剛体の世界位置・姿勢を保つ。
失敗反復の配置は初期推定だけに使い、材料履歴として受理しない。
摩擦は既存の増分クーロンモデルを維持し、永久的な接線ばね履歴の保存を新たに主張しない。

円柱を縮める一様アフィン予測では初期貫通を起こすため、円柱近傍は剛体移動、
遠方はアフィン圧縮となる滑らかな周期的初期推定を使う。
これは探索の初期値であり、受理状態では元の力の釣り合いを解く。
回転軌道の弦からの最大偏差を `rho*(h*sum(abs(delta_angle)))²/8` で抑え、
その2倍の離隔を要求する線形CCDで、実際の非線形回転軌道の交差を防ぐ。
接触候補を再利用する場合も、この偏差を含む囲み箱で全頂点を覆い、範囲外では再探索する。

## 初期形状

既存のランダム16粒子配置を周期的に平行移動し、円柱用の空隙を中心へ移した。
形状だけを用いるシード20261110の配置探索で、荷重結果を見て場所を選んでいない。
球との最小すき間0.553024mm、ネックとの最小すき間2.504563mm。
粒子やネックの切除・重なりはない。
載荷前にセル長を24.140718mmへ較正し、公称円柱を除いたCAD領域の空隙率を40%にした。
載荷中の両横周期寸法はこの値のまま固定する。
メッシュは21561節点・65407四面体、測定初期充填層空隙率40.4057%。
±0.5パーセントポイントの既存幾何許容差内であり、体積補正はしていない。

初期メッシュの最小品質は0.0503。品質改善の受理・拒否をすべて残す。
最初の再メッシュで品質0.0670へ改善し、次の周期辺細分も受理した。
さらに改善しない修復は拒否し、その状態を改善済みと表示しない。
初期状態には弱いIPC自己接触力があるため、初期NPZは数値緩和前の幾何状態として表示する。

## 検証と進行状況

剛体形状・体積、有限回転の微分、周期画像、法線・摩擦接触のヤコビアン、
実回転軌道のCCD、非貫通載荷予測、断面積、候補キャッシュ有無の力・ヤコビアンを確認する。
関連82テストに合格。周期境界をまたぐ剛体接触の小規模試験では、27画像と125画像で
摩擦を含む一般化力・剛体合力・トルク・接触項数・障壁エネルギーが一致した。
実充填層の最終状態での拡大周期画像監査は、目標到達後に別途行う。
5.625%圧縮・充填層空隙率36.9415%までの独立再計算は、材料履歴・圧力・クーロン上限・
剛体力・世界トルク・形状保持・体積・周期寸法の監査に合格した。
この段階では剛体接触が1項あり、弱い接触力が発生している。

メッシュ・増分・円柱分割・再メッシュ閾値の収束、統計的等方性、剛体の有無による
定量比較は未認定。工程3の完了条件は、今回の小規模系で載荷空隙率約10%へ到達し、
元の力と剛体の釣り合いを独立に再計算できることとする。

## 数値探索と品質判定の修正

元の探索001は9.53125%圧縮で最大残差約0.0091Nとなり、補助L2上限に張り付いた。
探索切替のRMS係数0.2と、ピーク探索の補助上限を分離した。
後者は `force_tolerance*sqrt(nFree)` とし、元の最大成分の許容値0.005Nを満たす解を
補助上限で排除しない。材料・摩擦・接触障壁・最終力許容値は維持した。
探索002は同じ受理済み5.625%履歴から再開し、9.53125%圧縮・充填層空隙率34.2357%へ収束。
剛体接触9項、自由力最大残差0.00480139N。独立した履歴・力・世界トルク監査に合格した。
その6反復という記録は、001で作った保存配置の準備費用を含まない。

回転軌道を覆う接触候補のキャッシュは、実メッシュで接触73項が一致し、
新規探索との力差は最大1.78e-15N。全体の高速化率を示すベンチマークとはしない。
剛体の移動だけを制限する別の候補は改善しなかったため採用しない。

002では剛体接触中の履歴転送・姿勢保持・再平衡を通過した。
ただし最小品質差6.94e-17を改善とする旧判定があり、実質的な品質改善とは認定しない。
材料体積・エネルギーの転送誤差は約3e-10、再平衡残差は0.00439Nだった。
品質差に `max(1e-12, 1e-8*quality_before)` を要求する修正を加えた003を主経路として進め、
002は保存した比較分岐として扱う。境界や物理形状を変更して合格させる操作は行っていない。

保存した002の再メッシュ実行ソースを用い、受理済み状態から転送と再平衡を再現した。
トポロジー・積分点・基準体積・材料履歴が一致し、転送時の剛体姿勢誤差はゼロ。
再平衡の自由力最大残差0.00438918N、剛体接触7項、世界合力・トルクとクーロン監査も合格した。
これは接触中の保存転送の確認であり、丸め誤差の品質改善を認定するものではない。
この比較分岐は保存して停止した。

14.4140625%圧縮の大きい増分では、003のL2残差探索が90反復を超えても未収束だった。
004では、L2が `force_tolerance*sqrt(nFree)` 以下になった時点で最大残差探索へ移る比較を行う。
005は受理済み9.53125%から荷重増分を半分の2.44140625%に減らして再開する。
003の未収束形状は初期推定にだけ使用し、材料履歴は転送しない。
二つの半増分は14.4140625%に一致するが、増分収束が確認済みという意味ではない。
剛体の再載荷予測と二分予測には、非線形回転を含む経路の非交差確認を加えている。

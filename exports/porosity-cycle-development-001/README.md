# 空隙率40%→10%：圧密・保持・除荷サイクルの開発

到達目標は**載荷・平衡状態の空隙率10%**だけに限定した。0.1 MPa到達、100 mm実寸モデル、剛体円柱は今回の完了条件に含めない。除荷後の空隙率は別に報告する。**実充填層の40%→10%サイクル完走と収束確認は未達成**である。

## 保持した物理条件

小周期BCCセル（12.1 mm、等価2球）、球径10 mm、焼結ネック径2 mm、E=10 MPa、ν=0.33、摩擦係数0.3。既存の等方Hencky弾性・Kirchhoff J2塑性（試験降伏応力0.05 MPa、硬化係数0.2 MPa）を使う。温度項を追加していない。塑性定数は粘土様の仮置きであり、焼結鉱の実験校正値ではない。横方向の巨視的応力を自由にした周期境界を維持する。

数値密度1e-9 tonne/mm³、減衰6000/s、CFL 0.2、接触バリア厚さ0.02 mm、法線剛性20 MPa/mmを維持した。初期試行は既存のボクセル四面体メッシュで、初期空隙率39.84375%（要求40%に対する幾何許容差内）である。固体FEMの計算であり、DEMへ置き換えていない。

## 実装

- `PorosityCycle`：軸圧縮を増分し、各段階で力・運動エネルギー・エネルギー収支が合格するまで保持する。平衡空隙率が10%に到達したら、反力を連続な外力に引き継ぎ、外力ゼロまで滑らかに除荷して回復を保持する。圧力上限は設けない。
- 目標を許容差0.001以上下回る過圧縮、平衡時間超過、探索ひずみ上限到達は不合格にする。過圧縮時の自動巻き戻し・ひずみ二分探索は未実装である。
- 2→3に加えて3→2・4→4の内部四面体再接続を追加。表面と節点は変更せず、接触積分点と摩擦履歴を保持する。参照体積、状態エネルギー、内部力、運動量・運動エネルギーを監査する。任意の表面再生成や節点移動による品質回復とは異なる。
- 小配列を形状・型別にまとめるチェックポイント形式2を追加。配列値の丸めや履歴の補間は行わず、旧形式1も読み込める。
- 接触積分の誤差床をエネルギー・力の尺度で正規化する選択肢を本体へ接続。従来設定は維持する。
- 新積分則の追加は接触前の認証済み状態から**連成計算全体を再実行**する。未知の摩擦履歴をゼロで補わない。
- 積分則の往復を避けるため、既存の材料三角形分割を引き継いで細分化する試験実装を追加。分割の重複と穴を、面積だけでなく三角形交差で検査する。積分点変更時の履歴再計算は引き続き必要である。**保存RVEで未合格のため`retain_surface_partition=false`を標準にし、試験用に分離した。**

## 確認できた範囲

| 工程 | 結果と限界 |
|---|---|
| 接触・履歴の統合 | 既存の埋込み接触を空隙率サイクルへ接続。実充填層の接触開始付近では積分則が往復し停止。分割保持方式の追加試験も未合格（下記）。一般の積分点追加時の履歴移行は未完了。 |
| 接触中の再メッシュ | 接触・すべりのある平面対照で、内部再接続前後の力・接触エネルギー・ばね・塑性すべり・法線・相手座標を保持。一般の表面再生成、実充填層の大変形での品質維持は未合格。 |
| 少数粒子の圧密・保持・除荷 | 実充填層は下記4保持段階に合格。除荷まで完走していない。別の弾性有孔セルでは37.5%→37%載荷・保持→37.5%回復の全サイクルを確認したが、40%→10%充填層の代わりにはならない。 |
| 収束確認 | 未合格。未完走を合格にしない判定器を実装。空間、時間刻み、負荷速度、接触積分について、他条件を保持した3水準を要求する。 |

実充填層の平衡保持結果（ボクセル16分割、14,784四面体）：

| 軸圧縮率 | 空隙率 | 軸Cauchy圧縮応力 MPa | 接触点数 |
|---:|---:|---:|---:|
| 0.025 | 0.3936395034 | 0.0130225015 | 0 |
| 0.050 | 0.3884935278 | 0.0169896290 | 0 |
| 0.075 | 0.3825840016 | 0.0203349824 | 0 |
| 0.100 | 0.3761137438 | 0.0233447845 | 0 |

各保持で自由方向の力残差<0.02、運動/内部エネルギー<0.01、相対エネルギー収支誤差<0.02を確認した。これらは開発上の許容値であり、物性精度ではない。

その後の空隙率約36.943%は**平衡保持前の途中値**である。接触開始付近の隣接時刻で異なる積分則を要求し、4試行で同じ則の往復を検出して停止した。元試行、停止理由、再実行用チェックポイントを保存した。圧密解として採用しない。

## 分割保持の追加試験（未合格）

平面対照は合格したが、保存RVEの12姿勢のうち1条件が不合格。最終積分則を以前の姿勢でも評価すると、最大エネルギー誤差0.00908587、最大力誤差0.00999212（約1%）で、判定値0.001を超えた。分割領域を細かくするだけでは、姿勢ごとに変わる最近接分岐を十分に積分できる保証にならない。

実充填層では接触開始の1ステップを進めたが、次の再実行で広域探索候補1,307,080件が上限1,000,000件を超えて初期化停止した。上限引き上げや積分誤差許容値の緩和は行っていない。単純な分割保持の採用では解決できておらず、複数姿勢に対する誤差監査と、保守的で省メモリな接触探索を改良する必要がある。

## 空間離散化

球・円柱ネックの同じ連続形状をCADで結合・周期メッシュ化するツールを追加した。CAD空隙率0.4006618505は独立な連続体積式0.4006618500と約5.2e-10で一致する。形状や固体体積を事後補正していない。

| メッシュ | 四面体数 | 初期空隙率 | 最小品質 |
|---|---:|---:|---:|
| CAD 0.6 mm / ネック0.3 mm | 103,258 | 0.4020883714 | 0.524149 |
| CAD 0.3 mm / ネック0.15 mm | 720,944 | 0.4010407864 | 0.401830 |

両者の周期節点誤差は約4.44e-15 mm、周期接続成分数1、巻き付き階数3。初期空隙率差は0.001047585で、提案判定値0.001をわずかに超える。**形状メッシュの収束も未合格**。既存ボクセルメッシュには大きな初期剛性依存があり、CADメッシュでも変形応答の収束を別途計算する必要がある。CADメッシュによる全圧密は未実施。

BCCは小セルの開発対照であり、統計的等方なランダム充填層の検証にはならない。

## テストと再現

全体スナップショットで **352 passed, 6 skipped**（1641 s）。その後の分割保持の変更について、接触・バックエンドを含む29試験が合格した。未合格方式を試験用に分離した最終コードでは関連**38試験が合格**（182.97 s）。全体試験後の変更まで全体試験済みと混同しない。独立な60桁平面積分を用い、変化する接触域を経た積分則を過去の姿勢でも再評価する。保存姿勢の検証は連成圧密の完走や履歴移行を証明しない。

```bash
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  /workspace/environment/mix_charging/.venv/bin/python tools/run_porosity_cycle.py \
  --config configs/packing-porosity-cycle.json \
  --output results/porosity-cycle-NEW
```

`results`の出力先は毎回新規にする。設定のネイティブライブラリはこの環境の検証済みバイナリを参照する。他環境では既存のビルド手順に従う。通常設定はCADメッシュ、今回の実走は保存済み`voxel-cycle-config.json`によるボクセルメッシュであり、区別する。

残る必須工程は、積分分割の増加と履歴再計算を実用的な負荷で制御すること、表面品質を回復する接触中の再メッシュを監査付きで実現すること、実充填層で10%平衡・除荷を完走すること、その後に独立な数値感度を満たすことである。現時点で到達を保証できる段階ではない。

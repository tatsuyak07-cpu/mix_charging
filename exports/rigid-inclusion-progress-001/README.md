# 浮遊剛体円柱：途中結果

直径4mm・高さ4mmの剛体と16粒子の数値結合試験。最終指定の20x20mm円柱／100mmセルとは区別します。
初期充填層空隙率40.4057%から、9.53125%軸圧縮で34.2357%へ収束しました。
両横周期寸法24.140718mmを固定し、剛体の並進・回転は自由です。
剛体接触9項、最大自由力残差0.00480139N。各軸の剛体力とトルク／半径も0.005N未満です。

**工程3の目標である空隙率10%には未到達です。計算を継続中です。**

# 真応力による周期一軸圧縮制御の検証

pressure-verification.png / transient-cubes.csv は空隙のない1 mm立方体の実際の陽解法FEMです。
mesh-at-0.1MPa.png はその実メッシュであり、球充填体ではありません。
contact-equilibrium.csv は接触を含む解析的な平衡状態の残差検査で、過渡計算ではありません。
load-definition-comparison.png は過去のセル形状を固定して外力の定義だけを比較しています。過去の解析の再計算ではありません。

従来の公称荷重方式は保持し、新方式は loading_mode=cauchy_pressure で明示的に選びます。
層状空隙の過渡試験、一般的な辺接触の反力、表面再メッシュ、40%→10%の充填体圧密は未完了です。
初回の実荷重試験は0.02 MPaの4ケースが合格、0.1 MPaの2ケースは運動エネルギー・解析枝・せん断の検査に不合格です。
追加の質量フレーム・増加時間比較は sensitivity に保存し、全ての判定を保持します。
単一の細分化比較は一般的なメッシュ収束を証明しません。

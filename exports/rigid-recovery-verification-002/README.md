同じ受理履歴・同じ圧縮率から、正則化幅を初期推定中だけ10倍→3倍→元の値とする方法も計算しました。最終段階は元の摩擦係数0.3・正則化幅1e-4 mm・力基準0.005 Nです。中間状態で材料履歴を進めません。

[独立監査](smoothing-force-audit.json)は合格し、直接解法との圧力差0.09105%、空隙率差0.000816ポイント、節点位置最大差0.02004 mmでした。[比較JSON](smoothing-sensitivity.json)。これは一つの有限変形荷重での初期推定依存性であり、全経路の収束ではありません。

## 終点の刻み制御

現在の骨格体積を用いて目標空隙率となるセル体積を予測する選択肢を追加しました。これは次の荷重増分の予測で、骨格体積を拘束するものではありません。材料式による弾性体積変化は従来どおり解きます。解いた後の実空隙率が目標の下限を越えた場合、材料履歴を更新せず増分を半分にして再計算します。新しいvolume制御では10%±0.1ポイントを判定し、最終出力も独立監査の空隙率とNPZハッシュで確認します。

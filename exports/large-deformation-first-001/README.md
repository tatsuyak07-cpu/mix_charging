# 大変形を先に計算する試作結果

実際に釣り合い基準を満たして保存した状態だけをCSVと曲線に含めています。
初期メッシュの測定空隙率は41.162%で、指定の40%と差があります。
材料・荷重増分・摩擦正則化・メッシュの収束を認定した結果ではありません。

`summary.json`に到達状態、`history.csv`に空隙率・公称応力・残差、
`*-mesh.png`に変形倍率1倍の計算メッシュ、`*-mesh.npz`に節点・四面体・材料履歴を保存しています。
圧縮・保持・除荷は別のphaseです。

完全な入力・ソーススナップショット・失敗試行は隣接ZIPに保存しています。

95%圧縮まで計算が正常終了しました。最終空隙率25.816%、経路の最小25.137%で、目標10%は未達成です。
横方向応力自由の周期条件を維持し、終点で横断面積は初期の15.587倍に広がっています。

57.5%圧縮からの別分岐では、保持→ゼロ軸荷重回復が正常終了しました。
空隙率27.103%→28.943%、残留圧縮率55.593%です。
95%から除荷した結果と混同しないでください。

# 接触開始時の積分誤差床と固定積分点の検証

2026-10-28（日本時間）。[前段の工程1〜5](pressure-stages.md)で不採用になった積分点削減案について、微小接触時の誤差判定を検証した。

**見直した誤差配分は、独立な平面9形状×2許容値と、実セル4面×3姿勢の細分化比較に合格した。一方、接触開始時の積分点を固定すると変形後8条件中5条件で不合格だった。** 圧縮ソルバーには組み込んでおらず、0.03 MPaの平衡保持、0.1 MPaへの到達、摩擦履歴を伴う連成再計算は今回の結果ではない。

## 前回の不合格の原因

旧案の誤差予算は、エネルギーについて `E_abs + tol × |E|` だった。3点則へ置換する際にも、許容値を掛けない絶対誤差床 `E_abs = 1e-18 N mm` が残っていた。

一方、ソルバー側の受入判定は `|ΔE| / max(|E_ref|, E_abs) < 0.001` である。両者の絶対誤差の扱いが一致していなかった。力についても同様に `1e-16 N` の床を扱う。

保存された接触開始姿勢の面1522では、細分化した参照値は **4.54520898×10⁻¹⁸ N mm**。ソルバー側の0.1%基準は約4.545×10⁻²¹ N mmなのに対し、旧案の3点置換には約1×10⁻¹⁸ N mmの枠があり、約220倍大きかった。

旧案の高次積分値は比較基準に収まったが、実際の点・重みで積分し直すと **0.271819%** のエネルギー差となり、不合格を再現した。前回の0.272351%との差は、今回の参照積分をさらに細分化したためである。

ここで確認したのは、**前回の点数削減案の不合格原因**である。従来の成分別予算の高次値・実積分則は、今回の実セル12姿勢では基準に収まった。圧縮ソルバーが再積分を繰り返す原因のすべてを、この誤差床だけで説明したという結果ではない。

## 見直した検証用の予算

検証用演算子に `normalized_floor=True` を追加した。既定の旧方式は維持し、圧縮ソルバーはこのオプションを使用しない。

```text
エネルギー誤差枠 = tol × max(|E|, 1e-18 N mm)
力の各成分の誤差枠 = tol × max(F_scale, 1e-16 N)
F_scale = max(源面合力のノルム, 相手節点反力のノルムの和)
```

3点則への置換差は、全小領域の成分別絶対差を加算し、`0.1 × tol` の予算内でだけ置換する。積分値や面積を後から正規化して合わせていない。これは従来の未スケールの床を厳しくする変更であり、0.1%の受入基準を緩める変更ではない。高次・低次差からの推定は一般の数学的誤差保証ではないため、以下の独立比較と細分化を実施した。

## 独立な平面試験

源三角形上の離隔を、面内座標 `x` の一次関数とした。接触する範囲の幅を1、0.1、0.01 mm、接触厚さに対する最小離隔の減少率を0.01、0.0001、0.000001とする9形状を使用した。

投影先は十分大きな1枚の平面三角形である。この形状では、三角形の面積分と源・相手の形状関数のモーメントを独立な1次元積分へ還元できる。密度はPython Decimalの60桁対数で評価し、微小量のスケールを除いてからSciPyの1次元適応積分で比較値を計算した。有限面に対する既存の2次元適応積分を、そのまま厳密値とみなした試験ではない。

- 検証用の `tol=2.5e-4` と `6.25e-5`、計18比較に合格。
- 最大の正規化エネルギー誤差は **0.002476%**、力誤差は **0.002739%**。判定基準はいずれも0.1%。
- 従来の成分別予算は9比較中1比較、従来の合力ノルム予算は9比較中2比較で不合格。これらもCSVに残した。
- 床より小さな信号では、床で正規化した誤差と、実信号そのものに対する相対誤差を別々の列に記録した。微小な物理信号に対して一律0.1%の相対精度を保証したという意味ではない。

## 保存された実セルでの比較

前回の `rve-run-009/attempt-001/last-state.npz` を使用した。完全な摩擦チェックポイントを改変せず、保存された節点位置・参照座標・要素・巨視的変形から、小さな幾何試験データを作成した。入力ファイルのSHA256、周期画像、対象面と参照面積を記録している。

4面（1521、1522、1652、1653）について、保存された接触開始姿勢と、微視的変位を固定して巨視的圧縮を追加した2姿勢（追加量1e-5、1e-4）を調べた。追加姿勢は材料・荷重に対する平衡解ではない。全周期画像を列挙した既存の幾何条件を使い、材料値・摩擦係数・バリア厚さを変えていない。

`tol=2.5e-4 → 6.25e-5 → 1.5625e-5` の3段階で比較した。最後の値は**数値的な細分化参照値であり、実セルの厳密解ではない**。参照値そのものとのゼロ差は合格数に含めない。

| 比較 | 最大エネルギー差 | 最大力差 | 判定 |
|---|---:|---:|---|
| 見直し案の先頭2水準と細分化参照値、12姿勢 | 0.003862% | 0.012170% | 合格 |
| 旧成分別予算の高次値・実積分則、12姿勢 | 約0.001511% | 約0.009682% | 合格 |
| 旧合力ノルム案の実積分則、12姿勢 | 0.271819% | 約0.027610% | 1姿勢不合格 |

### 接触開始時の積分点を固定した場合

見直し案の最初の姿勢の材料座標・重みを保持し、変形後に法線積分だけを再評価した。摩擦履歴の追加・投影・消去は実施していない。

| 面 | 追加圧縮1e-5での最大正規化誤差 | 追加圧縮1e-4での最大正規化誤差 |
|---|---:|---:|
| 1521 | 0.0978% | **0.6040%** |
| 1522 | 0.0355% | **0.1208%** |
| 1652 | **0.2280%** | **7.1819%** |
| 1653 | 0.0287% | **4.3921%** |

太字は基準0.1%を超えた値で、合計5/8条件が不合格だった。今回の見直しだけで初期積分点を固定して圧縮を継続できるとは判断しない。

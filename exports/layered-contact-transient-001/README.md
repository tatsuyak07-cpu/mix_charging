# 層状空隙セルの接触過渡検証

1 mm検証セル、初期空隙率20%、空隙は平面状。球充填体ではありません。
E=10 MPa、μ=0.3、目標Cauchy圧縮0.02 MPa。
4 ms / 8 ms、CFL 0.2 / 0.1を比較し、全ケースと不合格判定を保存しています。
comparison.csv が集計、verification-summary.json が判定の区別です。
各ケースの source と verification-plan.json は計算時のソースと事前の条件です。

追加の接触期間KE診断は、接触数>0かつ指定圧力>観測最大圧力の1%の出力点を対象とします。
出力点だけの最大値は全ステップ最大値の下限です。後半だけの判定とは区別し、
 sampled ratioが1%を超えれば、その接触期間を準静的に検証済みとは扱いません。
対角解析枝との差を一般的な平衡解の不成立と混同しません。
mechanism は、接触前に固体をひずませず空隙を閉じる無剛性モードの独立検査です。
この層状セルを連結した焼結骨格の準静的な圧密の代理には使いません。
connected-initial-stiffness は4 mm連結検証セルの初期接線の検査です。
periodic-connectivity は25 mm準備済み充填体を含む位相検査で、剛性や圧密の計算ではありません。

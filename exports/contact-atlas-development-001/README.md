# 工程1・2：接触積分・摩擦履歴の統合と接触探索

到達目標は引き続き**載荷平衡状態で空隙率40%→10%**。今回は、その前提となる工程1・2を開発・検証した。10%への圧密・保持・除荷、任意の接触位相変化、空間収束の完了を意味しない。

## 工程1：過去の姿勢を忘れない正の接触積分則

以前の「現在の姿勢に適合する積分則へ置換する」方法は隣接時刻で往復した。分割だけを保持する方法も、保存12条件のうち1条件で約1%の誤差を残した。

新しい`pose_atlas`は、過去に不合格となった姿勢を蓄積し、その全姿勢の法線ポテンシャル・源側と相手側の節点反力積分を同時に再現する正の重みを求める。参照面積と2次までの材料座標モーメントも保存する。連成変形解や空隙率を参照値へ合わせる処理ではなく、参照面上の数値積分である。

参照積分の許容値を本体判定値の1/16とし、複数姿勢の候補点から線形計画で正の支持点を選ぶ。従属する条件をQRで処理し、重みを改良した後、全姿勢の応答と面積モーメントを監査する。等式が数値的に不整合になる場合は、面積モーメントを保つミニマックス線形計画と候補点追加を試す。満たせない場合は停止し、過去の不合格姿勢を捨てない。候補点追加は解析対照では有効だったが、実充填層のすべての条件を解決したとは扱わない。

当初の内部合わせ込み枠1/8、続く5/8は、本体監査に合格し得る積分則まで却下するため撤回した。切り出した条件の最小残差は約0.0001907で、参照を4倍細かくしてもほぼ同じだった。最終実装では積分則を**再計算用の提案**として扱い、全保存姿勢の相対・絶対混合基準を満たすことを確認する。その後、接触前からの連成再実行で、実際の各姿勢と全接触面の誤差を別途監査する。この提案だけを物理解として採用しない。

保存形状12条件は、別の細かい参照積分（本体判定値の1/64）との比較に全条件合格した。

- 最大法線エネルギー正規化誤差：3.03848e-7（約0.0000304%）
- 最大法線力正規化誤差：2.34542e-6（約0.000235%）
- 判定値：0.001（0.1%）を維持
- 4面の支持点：27、27、27、26点、合計107点。全重みが正。

エネルギーは`max(|E|, 1e-18 N mm)`、力は源側合力・相手側反力の尺度と`1e-16 N`の床で正規化する。極小接触の実エネルギーに対する相対誤差や、ゼロに近い各成分の相対誤差を示す値ではない。

保存形状は、実計算の停止付近の形状と、そこから作った2つの幾何対照である。平衡圧密状態ではない。

### 摩擦履歴の扱いと周期力の比較

積分点を追加・変更するときは、**接触前の認証済み保存状態から連成計算全体を再実行**する。新しい積分点の塑性すべりや接触アンカーをゼロで補間しない。接触中の一般的な履歴の分割・統合・再メッシュ移行は今回の完了範囲ではない。

周期境界上の等価節点への個別の力の分担は、積分点や相手面の周期代表の選択で変わり得る。比較すべき量は、周期画像の反力と巨視的仕事を含む`Periodic.force(force, extra)`である。等価節点の荷重を別の代表へ移す単体試験で、画像の仕事を含めれば一致し、無視すれば一致しないことを確認した。

最初の試行では、この集約前の生の節点力に約4.3%の差があるとして不合格になった。材料面で共通の摩擦基準方向を使う案も試験したが、この生の力の差は解消しなかった。比較方法を修正し、**摩擦基準方向の変更を戻して、既存の摩擦則を維持した**。

固着・滑り・逆方向滑りの規定運動を、許容値0.001、0.0005、0.00025の3水準で再実行した。解析的な面積ばね・Coulomb限界、適用力状態の再評価、履歴配列の不変性、周期自由度の力・摩擦エネルギー・散逸の水準間差0.2%以内を確認した。これは平面接触の検証であり、任意の非一様すべり場の収束保証ではない。

### 積分用の近傍予測姿勢

接触開始直後に毎ステップの積分則更新と再計算が必要になる負荷を減らすため、現在の速度から4・32刻み先を作る**積分専用の幾何対照**も使用できる。実変形、応力、空隙率の計算結果として採用しない。各実ステップでは従来の独立な法線積分監査を必ず行う。過去の実際の不合格姿勢は保持し、予測用対照は別に記録する。

連成試行では、一時行列の1,200万要素・候補8万点の枠に達したため、試験設定の作業枠を4,800万要素・候補16万点に拡張した。行列本体の上限は倍精度で約384 MB（分解・ソルバー等の追加領域は別）。これは積分則を作るための一時作業枠であり、接触探索の100万件上限や精度判定を変更するものではない。既に解ける対照では、作業枠変更前後の支持点・重みが配列単位で一致することを確認した。

## 工程2：保守的な境界箱階層探索

点―三角形、辺―辺を現在の周期画像ごとの軸平行境界箱で階層化する。境界箱同士の距離は実際のプリミティブ距離の下界なので、箱の距離が探索幅より大きい場合だけ除外する。丸め誤差分の余裕を加える。探索幅、接触厚さ、摩擦係数、候補数上限は変更していない。

点の候補は1問い合わせずつ処理し、辺の厳密距離評価は最大1024組で分割する。全節点の候補リストを一括で確保しない。従来方式は独立な比較用として残した。

前回停止付近の保存形状で、仮想積分点48,950点、総点数52,741点を使い、次を確認した。

| 項目 | 従来の中心球探索 | 境界箱探索 |
|---|---:|---:|
| 点―三角形の広域候補 | 1,307,081 | 406,213 |
| 辺―辺の広域候補 | 262,012 | 83,468 |
| 合計候補 | 1,569,093 | 489,681 |
| 最終接触候補 | 98,320 | 98,320 |

最終候補のキー、節点、周期画像、係数、閾値は全組一致し、欠落・追加とも0。新方式は本体上限1,000,000件で通過した。旧方式の全組比較だけには診断用の大きい上限を与えたが、物理ソルバーの上限は引き上げていない。

処理時間は共有CPU環境で約104秒と265秒だった。厳密な専有環境の速度測定ではない。ランダム境界箱の全探索、変形した周期画像の全プリミティブ探索、接触力の比較でも一致した。

## 連成再計算とテスト

接触前の変位指定サイクルから接触演算子を更新できるよう、保存された変位・速度・加速度、自由成分の半ステップ速度、材料力・体積・エネルギーの再計算を照合する再開監査を追加した。履歴が存在する状態での演算子交換は許可していない。加速度を改変した保存状態は拒否する。

回帰用スナップショットで363件合格・6件スキップ。摩擦履歴の3水準試験も別途合格した。最終ソースでは接触探索・積分・絶対誤差予算・予測対照・再開監査・埋込接触の関連36テストが87.20秒で合格した（コマンドは同梱ログ参照）。回帰用ソース、後続修正用ソース、未採用の材料面基準方向の試行は区別して保存する。363件すべてを最終ソースで再実行済みとは扱わない。

### 極小接触の絶対誤差予算と連成44ステップ

極小の接触力に相対基準だけを課すと、連続する姿勢で積分則の再構築を繰り返した。このため、法線積分に追加する全体絶対誤差予算を任意設定として導入した。既定値は0で、従来の相対基準0.1%を維持する。各面の相対許容分を差し引いた残差について、力は全成分の絶対値和、エネルギーは絶対値を取り、全接触面で合算する。適用則の合算上限は全体予算Bの1/2。参照積分には全表面へ均等に分けたB/8を与える。追加の法線誤差枠は合計5B/8以下であり、これとは別に既存の相対許容分がある。参照積分自体は適応積分の誤差推定に基づき、数学的な厳密誤差保証ではない。

適用則の予算を非接触面にも均等配分した旧試行は過剰に厳しく、再計算を繰り返した。最終実装は、実測した全接触面の残差和が上限を超える場合だけ接触面に再配分する。各受理ステップの残差和を`contact-integration-budget.jsonl`へ保存する。摩擦係数0.3と元の摩擦則は維持し、この法線予算を接線力・履歴の厳密誤差限界とは扱わない。

既存の小BCCセル、E=10 MPa、ν=0.33、降伏0.05 MPa、硬化0.2 MPa、横方向応力自由の周期条件を維持し、接触前の90206刻みから90250刻みまで、44受理刻みを3水準で検証した。

| 全体予算：力N / エネルギーN mm | 再実行回数 | 最大の法線力追加残差N | 44刻みの検査 |
|---|---:|---:|---|
| 1e-6 / 1e-6 | 1 | 4.20411e-7 | 合格 |
| 5e-7 / 5e-7 | 2 | 3.07193e-8 | 合格 |
| 2.5e-7 / 2.5e-7 | 2 | 1.30193e-8 | 合格 |

全水準で体積整合、正のJ、エネルギー収支、低運動エネルギー、Coulomb限界、貫入量等の検査に合格した。3水準の共通軸圧縮区間を201点で比較し、空隙率の最大絶対差2.35e-12、圧力の最大正規化差4.36e-8、内部エネルギーの最大正規化差1.04e-14。開発者設定の判定値はそれぞれ1e-6、1e-4、1e-4。最初の比較器は保存先パスと学習された積分則も設定不一致と判定したため、物理条件からこの記録上の差を分離して再評価した。元の判定も保存している。

終端の空隙率は約36.9419214%だが、**圧縮中の過渡値**である。全3試験とも事前指定の刻み数上限で停止し、サイクル完了フラグはfalse。短区間の予算感度は確認したが、静的平衡、時間刻み・空間収束、10%への圧密、保持・除荷、接触中の表面再メッシュは未達成。旧試行の積分則往復、作業枠超過、線形計画の失敗、中断も診断資料に残す。

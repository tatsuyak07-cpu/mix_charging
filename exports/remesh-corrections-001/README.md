# 接触中の再メッシュ：速度保存・同距離分岐・過去姿勢の修正

前回不合格だった、速度移行の保存則と、同距離の異なる最近接投影による参照積分の停止を修正した。**速度のある接触状態での分割・保存/再開・3ステップの継続が、CFL 0.2 / 0.1 / 0.05の全条件で合格**した。実充填層は積分点と子面面積の不整合で依然分割できないため、工程3全体と空隙率40%→10%の圧密は未完了である。

## 速度の制約付き移行

従来の新メッシュ上の質量射影だけでは、角運動量と運動エネルギーが変化した。前回の動的対照では、それぞれ正規化誤差約0.0100、0.00480で、既存許容値0.001を超えていた。

`conservative_velocity.project`では、新しい周期自由度の質量行列を使い、物理節点で計算した線形運動量3成分・角運動量3成分を制約する。指定されている巨視的速度成分は固定する。制約内の最小エネルギー速度を求め、その制約を変えない速度成分だけを拡大・縮小して、元の運動エネルギーへ一致させる。

質量内積で直交する分解により、運動エネルギーは「制約内最小値＋制約を変えない成分のエネルギー」となる。元のエネルギーが最小値を下回る場合、制約の整合性を満たせない場合、保存に必要な速度成分が表現されない場合は拒否する。未知の速度モードを追加してエネルギーを作らない。最終的に節点の速度から運動量とエネルギーを独立に計算し直す。

この方法は`surface_velocity_transfer="momentum_energy"`の明示指定で有効になる。従来の`l2`を既定値として残す。6×6の制約行列の階数判定は128倍の機械精度、エネルギー差の丸め枠は1024倍の機械精度を用いる開発上の数値選択である。最終保存監査1e-10と既存の再メッシュ許容値は緩和していない。局所速度場は射影で変化するため、その分布や変形応答への影響は別途収束確認が必要である。

周期平面対照では、速度を持つ1ステップ後に分割した。前回と同じ材料・密度・減衰・μ=0.3・接触剛性を使い、再開結果は連続計算と配列単位で一致した。分割を許可しない対照は、分割しない計算の配列と一致する。

3つのCFLは、異なる時間刻みで保存処理が成立することの対照である。それぞれ3ステップまでの短い動的試験であり、同じ物理時間での時間収束、準静的平衡や圧密完走の確認ではない。

## 同距離接触の参照積分

本体の`closest_tie_rule="clarke"`は、異なる最近接点が同距離にあるとき、それぞれの反力の一様平均を使う。一方、参照積分はこの状態を常に拒否しており、分割後の動的継続が停止した。

参照積分へ同じ選択肢を接続した。ポテンシャルは最近接距離から計算した値を保ち、勾配だけを異なる投影点のClarke平均にする。共有辺の三角形の重複など、同じ投影を表す面を重ねて数えない。既定の`stop`は維持し、接触本体で明示した規則を参照積分・積分用予測姿勢・pose-atlasへ引き継ぐ。

独立なV字面対照では、左右の投影点が異なり、距離は高さ/√2となる。3種類の高さで、解析的な法線ポテンシャル、水平反力ゼロ、鉛直反力Fn/√2、作用反作用、三角形の重複・順序による不変性、鉛直方向の有限差分勾配を検査する。これは平均反力の選択規則の検証で、非滑らかな接触問題全般の収束保証ではない。 最近接面が切り替わる領域をまたぐ追加対照では、従来の面の辺だけによる細分化に時間を要した。平面の符号付き距離の和・差がゼロとなる二等分面も積分分割の候補へ追加した。分割後も領域全体と誤差監査を保持し、候補・力を削除したり精度枠を広げたりしない。同じV字対照を再実行し、正のpose-atlas積分則と細かい独立参照の一致、分割の被覆と分岐境界の解消を確認した。

## 過去姿勢の子面への移行

以前はpose-atlasを持つ面の分割を一律に拒否した。今回は、既存の点・重みが子面面積に一致する場合に限り、**すべての過去姿勢と予測用姿勢**を子面の材料座標へ変換する。各子面で保持した点・重みを使い、独立な細かい参照積分と法線ポテンシャル・節点反力を再比較する。相対判定0.001を超えれば拒否し、過去姿勢を削除したり、重みを修正したりしない。全体絶対誤差予算を子面の過去姿勢監査に流用しないため、この移行判定は保守的である。

面積を保って反力の一次モーメントを壊した異常対照は拒否する。最初の異常注入は許容差内であり、拒否を期待した試験が失敗したため、一次モーメントを明確に壊す対照へ修正した。許容値は変更していない。保持された積分分割セルそのものの切断、積分点の追加・削除、接触履歴の一般的な射影は今回の対象外。

## 実充填層の残る制限

以前の90250刻み・接触履歴69個の保存状態から、同じ接触面の3辺を再検査した。過去姿勢メタデータの一律拒否は解消したが、**適用可能0/3**は変わらない。

- 2辺：既存積分点の重み和が子面の参照面積に一致しない。
- 1辺：分割に適合する積分則が事前にない。

この保存状態は幾何と積分則の適用診断にだけ使い、新しい摩擦・接触演算子でそのまま継続していない。次に必要なのは、積分領域と接触履歴の保存を満たす一般的な点の追加・再配分である。さらに、形状品質を回復する操作、実充填層の長い圧密・保持・除荷、空間・時間・載荷速度等の収束を検証する必要がある。今回の辺分割は形状を細分化する操作であり、最小品質の改善を保証しない。

## 最終検証結果

最終ソースの関連**50試験が109.94秒で合格**した。保存射影の3分割位置×2周期質量フレーム、ゼロエネルギー・不整合データの拒否、V字面と正の積分則、過去姿勢の子面監査、既存の接触・保存/再開・固着履歴等を含む。全リポジトリの全試験を再実行した件数ではない。

修正後のCFL 0.2、0.1、0.05では、いずれも動的分割の保存監査、連続計算との保存/再開一致、拒否時の未分割計算との一致、3ステップ継続に合格した。CFL 0.2での線形運動量・角運動量・運動エネルギーの正規化誤差は、それぞれ約1.20e-16、2.25e-16、4.04e-16。接触の巨視的仕事の誤差は約5.10e-14だった。

条件を一つずつ戻す対照も保存した。速度だけを従来のL2射影にすると角運動量・運動エネルギーで不合格になり、反力規則を`stop`にすると分割後に同距離投影で停止する。これらの対照は未合格として記録し、修正後の合格条件と混同しない。

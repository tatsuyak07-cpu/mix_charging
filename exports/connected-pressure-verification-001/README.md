# 連結多孔質セルの圧縮検証

4 mm角、初期空隙率0.25%、100節点・264初期四面体の検証用形状です。
球充填体の40%→10%の結果ではありません。
comparison.csvとverification-summary.jsonで既存の後半・終点検査と追加KE監査を区別しています。
全採用ステップのデータは各 run/accepted-step-audit.csv.gz です。
追加KE窓は、圧力が観測最大値の1%を超える時点。初期の小さい分母にも注意してください。
初期接線の一次予測は弾性の低圧比較のみで使い、塑性時に適用しません。
連結セルの変形・接触・塑性を検証する試験で、初期弾性の1回の細分化比較を initial-refinement に保存しました。圧縮塑性のメッシュ収束ではありません。
材料校正、除荷、一般辺接触、表面再メッシュ、メッシュ収束は未完了です。

## 三角形対と独立基準

単位はmm、N、MPa。元の材料座標で頂点(0,0)、(1,0)、(0,1)の参照三角形を使い、参照面積は0.5 mm²とする。現在の三角形は、対向する有限平面三角形からの離隔を `g = g_min + (0.02−g_min)u/w` として傾斜させる。

- 辺の帯状接触：`u=x`。活性領域は `x<w`。
- 頂点付近の接触：`u=x+y`。活性領域は `x+y<w`。

`w` は0.02、0.002、0.0002 mm、最小離隔は0.005、0.0005 mm、相対許容値は0.001、0.0005の計24条件とする。頂点付近の `w` は座標和の幅であり、帯と同じユークリッド幅という意味ではない。現在の三角形は検証用に強く傾く場合がある。実充填層をこの形状で近似したものではない。

相手の三角形は頂点(−2,−2,0)、(4,−2,0)、(−2,4,0)で、活性領域の投影を含む。全体を平行移動し、最小離隔0.0005 mmの条件では法線まわりに0.37 rad回転する。一般の3次元回転に対する適応積分の客観性は今回の比較からは主張しない。

接触厚さ0.02 mm、面積あたり法線係数20 MPa/mmは、既存の平面接触試験から維持した数値条件である。単一の対について一方の参照面を1回積分する。既存の両側積分へ組み込む際の二重計上を解決したわけではない。

基準値には、面積分を独立に1次元へ還元したQUADPACK積分を用いる。辺では断面の長さが `1−u`、頂点では `u` となるため、それぞれを法線ポテンシャル・反力へ掛けて `0≤u≤w` を積分する。元の形状関数で重み付けした各源側節点の反力も基準値と比較する。法線則そのものは既存の `barrier` を共有するので、これは積分の検証であり、法線則の独立校正ではない。

## 検出・積分・力の配分

源側の材料座標を重心座標で保持し、その小三角形を積分のためだけに分割する。体積メッシュや有限要素の自由度は増やさない。重みは現在面積ではなく参照面積で定義する。

各小三角形と相手三角形の軸平行包囲箱（AABB）間距離を、離隔の下限として使用する。浮動小数点の丸めを考慮する余白も引く。下限が接触厚さ以上の領域だけを幾何的な非接触領域として除外する。AABBが重なる場合、下限0は交差や接触の証明ではなく「この下限では未解決」である。

小三角形の頂点での距離差を使って材料座標の切断方向を選ぶ。ただし、この線形距離補間は分割位置の選択にだけ使い、非接触判定には使わない。等しい頂点距離だけでも内部に接触がないとは判断しない。

Duffy写像と4×4・8×8点のGauss積分を比較し、積分点の距離と下限との関係も確認する。十分に解像されていない小領域には、下限でのポテンシャル・法線反力から積分寄与の上限を付ける。積分点で反力が0でも、それだけで接触なしとは扱わない。

各領域の誤差見積もりを全体で合計し、寄与の大きい領域から分割する。成分ごとの全体予算は `相対許容値×|全体積分|＋絶対許容値` とし、絶対許容値はエネルギー1e−18 N mm、各節点力成分1e−16 Nを維持する。下限0や誤差が解決しない場合は分割上限で明示的に停止する。

次数比較は厳密な積分誤差証明ではない。合格判定には上記の内部判定とは別に、独立基準との誤差0.002以下、許容値半減時の変化0.002以下を使用した。両者を混同していない。一般形状ではAABBが緩すぎて停止する可能性がある。

各積分点では、源側3節点と相手側3節点へ形状関数で等大反対の力を配分する。面内部の射影では平面法線から距離を求め、射影位置の丸めによる微小な偽の接線反力を避ける。辺・頂点が最近接の場合は既存の最近接計算へ戻す。まとめて評価する処理は、面・辺・頂点・非接触点・回転した形状でスカラー処理と照合した。

## 最終結果

| 確認項目 | 最大誤差・結果 |
|---|---:|
| 独立基準との法線反力の相対誤差 | 6.55×10⁻⁵ |
| 独立基準とのエネルギーの相対誤差 | 4.64×10⁻⁶ |
| 許容値半減による反力の相対変化 | 4.14×10⁻⁵ |
| 許容値半減によるエネルギーの相対変化 | 3.26×10⁻⁶ |
| 固定した最終積分点での仮想仕事の相対誤差 | 9.84×10⁻⁸ |
| 参照面積の分割誤差 | 5.56×10⁻¹⁷ mm² |
| 最大積分点数 | 12,096 |
| 最大分割深さ | 16（上限28） |

全24条件で作用反作用、モーメントの釣り合い、正の積分重み、有効な材料重心座標も確認した。最終的に未解像のまま残る領域の寄与上限は全24条件で0だった。重心1点だけの負例では、全条件で接触を完全に見逃すことも確認した。

仮想仕事は、適応分割後の積分点と重みを固定し、6節点を独立方向へ摂動してポテンシャルの差分と反力を比較した。積分点集合を変えるときのエネルギー連続性や、連成ソルバーの時間積分を確認したものではない。

さらに、辺上の分割位置0.2・0.5・0.8、相対許容値0.001・0.0005、辺・頂点の接触の計12条件を検証した。子三角形の源側反力を、幾何補間の転置で親の3節点へ戻した。元の三角形との反力差は最大5.48×10⁻⁶、エネルギー差は3.20×10⁻⁷、独立基準との差は8.32×10⁻⁶だった。これは法線積分の分割位置依存の検証であり、摩擦履歴の移行ではない。

関連30テストはすべて合格した（新規三角形積分13、既存摩擦履歴・接触記録17）。既存の圧縮処理から呼ばれない独立モジュールの追加なので、全体スイートは今回再実行していない。

## 保存した途中試行

低次の3点積分では、最初の条件だけで約16.6万点を要した。高次化と一括評価への変更前の2試行は、完了済みの比較を保存した上で計算量改善のために中断した。中断を完走とは数えていない。

その後の2試行では、活性領域の境界で分割上限に達して停止した。診断した小領域は面積約8.88×10⁻¹⁶ mm²、反力寄与約2.40×10⁻²⁸ Nだった。局所的な相対誤差を面積に比例した極小の絶対予算で判定したため、全体積分に影響しない領域を過剰に細分化していた。

全体上限の残額から小領域を逐次省略する試行でも、予算を使い切る方向に偏り、別の微小領域で停止した。最終方式では領域を順に省略する方式を使わず、全領域の推定誤差を合計して分割順を選ぶ。材料・接触係数・判定用相対許容値・全体の絶対誤差予算は変更していない。失敗・中断ログ、その時点の実装と入力生成コード、完了済みデータをすべてZIPに残した。

## 圧縮ソルバーへ接続する前の工程

次は有限な複数面と周期画像を含む最近接パッチの選択を検証し、面ごとの積分を単純に足して二重計上しないこと、セル境界を跨いだ反力・仕事が保存されることを確認する必要がある。

その後、[前回の履歴再生検証](integration-replay.md)と組み合わせ、材料座標を持つ積分点へ確定履歴と力評価状態を復元する。現在の新モジュールには摩擦履歴、パッチ遷移、周期画像の列挙、接触CFL、圧縮ソルバーの完全なチェックポイント・巻き戻しを実装していない。新しい積分規則を入れた連成計算の再実行と、力・エネルギー・準静的性の監査が必要である。

100 mm充填層の代表性、体積メッシュ収束、大変形での一般の表面再生成も未確認である。今回の接触単体試験の合格を、0.1 MPaの圧密解として使わない。
